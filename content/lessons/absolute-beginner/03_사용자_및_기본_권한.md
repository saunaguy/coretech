### 사용자와 권한의 기본 개념
> 💡 리눅스는 여러 사람이 하나의 시스템에 동시에 접속해서 사용하는 '다중 사용자(Multi-user)' 시스템입니다. 따라서 다른 사용자나 시스템 자체에 영향을 주지 못하도록 사용자별로 권한을 나누어 관리하는 것이 매우 중요합니다.

**1. `root` (슈퍼유저) 와 일반 사용자**
* **`root` 사용자**: 시스템의 모든 것을 할 수 있는 전지전능한 관리자입니다. 어떤 파일이든 수정/삭제가 가능하므로, 사소한 실수가 시스템 전체를 망가뜨릴 수 있어 평소에는 사용을 자제해야 합니다.
* **일반 사용자**: `root`에 의해 생성되며, 제한된 권한을 가집니다. 기본적으로 자신의 홈 디렉토리(`home/사용자명`)에서만 자유롭게 파일을 다룰 수 있습니다.

**2. `whoami` : 현재 사용자 확인하기**
* 현재 터미널에 로그인된 사용자가 누구인지 알려줍니다.
```bash
$ whoami
user
```

**3. `sudo` (Superuser Do) : 관리자 권한 빌려오기**
* 일반 사용자가 관리자 권한이 필요한 명령어를 실행해야 할 때, 명령어 앞에 `sudo`를 붙여 임시로 `root`의 권한을 빌려 실행합니다.
* 명령어 실행 시 현재 사용자의 비밀번호를 입력하여 인증합니다.
```bash
# 시스템 패키지를 업데이트하려면 관리자 권한이 필요합니다.
$ apt update
Reading package lists... Done
E: Could not open lock file /var/lib/apt/lists/lock - open (13: Permission denied)

# sudo를 붙여서 다시 실행
$ sudo apt update
[sudo] password for user: (비밀번호 입력)
... (성공적으로 실행됨)
```

### 권한 확인 및 변경
**1. `ls -l` : 권한 확인하기**
* `ls -l` 명령어를 사용하면 파일과 디렉토리의 상세 정보를 볼 수 있으며, 가장 앞부분에 권한 정보가 표시됩니다.
```bash
$ ls -l
-rwxr-xr-- 1 user staff 8540 Aug 25 10:20 report.docx
drwxr-xr-x 2 user staff 4096 Aug 25 10:21 backup
```

> 🔎 **`drwxr-xr--` 권한 분석하기**
> 
> • **1번째 글자 (`d`) : 파일 종류**
>   - `-` : 일반 파일
>   - `d` : 디렉토리
>   - `l` : 심볼릭 링크
> 
> • **2~4번째 글자 (`rwx`) : 소유자(User)의 권한**
>   - `r` (Read): 읽기
>   - `w` (Write): 쓰기
>   - `x` (eXecute): 실행
> 
> • **5~7번째 글자 (`r-x`) : 그룹(Group)의 권한**
>   - `r--`: 읽기만 가능
>   - `r-x`: 읽기와 실행만 가능
> 
> • **8~10번째 글자 (`r--`) : 그 외 사용자(Others)의 권한**
>   - `---`: 아무 권한 없음
> 
> → 즉, `drwxr-xr--`는 **디렉토리**이며, **소유자**는 모든 권한을, **그룹**은 읽고 실행할 권한을, **그 외 사용자**는 읽기 권한만 가집니다.

**2. `chmod` (Change Mode) : 권한 변경하기**
* 파일이나 디렉토리의 접근 권한을 변경하는 명령어입니다. 두 가지 방식이 있습니다.

<details>
<summary>**Symbolic(기호) 방식**</summary>
문자 조합으로 대상(u,g,o,a)과 동작(+,-,=)을 지정합니다.

```bash
# 소유자(u)에게 실행(x) 권한 추가
chmod u+x run.sh

# 그룹(g)과 기타(o)에서 쓰기(w) 권한 제거
chmod go-w notes.txt

# 모든 대상(a)에 대해 읽기-실행만 허용(=)
chmod a=rx script.py
```
</details>

<details>
<summary>**Octal(8진수) 방식**</summary>
각 권한은 r=4, w=2, x=1로 합산하여 표기합니다. 순서는 사용자-그룹-기타입니다.

```bash
# rwxr-xr-- (소유자=7, 그룹=5, 기타=4)
chmod 754 app

# rw-r----- (소유자=6, 그룹=4, 기타=0)
chmod 640 secret.txt
```
</details>

### 심화 학습: 권한의 상세 이해
> 🔬 **`ls -l` 명령어의 출력을 제대로 해석할 수 있다면, 파일의 모든 권한 상태를 한눈에 파악할 수 있습니다.**

**`ls -l` 출력 결과 상세 분석**
```bash
$ ls -l
-rwxr-xr-- 1 user staff 8540 Aug 25 10:20 report.docx
```
위 출력 결과는 7개의 필드로 구성됩니다.

**[1] 권한 정보 (`-rwxr-xr--`)**: 파일의 종류와 권한을 나타냅니다. (자세한 내용은 바로 아래에서 설명)

**[2] 하드 링크 수 (`1`)**: 이 파일에 연결된 하드 링크의 개수입니다.

**[3] 소유자 (`user`)**: 파일을 소유한 사용자의 이름입니다.

**[4] 그룹 (`staff`)**: 파일을 소유한 그룹의 이름입니다.

**[5] 파일 크기 (`8540`)**: 파일의 크기를 바이트(Byte) 단위로 나타냅니다.

**[6] 최종 수정일 (`Aug 25 10:20`)**: 파일이 마지막으로 수정된 날짜와 시간입니다.

**[7] 파일 이름 (`report.docx`)**: 파일의 이름입니다.

**파일 vs 디렉토리 권한의 의미**
* r, w, x 권한은 대상이 파일이냐 디렉토리냐에 따라 그 의미가 달라집니다.

<details>
<summary>📄 **파일(File)일 경우**</summary>
* r: 파일 내용 읽기, w: 파일 내용/크기 수정, x: 실행 가능(스크립트/바이너리).
* 실행 권한이 없는 스크립트는 `bash script.sh`처럼 인터프리터로 실행해야 합니다.
</details>

<details>
<summary>📁 **디렉토리(Directory)일 경우**</summary>
* r: 디렉토리 내 파일 ‘이름 목록’을 읽을 수 있음.
* w: 디렉토리 내에서 파일 생성/삭제/이름변경 가능.
* x: 디렉토리에 ‘들어갈 수 있음’(검색/접근). 보통 목록(r)과 함께 필요.
</details>

### 소유권 변경과 umask, 특수권한 기초
**소유권 변경**
```bash
# 파일 소유자 변경
sudo chown alice report.txt

# 소유자와 그룹 동시에 변경
sudo chown bob:dev team_notes.md

# 디렉토리 재귀 변경
sudo chown -R www-data:www-data /var/www/html
```

**umask: 기본 권한 마스크**
* 새로 만드는 파일/디렉토리의 기본 권한에서 ‘빼줄’ 값을 의미합니다.
* 일반적으로 022(파일 기본 644, 디렉토리 기본 755) 또는 027을 사용.
```bash
# 현재 세션 umask 확인/설정
umask
umask 027
```

**SUID/SGID 기초**
* SUID(bit 4xxx): 실행 시 소유자 권한으로 동작. 예) `/usr/bin/passwd`
* SGID(bit 2xxx): 실행 파일에선 그룹 권한으로, 디렉토리에서는 하위 파일의 그룹을 상속.
```bash
# SUID 설정 예 (소유자 실행 비트에 s): -rwsr-xr-x
sudo chmod 4755 /usr/local/bin/mytool

# 디렉토리에 SGID 설정 (신규 파일의 그룹 상속)
sudo chmod 2775 /shared/projects
```
