### 명령어 조합의 예술: 파이프와 리다이렉션
> 🔗 리눅스의 진정한 강력함은 각자의 역할에 충실한 작은 명령어들을 조합하여 복잡한 작업을 해결하는 데 있습니다. 이 조합의 핵심이 바로 파이프와 리다이렉션입니다.

**1. `|` (파이프): 명령어의 출력을 다른 명령어의 입력으로**
* 파이프는 왼쪽 명령어의 실행 결과(표준 출력)를 오른쪽 명령어의 입력(표준 입력)으로 전달하는 연결 통로입니다.
```bash
# 실행 중인 프로세스 목록 중에서 'nginx'라는 단어가 포함된 줄만 필터링
$ ps aux | grep nginx

# 현재 디렉토리의 파일 목록을 한 페이지씩 보여주기
$ ls -al | less
```

**2. `>` , `>>` (리다이렉션): 명령어의 출력을 파일로 저장**
* `>`: 명령어의 결과를 파일에 **덮어씁니다.** (기존 내용 삭제)
* `>>`: 명령어의 결과를 파일의 **끝에 추가합니다.** (기존 내용 유지)
```bash
# 현재 디렉토리 목록을 file_list.txt 파일에 저장 (덮어쓰기)
$ ls -al > file_list.txt

# 시스템 로그 중 에러 부분만 error.log 파일에 추가하기
$ cat /var/log/syslog | grep "error" >> error.log
```

### 핵심 유틸리티: `grep`과 `find`
**1. `grep` : 텍스트 검색의 제왕**
* 파일 내용이나 명령어 출력 결과에서 특정 텍스트 패턴을 찾아 해당 라인을 출력합니다.
* **주요 옵션**: `-r` (하위 디렉토리까지 검색), `-i` (대소문자 무시), `-v` (패턴을 제외한 라인 출력), `-n` (라인 번호 표시)
```bash
# access.log 파일에서 "ERROR" 문자열이 포함된 줄을 대소문자 무시하고 검색
$ grep -i "ERROR" access.log

# 현재 디렉토리와 하위 모든 디렉토리의 .py 파일에서 "import"가 들어간 라인을 라인 번호와 함께 검색
$ grep -rn "import" . --include="*.py"
```

**2. `find` : 파일 및 디렉토리 검색**
* 이름, 종류, 크기, 수정 시간 등 다양한 조건으로 파일이나 디렉토리를 검색합니다.
* **주요 옵션**: `-name` (이름으로 검색), `-type f` (파일만), `-type d` (디렉토리만), `-mtime -7` (최근 7일 내 수정된 파일)
```bash
# 현재 디렉토리 아래에서 .log로 끝나는 모든 파일 검색
$ find . -name "*.log"

# /etc 디렉토리 아래에서 이름이 conf로 끝나는 파일 검색
$ find /etc -name "*conf"

# 7일 이내에 수정된 모든 파일 찾아서 상세 정보 출력
$ find . -mtime -7 -exec ls -l {} \;
```

### 셸 스크립트 기초: 변수/조건/반복
```bash
#!/usr/bin/env bash

# 변수
NAME="Alice"
echo "Hello, $NAME"

# 조건문
if [ -f "/etc/os-release" ]; then
  echo "Linux"
else
  echo "Unknown OS"
fi

# 반복문
for u in alice bob carol; do
  echo "User: $u"
done
```

### 실습 1: 사용자 계정 생성 자동화
```bash
#!/usr/bin/env bash
set -euo pipefail

USERS=(alice bob carol)
for u in "${USERS[@]}"; do
  id "$u" &>/dev/null || sudo useradd -m "$u"
  echo "$u:TempPass123" | sudo chpasswd
  echo "Created/updated $u"
done
```

### 실습 2: 로그 백업 스크립트
```bash
#!/usr/bin/env bash
set -euo pipefail
DATE=$(date +%F)
SRC=/var/log
DST=/backup/logs
sudo mkdir -p "$DST"
sudo tar -czf "$DST/logs_$DATE.tgz" "$SRC"
echo "Backup done: $DST/logs_$DATE.tgz"
```
