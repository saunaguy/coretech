### 리눅스란?: 역사와 철학
리눅스(Linux)는 1991년 핀란드의 대학생이었던 리누스 토르발스(Linus Torvalds)가 개발한 운영체제 '커널'에서 시작되었습니다. 커널이란 운영체제의 가장 핵심적인 부분으로, 하드웨어와 소프트웨어 사이의 통신을 관리합니다.
리눅스의 발전을 이해하기 위해서는 그보다 먼저 시작된 'GNU 프로젝트'를 알아야 합니다. 1983년 리처드 스톨먼(Richard Stallman)이 시작한 이 프로젝트는 모든 소프트웨어가 자유로워야 한다는 '자유 소프트웨어' 철학을 기반으로 합니다.
* **GNU의 네 가지 자유**
* 1.  **실행의 자유**: 목적에 상관없이 프로그램을 실행할 수 있는 자유
* 2.  **연구 및 수정의 자유**: 소스 코드를 보고 필요에 맞게 고칠 수 있는 자유
* 3.  **복제 및 배포의 자유**: 이웃을 돕기 위해 자유롭게 복제하고 나눠줄 수 있는 자유
* 4.  **개선 및 재배포의 자유**: 프로그램을 개선하여 공동체 전체와 나눌 수 있는 자유
GNU 프로젝트는 운영체제에 필요한 대부분의 소프트웨어(컴파일러, 셸, 편집기 등)를 만들었지만, 핵심인 '커널' 개발이 더뎠습니다. 바로 그때, 리누스 토르발스의 '리눅스 커널'이 등장했고, 이 둘이 만나 완전한 자유 운영체제인 **GNU/리눅스**가 탄생하게 된 것입니다.

### 터미널과 셸(Shell)
리눅스에서는 주로 텍스트 기반의 명령어로 소통하는데, 이때 사용되는 두 가지 핵심 요소가 바로 '터미널'과 '셸'입니다. 둘은 종종 혼용되지만 다른 개념입니다.
**터미널 (Terminal)**
* **역할**: 사용자가 키보드로 명령어를 입력하고, 컴퓨터의 처리 결과를 눈으로 볼 수 있게 해주는 '환경' 또는 '창' 그 자체입니다.
* **비유**: 컴퓨터와 대화하기 위한 '키보드와 모니터'라고 생각할 수 있습니다.
**셸 (Shell)**
* **역할**: 터미널을 통해 입력된 명령어를 해석해서, 운영체제의 핵심(커널)이 알아들을 수 있도록 전달하는 '명령어 해석기'입니다.
* **비유**: 해외여행 시 우리의 말을 현지 언어로 바꿔주는 '통역가'와 같습니다.
**주요 셸(Shell)의 종류**
* **Bash (Bourne-Again Shell)**: 대부분의 리눅스 배포판에서 기본으로 사용하는 가장 대중적인 셸입니다. 강력한 스크립팅 기능을 제공합니다.
* **Zsh (Z Shell)**: Bash를 확장한 셸로, 향상된 자동 완성, 테마, 플러그인 등 사용자 편의 기능이 매우 강력하여 인기가 높습니다.
* 이 외에도 `sh`, `csh`, `ksh`, `fish` 등 다양한 셸이 존재합니다.

### 핵심 탐색 명령어
리눅스 파일 시스템을 자유롭게 돌아다니기 위해 반드시 알아야 할 3가지 필수 명령어입니다.
**1. `pwd` (Print Working Directory)**
* 현재 내가 어떤 디렉토리(폴더)에 위치해 있는지 전체 경로를 보여줍니다.
```bash
$ pwd
/home/user/Documents
```
**2. `ls` (List)**
* 현재 위치의 파일 및 디렉토리 목록을 보여줍니다. 가장 많이 사용하는 옵션은 다음과 같습니다.
* `ls -l`: 권한, 소유자, 크기, 날짜 등 상세 정보를 긴 형태로 보여줍니다.
* `ls -a`: 숨김 파일(이름이 `.`으로 시작)을 포함한 모든 항목을 보여줍니다.
```bash
$ ls -la
total 28
drwxr-xr-x 2 user user 4096 Aug 15 10:00 Desktop
-rw-r--r-- 1 user user 8451 Aug 22 09:15 report.txt
```
**3. `cd` (Change Directory)**
* 다른 디렉토리로 작업 위치를 이동합니다.
* `cd [디렉토리명]`: 해당 디렉토리로 이동합니다.
* `cd ..`: 바로 상위 디렉토리로 이동합니다.
* `cd ~` 또는 `cd`: 나의 홈 디렉토리로 바로 이동합니다.
```bash
# 현재 위치가 /home/user/Documents 라고 가정
$ cd ..
$ pwd
/home/user

$ cd ~
$ pwd
/home/user
```

### 설치 및 가상화 기초
> 처음 만나는 리눅스는 가상머신에서 안전하게 실습하는 것이 가장 좋습니다.

**1. ISO 이미지와 부팅**
* 배포판 사이트에서 `.iso` 이미지를 내려받아 가상머신의 CD/DVD로 마운트하여 설치를 시작합니다.
* 흔한 선택: Ubuntu Server, Rocky Linux, AlmaLinux 등.

**2. VirtualBox/VMware 핵심 네트워크 모드**
* NAT: 호스트의 인터넷을 공유. 간단한 실습에 적합. 외부에서 VM 접속은 포트포워딩 필요.
* Bridged: VM이 동일 LAN의 독립 호스트처럼 동작. 다른 장치에서 직접 접속 가능.
* Host‑only: 호스트와 VM만 통신. 외부망 차단된 격리형 실습에 적합.

**3. 빠른 설치 체크리스트**
1) vCPU 2개, RAM 2–4GB, 디스크 20GB+ 구성
2) ISO 연결 후 부팅 → 언어/키보드/네트워크 설정
3) 사용자/비밀번호 생성, OpenSSH 서버 설치 선택
4) 설치 완료 후 ISO 분리 및 재부팅

### 원격 접속: PuTTY로 SSH 연결
* 호스트에서 PuTTY 실행 → VM의 IP 입력 → OpenSSH 서버가 켜져 있어야 함.
* 계정/비밀번호로 접속 후, `whoami`, `uname -a`, `ip addr`로 기본 상태 확인.
* 키 기반 접속: PuTTYgen으로 키 생성 → 서버 `~/.ssh/authorized_keys` 등록 → PuTTY에서 PPK 지정.
