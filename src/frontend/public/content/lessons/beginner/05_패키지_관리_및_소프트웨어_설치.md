### 패키지 매니저와 저장소(Repository)
> 📦 리눅스에서 소프트웨어를 설치하는 방식은 Windows와 다릅니다. 인터넷에서 `.exe` 파일을 받아 설치하는 대신, 대부분 **패키지 매니저**를 통해 공식 **저장소(Repository)**에 있는 소프트웨어를 설치합니다.

* **패키지(Package)**: 컴파일된 프로그램, 설정 파일, 의존성 정보 등을 하나로 묶어놓은 설치 파일 묶음입니다.
* **저장소(Repository)**: 이 패키지들이 모여있는 거대한 온라인 창고입니다.
* **패키지 매니저(Package Manager)**: 저장소에서 원하는 패키지를 찾아, 다른 프로그램과의 의존성을 자동으로 해결하며 안전하게 설치/업데이트/제거해주는 프로그램입니다. (예: `apt`, `yum`, `dnf`)

---

### Debian/Ubuntu 계열: `apt` 명령어
**1. `apt update` : 패키지 목록 갱신**
* 설치나 업그레이드 전, 내 컴퓨터가 저장소의 최신 패키지 정보를 받아오도록 목록을 동기화하는 작업입니다. **가장 먼저 실행해야 할 명령어입니다.**
```bash
$ sudo apt update
Hit:1 http://kr.archive.ubuntu.com/ubuntu jammy InRelease
Get:2 http://kr.archive.ubuntu.com/ubuntu jammy-updates InRelease [119 kB]
... (중략) ...
Fetched 2,350 kB in 2s (1,226 kB/s)
Reading package lists... Done
```

**2. `apt upgrade` : 설치된 패키지 업그레이드**
* `update`로 받아온 최신 정보를 바탕으로, 현재 내 컴퓨터에 설치된 모든 패키지를 최신 버전으로 업그레이드합니다.
```bash
$ sudo apt upgrade
Reading package lists... Done
Building dependency tree... Done
The following packages will be upgraded:
  firefox libssl3 ...
... (중략) ...
Do you want to continue? [Y/n]
```

**3. `apt install [패키지명]` : 새 패키지 설치**
```bash
# htop 패키지 설치
$ sudo apt install htop
```

**4. `apt remove` vs `apt purge` : 패키지 제거**
* `remove`: 프로그램은 삭제하지만, 개인 설정 파일 등은 남겨둡니다.
* `purge`: 설정 파일을 포함한 모든 것을 완전히 삭제합니다.
```bash
# htop 프로그램만 삭제
$ sudo apt remove htop

# htop 프로그램과 모든 설정 파일까지 삭제
$ sudo apt purge htop
```

**5. `apt autoremove` : 불필요한 패키지 자동 제거**
* 다른 프로그램을 설치할 때 함께 설치되었지만, 이제는 더 이상 필요 없어진 의존성 패키지들을 자동으로 찾아서 제거해주는 유용한 명령어입니다.

### Red Hat/CentOS/Fedora 계열: `yum`, `dnf` 명령어
> 💡 `dnf`는 `yum`의 차세대 버전으로, 더 향상된 성능과 의존성 해결 능력을 제공합니다. 최신 Red Hat 계열 배포판에서는 `yum` 명령어가 `dnf`를 실행하도록 연결되어 있는 경우가 많아, 두 명령어의 사용법은 거의 동일합니다.

**1. `dnf/yum search [패키지명]` : 패키지 검색**
* 저장소에서 특정 키워드를 포함하는 패키지를 찾습니다.
```bash
# httpd (아파치 웹서버) 패키지 검색
$ sudo dnf search httpd
```

**2. `dnf/yum install [패키지명]` : 새 패키지 설치**
```bash
# httpd 패키지 설치
$ sudo dnf install httpd
```

**3. `dnf/yum remove [패키지명]` : 패키지 제거**
```bash
# httpd 패키지 제거
$ sudo dnf remove httpd
```

**4. `dnf/yum update` 또는 `upgrade` : 시스템 업데이트**
* `apt`와 달리, `yum`과 `dnf`는 목록 갱신과 실제 업그레이드가 한번에 이루어집니다.
```bash
# 특정 패키지만 업데이트
$ sudo dnf update httpd

# 시스템에 설치된 모든 패키지를 최신 버전으로 업데이트
$ sudo dnf upgrade
```

**5. 기타 유용한 명령어**
```bash
# 설치된 패키지 목록 보기
$ dnf list installed

# 특정 패키지의 상세 정보 보기
$ dnf info httpd

# 불필요한 의존성 패키지 자동 제거
$ sudo dnf autoremove
```

### RPM 로컬 저장소(Repository) 간단 구축
> 인터넷이 제한된 환경에서 USB/디렉토리를 저장소로 사용해 설치/업데이트를 수행합니다.

**1) 패키지 수집 디렉토리 준비**
```bash
sudo mkdir -p /opt/localrepo
sudo cp /media/usb/*.rpm /opt/localrepo/
```

**2) 메타데이터 생성 (createrepo)**
```bash
sudo dnf install -y createrepo
sudo createrepo /opt/localrepo
```

**3) repo 파일 생성**
`/etc/yum.repos.d/local.repo`
```ini
[localrepo]
name=Local RPM Repo
baseurl=file:///opt/localrepo
enabled=1
gpgcheck=0
```

이후 `dnf clean all && dnf makecache`로 캐시를 갱신하고, `dnf install 패키지명`으로 설치를 검증합니다.

> 참고: Debian/Ubuntu에서도 `file://` 소스 라인을 `sources.list`에 추가해 로컬 패키지 풀을 활용할 수 있으나, 체계적 오프라인 미러는 `apt-mirror`, `reprepro` 등을 사용합니다.
