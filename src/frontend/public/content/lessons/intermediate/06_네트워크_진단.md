### 네트워크 기초 요약
* OSI 7계층: 물리 → 데이터링크 → 네트워크 → 전송 → 세션 → 표현 → 응용
* HTTP: 기본 메서드(GET/POST/PUT/DELETE), 상태코드(200/301/404/500)
* DNS: 도메인→IP 매핑, A/AAAA/CNAME/MX 레코드, 재귀/권한 서버

### 네트워크 설정 확인: `ip` 와 `ifconfig`
> 💡 `ip`는 최신 리눅스 배포판의 표준 네트워크 설정 도구이며, `ifconfig`는 구버전에서 사용되던 명령어입니다. 가급적 `ip` 명령어 사용을 권장합니다.

**1. `ip addr` : IP 주소 및 네트워크 인터페이스 확인**
```bash
$ ip addr
1: lo: <LOOPBACK,UP,LOWER_UP> mtu 65536 qdisc noqueue state UNKNOWN group default qlen 1000
    link/loopback 00:00:00:00:00:00 brd 00:00:00:00:00:00
    inet 127.0.0.1/8 scope host lo
       valid_lft forever preferred_lft forever
2: eth0: <BROADCAST,MULTICAST,UP,LOWER_UP> mtu 1500 qdisc fq_codel state UP group default qlen 1000
    link/ether 00:15:5d:01:0a:b1 brd ff:ff:ff:ff:ff:ff
    inet 172.29.87.15/20 brd 172.29.95.255 scope global eth0
       valid_lft forever preferred_lft forever
```
→ `eth0` 인터페이스에 할당된 IP 주소가 `172.29.87.15`임을 확인할 수 있습니다.

**2. `ping` : 네트워크 연결 테스트**
* 특정 서버나 IP 주소와 내 컴퓨터 간의 네트워크가 정상적으로 연결되어 있는지 확인합니다.

### 경로 및 DNS 확인: `traceroute`, `dig`, `nslookup`
```bash
# 패킷이 목적지까지 가는 라우팅 경로 확인
traceroute 8.8.8.8

# 특정 레코드 질의 (A, MX 등)
dig A example.com +short
nslookup -type=MX example.com
```

### 포트 및 연결 상태 확인: `netstat` 와 `ss`
> 💡 `ss`는 `netstat`을 대체하는 최신 명령어로, 더 빠르고 상세한 정보를 제공합니다. 가급적 `ss` 사용을 권장합니다.

**`ss` 또는 `netstat` : 열려있는 포트 및 연결 상태 확인**
* 어떤 프로그램이 어떤 포트를 사용해서 외부와 통신하고 있는지 확인할 수 있습니다. 서버의 방화벽 문제를 진단할 때 필수적입니다.
* **주요 옵션 조합**: `-t` (TCP), `-u` (UDP), `-l` (Listening, 연결 대기중인 포트), `-n` (이름 대신 숫자(IP)로 표시), `-p` (프로그램 이름 표시)
```bash
# 현재 시스템에서 열려있는 모든 TCP/UDP 포트를 프로그램 정보와 함께 확인
$ sudo ss -tulnp

# 출력 예시
# State    Recv-Q   Send-Q     Local Address:Port      Peer Address:Port   Process
# LISTEN   0        128            0.0.0.0:22             0.0.0.0:*       users:(("sshd",pid=987,fd=3))
# LISTEN   0        511            127.0.0.1:631            0.0.0.0:*       users:(("cupsd",pid=789,fd=7))
```
→ `sshd` 프로그램이 22번 포트를, `cupsd` 프로그램이 631번 포트를 사용하며 외부의 연결을 기다리고 있음(`LISTEN`)을 의미합니다.

### HTTP 빠른 점검: `curl`
```bash
# 헤더만 확인하여 서버 응답 상태 보기
curl -I http://localhost

# HTTPS 인증서 체인/만료일 확인(요약)
curl -Iv https://example.com 2>&1 | grep -i "expire\|subject\|issuer"
```
