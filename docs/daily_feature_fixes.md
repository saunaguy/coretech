# 데일리 기능 수정 내역

이 문서는 데일리 퀴즈 기능에 적용된 수정 사항을 요약합니다.

## 문제 1: 데일리 퀴즈가 화면에 표시되지 않는 현상

*   **증상:** 데일리 퀴즈 목록과 개별 퀴즈가 프론트엔드에 표시되지 않았습니다.
*   **원인:** 백엔드 API 코드(`main.py`)가 데이터베이스의 `daily_tests` 테이블을 조회할 때 잘못된 클래스 이름(`DBDailyTest`가 아닌 `DailyTest`를 사용해야 함)을 사용했습니다. 데이터는 데이터베이스에 있었지만 API가 이를 올바르게 가져오지 못했습니다.
*   **해결:** `backend_src/main.py`에서 `DBDailyTest`의 모든 항목을 `db.py`에 정의된 실제 클래스 이름인 `DailyTest`로 수정했습니다.

## 문제 2: 데일리 세트 페이지의 UI 텍스트 오버플로우

*   **증상:** `/daily/sets` 페이지의 버튼("데일리로 돌아가기" 및 "전체 세트 보기") 내의 텍스트가 작은 화면 크기에서 너무 커서 버튼 컨테이너를 벗어났습니다.
*   **원인:** 버튼에 반응형 글꼴 크기가 적용되지 않았습니다.
*   **해결:** `frontend/app/daily/sets/page.tsx`의 버튼에 반응형 텍스트 크기 클래스(`text-xs sm:text-sm`)를 추가했습니다. 이렇게 하면 매우 작은 화면에서 글꼴 크기가 작아져 텍스트 오버플로우를 방지할 수 있습니다.
