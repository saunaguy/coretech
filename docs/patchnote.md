## v1.1 — 2025-10-10
### ✅ 패치 내역 (ver 1.1)
- **QnA 라우트 통합:** `qnatest` → `qna` (내비게이션/링크/SSR 모두 정합성 확보)

### Board 쪽 버그 수정
- **댓글 API 응답 안정화:** HTML 반환 이슈 제거, **항상 JSON** 반환
- **응답 스키마 확장:** `author`, `is_accepted` 필드 추가
- **클라이언트 파서 보강:** `204 No Content` 수신 시 예외 처리 로직 반영
- **삭제 기능 추가:** API + UI 연동, 삭제 후 목록 리프레시/토스트 알림
- **권한 검증 보정:** 존재하지 않는 `author_id` 대신 **`user_id` 기준**으로 검증
- **(각종 버그 수정했단 의미)**

### 🖼️ UI/UX
