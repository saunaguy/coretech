# Coretech — 홈/네비 구조 (for Codex)

## 목표
- 홈 화면에 **공지사항** + **간단한 테스트(진행률)** 모듈을 배치.
- 상단 카테고리: **Linux 기초 / 서버 관리 / 네트워크 / 커뮤니티** 카드 진입.
- 자유게시판(`/board`), Q&A(`/qna`)는 상단 네비/카드로 이동. 내부 구현은 `ai-prompt-lab (4)` 스타일.

## 네비게이션
- 상단 바: `Linux 기초 | 게시판 | Q&A | 소개 | 로그인`
- 홈 `/` 섹션 배치:
  1) **Hero**: 제목(“리눅스, 서버, 네트워크 전문 학습 플랫폼”), 서브텍스트
  2) **카테고리 4타일**  
     - Linux 기초 → `/linux`  
     - 서버 관리 → `/server`  
     - 네트워크 → `/network`  
     - 실습 → `/practice`  
       - 커뮤니티는 유지(`/community`), 리다이렉트 제거
  3) **최근 활동** 그리드(2열)  
     - 좌측: **공지사항** 카드 리스트(배지: 중요/공지/업데이트/이벤트) + “더보기” → `/notice`  
     - 우측: **간단한 테스트**(카테고리별 진행률 바) + “더보기” → `/quiz`

## 라우트 개요
- `/` 홈 (이 문서 레이아웃 기준)
- `/community` (탭: 게시판/Q&A/공지) — 내부는 `ai-prompt-lab (4)` 가이드, 리다이렉트 없음
- `/board` 자유게시판 목록/상세/작성
- `/qna` Q&A 목록/상세/작성
- `/notice` 공지 목록/상세
- `/daily` 데일리 테스트 목록/상세
- `/lessons/*` 강의 인덱스/콘텐츠
- `/practice` 실습 랜딩(카드/필터/검색)
 

## 현재 상황 요약 (2025-09-04)
- 홈 카테고리 그리드의 "커뮤니티" 타일을 "실습"으로 교체하여 `/practice`로 이동
- `/practice` 페이지는 제공된 디자인(필터/검색/카드/진행률)으로 구성, 전역 헤더만 표시
 
- 상세 페이지의 "실습 연결하기" 버튼은 Notion 링크로 이동하도록 설정
- 커뮤니티는 기존 경로 유지(`/community`), 리다이렉트 제거
- UI 컴포넌트 보강: `badge`, `input`, `progress`, `skeleton` 추가, `user-menu`/`auth` 유틸 추가
- 패키지 업데이트(주요 UI/유틸 설치). `vaul`은 React 19와 충돌로 미설치

## 디자인 원칙
- `ai-prompt-lab (4)`의 카드/배지/프로그레스 바 패턴 준수
- 반응형(모바일: 1열 → 공지/테스트 순서 스택)
- 서버 컴포넌트 우선, 데이터는 내부 API(`/api/v1/...`)로 페치
