## 📂 저장소 개요
- **프로젝트명**: Coretech Linux 교육 사이트
- **목표**: 리눅스 강의를 웹사이트 형태로 제공하여, 교육자와 학습자가 손쉽게 접근할 수 있는 플랫폼 구축
- **구성요소**
  - 강의 콘텐츠 문서화
  - 디자인 적용 (`ai.prompt-lab` 기반)
  - 진행 로그 관리
  - 향후 기능 확장(검색, 실습 코드, 자동 배포 등)

---

## 📄 주요 문서 안내

| 파일명 | 설명 |
|--------|------|
| `index.md` | (현재 문서) 프로젝트 개요와 `docs/` 전체 문서 안내 |
| `progress.md` | 진행 상황을 기록하는 로그 테이블 (날짜, 작업, 담당자, 상태) |
| `design.md` | 사이트 레이아웃 및 디자인 계획, `ai.prompt-lab` 디자인 적용 방안 포함 |
| (추가 예정) | 설치 가이드, 강의 목차, API 연동 가이드 등 |

---

## 🎨 디자인 적용 (`ai.prompt-lab`)
- `ai.prompt-lab`에서 실험된 디자인 아이디어를 본 프로젝트에 반영할 예정
- 주요 반영 요소:
  - 레이아웃 (메인 페이지, 강의 세부 페이지)
  - 색상/폰트 스타일
  - 반응형 UI
  - 코드 블록 및 예제 표시 방식

---

## 🤖 AI 활용 목적
이 `index.md`는 AI에게 맥락을 제공하기 위해 작성되었습니다.  
- AI가 프로젝트 구조와 목적을 한눈에 파악하도록 함  
- `progress.md`, `design.md` 등의 세부 문서를 AI에게 추가로 제공할 때 기준점 역할을 함  
- 새로운 기획/코드/문서 자동화를 요청할 때 참고 자료로 활용
