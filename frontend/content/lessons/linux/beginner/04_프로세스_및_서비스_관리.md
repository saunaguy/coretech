### 프로세스 모니터링: 내 컴퓨터는 지금 무슨 일을 하고 있을까?
> 🖥️ 프로세스(Process)란 현재 메모리에서 실행되고 있는 프로그램을 의미합니다. 리눅스 시스템 관리의 핵심은 바로 이 프로세스들을 효과적으로 감시하고 제어하는 것입니다.

**1. `ps` (Process Status) : 현재 프로세스 목록 스냅샷**
* 현재 시점의 프로세스 상태를 사진 찍듯이 보여주는 명령어입니다. 가장 많이 사용하는 옵션 조합은 `aux` 입니다.
```bash
# 현재 시스템에서 실행 중인 모든 프로세스를 상세 정보와 함께 출력
$ ps aux

# 출력 예시
# USER       PID %CPU %MEM    VSZ   RSS TTY      STAT START   TIME COMMAND
# root         1  0.0  0.1 168960 11392 ?        Ss   Aug24   0:02 /sbin/init
# user      1234  0.2  0.5 250340 41332 ?        Sl   Aug24   2:30 /usr/lib/firefox/firefox
# user      5678  0.0  0.0  14884  3328 pts/0    Ss   09:15   0:00 /bin/bash
```
<details>
<summary>주요 컬럼 의미</summary>

• USER: 프로세스 소유자
• PID: 프로세스 ID
• %CPU / %MEM: CPU/메모리 사용률
• VSZ/RSS: 가상/실주 메모리 사용량(KB)
• STAT: 상태(S,R,D,T,Z 등)와 플래그(+ 전면, l 멀티스레드 등)
• START/TIME: 시작시각/누적 CPU 시간
• COMMAND: 실행 명령어

</details>

**2. `top` : 실시간 프로세스 모니터링**
* 시스템의 상태를 동영상처럼 실시간으로 보여줍니다. CPU나 메모리 점유율이 높은 프로세스를 찾아낼 때 매우 유용합니다. (종료는 `q`키)
* **주요 키**: `top` 실행 중 `M`을 누르면 메모리 사용량 순, `P`를 누르면 CPU 사용량 순으로 정렬됩니다.

**3. `htop` : 더 강력하고 보기 편한 `top`**
* `top`의 업그레이드 버전으로, 컬러풀한 UI와 마우스 클릭, 쉬운 정렬/검색/종료 기능을 제공하여 훨씬 직관적입니다. (기본 설치가 안된 경우 `sudo apt install htop` 등으로 설치 필요)

### 프로세스 제어 및 작업 관리
**1. `kill` & `pkill` : 프로세스에 신호 보내기**
* `kill`은 특정 PID(프로세스 ID)를 지정하여 신호를 보내고, `pkill`은 프로세스 이름을 지정하여 관련된 모든 프로세스에 신호를 보냅니다. 가장 흔한 신호는 프로세스를 종료시키는 것입니다.
> 💡 **주요 신호(Signal)의 이해**
> `SIGTERM (15)`: 프로세스에게 정상적으로 종료하라고 정중히 요청합니다. (기본값)
> `SIGKILL (9)`: 프로세스를 강제로 즉시 종료시킵니다. 프로그램이 응답하지 않을 때 사용합니다.

```bash
# 1. 종료할 프로세스의 PID 찾기 (예: firefox)
$ ps aux | grep firefox
user      1234  0.2  0.5 250340 41332 ?   Sl   Aug24   2:30 /usr/lib/firefox/firefox

# 2. kill 명령어로 PID를 지정하여 종료 (정상 종료 요청)
$ kill 1234

# 3. pkill 명령어로 이름을 지정하여 강제 종료
$ pkill -9 firefox
```

**2. 작업 관리 (Job Control)**
* 하나의 터미널에서 여러 작업을 동시에 관리하는 기술입니다. 시간이 오래 걸리는 작업을 백그라운드에서 실행하고, 다른 작업을 포그라운드에서 계속할 수 있습니다.
* `&` (앰퍼샌드): 명령어 뒤에 붙이면 해당 작업을 백그라운드에서 실행합니다.
* `jobs`: 현재 실행 중이거나 멈춘 백그라운드 작업 목록을 보여줍니다.
* `fg %[작업번호]`: 백그라운드 작업을 다시 포그라운드로 가져옵니다.
* `bg %[작업번호]`: 멈춰있는 작업을 백그라운드에서 다시 실행합니다.
* `Ctrl + Z`: 현재 포그라운드에서 실행 중인 작업을 일시 정지(Stopped) 상태로 만듭니다.
```bash
# 1. 500초 동안 대기하는 작업을 백그라운드로 실행
$ sleep 500 &
[1] 6789

# 2. 현재 작업 목록 확인
$ jobs
[1]+  Running                 sleep 500 &

# 3. 포그라운드에서 다른 작업 수행 가능
$ echo "Hello World"
Hello World

# 4. 1번 작업을 다시 포그라운드로 가져오기
$ fg %1
sleep 500
# (이제 터미널은 sleep 500이 끝날 때까지 멈춤)
# 여기서 Ctrl+Z를 눌러 작업을 일시정지

[1]+  Stopped                 sleep 500

# 5. 멈춘 1번 작업을 백그라운드에서 다시 실행
$ bg %1
[1]+  sleep 500 &
```

### 서비스(데몬) 관리: 백그라운드의 일꾼들
> ⚙️ 서비스 또는 데몬(Daemon)은 시스템 백그라운드에서 실행되며 웹 서버, 데이터베이스 등과 같이 특정 기능을 계속 제공하는 프로그램입니다. 최신 리눅스에서는 `systemd`라는 시스템 관리자가 이 서비스들을 제어하며, 우리는 `systemctl` 명령어로 `systemd`에게 일을 시킵니다.

**1. `systemctl status` : 서비스 상태 확인**
* 가장 기본이며, 서비스가 현재 실행 중인지, 오류는 없는지, 부팅 시 자동으로 실행되도록 설정되어 있는지 등 상세한 정보를 보여줍니다.
```bash
# sshd (원격 접속) 서비스의 상태 확인
$ sudo systemctl status sshd

# 출력 예시
● ssh.service - OpenBSD Secure Shell server
     Loaded: loaded (/lib/systemd/system/ssh.service; enabled; vendor preset: enabled)
     Active: active (running) since Mon 2025-08-25 09:10:15 KST; 1h 2min ago
       Docs: man:sshd(8)
             man:sshd_config(5)
   Main PID: 987 (sshd)
      Tasks: 1 (limit: 9451)
     Memory: 8.2M
        CPU: 102ms
     CGroup: /system.slice/ssh.service
             └─987 sshd: /usr/sbin/sshd -D [listener] 0 of 10-100 startups
```
→ `Active: active (running)`는 현재 실행 중임을, `enabled`는 부팅 시 자동 시작됨을 의미합니다.

**2. `start`, `stop`, `restart` : 서비스 즉시 제어**
* 현재 세션에서 서비스를 시작, 중지, 또는 재시작합니다. 설정 파일을 변경했을 때 주로 `restart`를 사용합니다.
```bash
# nginx 웹서버 시작
sudo systemctl start nginx

# nginx 웹서버 중지
sudo systemctl stop nginx

# nginx 설정 변경 후 재시작
sudo systemctl restart nginx
```

**3. `enable`, `disable` : 부팅 시 자동 시작 설정**
* 서비스를 부팅 시 자동으로 시작하게 하거나(enable), 못하게(disable) 설정합니다. 현재 실행 상태를 바꾸지는 않습니다.
```bash
# 부팅 시 nginx 자동 시작 설정
sudo systemctl enable nginx

# 부팅 시 nginx 자동 시작 해제
sudo systemctl disable nginx

# Tip: 활성화와 동시에 바로 시작하기
sudo systemctl enable --now nginx
```
