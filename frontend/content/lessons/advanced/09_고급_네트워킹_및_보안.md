### 방화벽 관리 (Firewall)
* iptables: 전통적인 리눅스 방화벽 도구. 체인(INPUT, OUTPUT, FORWARD)과 규칙(Rule) 기반으로 패킷 필터링.
* firewalld: 동적 방화벽 관리 데몬. Zone 기반으로 네트워크 연결을 신뢰 수준에 따라 관리하여 규칙 설정이 용이.
```bash
# firewalld 기본 조작
sudo systemctl enable --now firewalld
sudo firewall-cmd --get-active-zones
sudo firewall-cmd --zone=public --add-service=http --permanent
sudo firewall-cmd --reload

# 특정 포트 허용
sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent
sudo firewall-cmd --reload
```

### 원격 접속 및 파일 전송
* SSH (Secure Shell): 암호화된 원격 터미널 접속을 제공. 비밀번호 인증 및 공개키/개인키 기반 인증 방식 지원.
* SCP (Secure Copy): SSH 프로토콜을 사용하여 안전하게 파일을 복사.
* Rsync (Remote Sync): 효율적인 파일 동기화 도구. 변경된 부분만 전송하여 대역폭을 절약.
```bash
# 공개키 배포(예: OpenSSH)
ssh-copy-id user@server

# rsync 차등 동기화 예시
rsync -avz --delete ./site/ user@server:/var/www/site/
```

### 사용자/그룹 심화 관리
* /etc/passwd: 사용자 계정 정보 저장 (사용자 이름, UID, GID, 홈 디렉토리, 기본 셸). 
* /etc/shadow: 암호화된 사용자 비밀번호 및 만료 정책 저장. 보안을 위해 root만 읽기 가능.
* usermod: 기존 사용자의 속성(홈 디렉토리, 그룹 등)을 변경.
```bash
# 만료 정책 설정 예시
sudo chage -M 90 -W 7 alice

# sudo 권한 부여(배포판에 따라 wheel/sudo 그룹)
sudo usermod -aG wheel alice
```

### SELinux 개요 및 관리
```bash
# 현재 모드 확인/일시 변경
getenforce
sudo setenforce 0   # Permissive

# 컨텍스트 확인/복원
ls -Z /var/www/html
sudo restorecon -Rv /var/www/html

# 포트 컨텍스트 부여(예: httpd가 8080 사용)
sudo semanage port -a -t http_port_t -p tcp 8080
```

### NIC 본딩/팀(bonding/teaming)과 VLAN
```bash
# VLAN 인터페이스 예 (ip 명령)
sudo ip link add link eth0 name eth0.10 type vlan id 10
sudo ip addr add 192.168.10.2/24 dev eth0.10
sudo ip link set eth0.10 up

# RHEL 계열: nmcli로 본딩 구성(예)
sudo nmcli con add type bond ifname bond0 mode active-backup
sudo nmcli con add type ethernet ifname eth1 master bond0
sudo nmcli con add type ethernet ifname eth2 master bond0
sudo nmcli con mod bond0 ipv4.addresses 192.168.1.20/24 ipv4.method manual
sudo nmcli con up bond0
```

### SSH 하드닝 빠른 점검
* 비밀번호 로그인 비활성화, 키 기반만 허용
* 루트 직접 로그인 금지(`PermitRootLogin no`)
* 포트 변경, Fail2ban/NFT 기반 차단
```bash
sudoedit /etc/ssh/sshd_config
# PasswordAuthentication no
# PermitRootLogin no
sudo systemctl restart sshd
```
