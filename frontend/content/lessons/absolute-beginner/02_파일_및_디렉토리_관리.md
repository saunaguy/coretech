### 리눅스 파일 시스템 구조 (FHS)
리눅스의 모든 파일과 디렉토리는 최상위 지점인 루트(Root) 디렉토리(`/`)로부터 시작하는 거대한 트리(Tree) 구조로 이루어져 있습니다. 각 디렉토리는 파일 시스템 계층 구조 표준(FHS, Filesystem Hierarchy Standard)에 따라 저마다의 역할과 목적을 가집니다.
**/bin** (Binaries)
* 사용자가 사용하는 필수적인 기본 명령어(`ls`, `cp`, `mv` 등)가 들어있습니다.
**/sbin** (System Binaries)
* 시스템 관리자(root)가 사용하는 시스템 관리용 명령어(`reboot`, `ifconfig` 등)가 위치합니다.
**/etc** (Etcetera)
* 시스템 전체의 환경 설정 파일들이 모여있는 핵심 디렉토리입니다.
**/home**
* 일반 사용자들의 개인 작업 공간인 홈 디렉토리가 생성되는 곳입니다. (예: `/home/user`)
**/root**
* 시스템 최고 관리자인 `root` 사용자의 전용 홈 디렉토리입니다.
**/usr** (Unix System Resources)
* 사용자가 사용하는 대부분의 프로그램과 추가 데이터(라이브러리, 문서 등)가 설치되는 공간입니다.
**/var** (Variable)
* 시스템 운영 중 수시로 내용이 변하는 파일들, 특히 로그(log) 파일이 저장되는 디렉토리입니다.
**/tmp** (Temporary)
* 잠시 사용하고 버릴 임시 파일들을 저장하는 공간입니다. 재부팅 시 내용이 사라질 수 있습니다.
**/boot**
* 리눅스 커널과 부팅에 필요한 핵심 파일들이 들어있습니다.
**/dev** (Devices)
* 시스템에 연결된 하드웨어 장치들을 파일 형태로 관리하는 특별한 디렉토리입니다.

### 파일 및 디렉토리 조작
**1. `touch` : 빈 파일 생성 및 시간 정보 업데이트**
* 주로 빈 파일을 만들거나, 이미 있는 파일의 최종 수정 시간을 현재 시간으로 업데이트할 때 사용합니다.
```bash
# 1. 빈 파일 하나 생성
touch report.txt

# 2. 여러 개의 빈 파일 동시에 생성
touch index.html style.css script.js

# 3. 이미 있는 파일의 수정 시간을 현재로 변경
touch report.txt
```
**2. `mkdir` (Make Directory) : 디렉토리 생성**
* 새로운 디렉토리(폴더)를 만듭니다.
* **주요 옵션**: `-p` : 상위 디렉토리가 없을 경우, 그 경로까지 자동으로 함께 생성합니다. 매우 유용합니다.
```bash
# 1. 디렉토리 하나 생성
mkdir backup

# 2. 여러 디렉토리 동시에 생성
mkdir images videos audio

# 3. 하위 디렉토리까지 한번에 생성 (-p 옵션)
mkdir -p project/src/components
```
**3. `cp` (Copy) : 파일 및 디렉토리 복사**
* **주요 옵션**: 
* `-r` : 디렉토리를 복사할 때 반드시 필요한 옵션으로, 내부의 모든 파일과 하위 디렉토리까지 재귀적으로 복사합니다.
* `-i` : 덮어쓰기 전에 사용자에게 확인 질문을 합니다. (실수 방지)
```bash
# 1. 파일을 특정 디렉토리로 복사
cp report.txt backup/

# 2. 파일을 복사하며 이름 변경
cp report.txt report_backup.txt

# 3. 디렉토리 전체를 복사 (-r 옵션 필수)
cp -r project/ project_backup/
```
**4. `mv` (Move) : 파일 및 디렉토리 이동 또는 이름 변경**
* 파일/디렉토리를 다른 위치로 옮기거나, 이름을 바꿀 때 사용합니다.
```bash
# 1. 파일 이름 변경
mv old_name.txt new_name.txt

# 2. 디렉토리 이름 변경
mv my_folder/ my_app/

# 3. 파일을 특정 디렉토리로 이동
mv report.txt backup/

# 4. 여러 파일을 특정 디렉토리로 한번에 이동
mv image1.jpg photo.png videos/
```
**5. `rm` (Remove) : 파일 및 디렉토리 삭제**
> ⚠️ **경고: `rm` 명령어는 휴지통이 없습니다. 삭제된 파일은 복구할 수 없으므로 사용에 각별한 주의가 필요합니다.**

* **주요 옵션**: 
* `-r` : 디렉토리를 삭제할 때 필요한 옵션으로, 내부의 모든 것을 재귀적으로 삭제합니다.
* `-f` : 사용자에게 묻지 않고 강제로 삭제를 진행합니다. (`-i` 옵션을 무시합니다.)
* `-i` : 삭제하기 전에 사용자에게 확인 질문을 합니다. (안전장치)
```bash
# 1. 파일 삭제 (안전하게 물어보도록 -i 옵션 사용 추천)
rm -i temp.log

# 2. 디렉토리와 그 안의 모든 내용 삭제
rm -r old_project/

# 3. 묻지도 따지지도 않고 강제 삭제 (!!매우 위험!!)
# rm -rf /경로/잘못/지정하면/시스템/전체가/삭제될수도/있음
```

### 파일 내용 확인
**1. `cat` (Concatenate) : 파일 내용 전체 보기**
* 파일의 전체 내용을 한번에 화면에 출력합니다. 짧은 파일 내용을 확인할 때 유용합니다.
* **주요 옵션**: `-n` : 모든 줄에 번호를 붙여서 출력합니다.
```bash
# 1. 파일 내용 보기
cat report.txt

# 2. 여러 파일을 이어서 보기
cat file1.txt file2.txt

# 3. 줄 번호와 함께 보기
cat -n report.txt
```
**2. `head` & `tail` : 파일의 앞/뒤 부분만 보기**
* `head`는 파일의 첫 부분, `tail`은 파일의 마지막 부분을 보여줍니다. 용량이 큰 로그 파일을 확인할 때 유용합니다.
* **주요 옵션**: 
* `-n [숫자]` : 지정한 숫자만큼의 줄을 보여줍니다. (기본값: 10줄)
* `-f` (`tail` 전용) : 파일의 내용이 추가될 때마다 실시간으로 화면에 계속 출력합니다. (로그 감시 필수 기능)
```bash
# 1. 파일의 첫 5줄 보기
head -n 5 /var/log/syslog

# 2. 파일의 마지막 20줄 보기
tail -n 20 /var/log/syslog

# 3. 로그 파일 실시간으로 감시하기 (Ctrl+C로 종료)
tail -f /var/log/syslog
```
**3. `less` : 스크롤하며 파일 내용 보기 (가장 추천)**
* `cat`과 달리 파일 전체를 불러오지 않고 현재 보이는 부분만 읽어와서 매우 빠릅니다. 용량이 큰 파일을 볼 때 가장 효율적이며, 위/아래 스크롤, 검색 등 다양한 기능이 있습니다.
* **주요 키**: 
* 방향키, PageUp/Down: 페이지 이동
* `/ [검색어]`: 아래 방향으로 텍스트 검색
* `n`: 다음 검색 결과로 이동
* `q`: 종료
```bash
# 1. 파일 열기
less large_log_file.log

# 2. 다른 명령어의 결과를 less로 넘겨서 보기
ls -al | less
```
### 심화 학습: 와일드카드와 명령어 옵션 활용
> ✨ 단순한 파일 하나가 아닌, 여러 파일을 효율적으로 다루는 것은 매우 중요합니다. 와일드카드를 사용하면 작업 효율을 극대화할 수 있습니다.

**1. 와일드카드(Wildcard)란?**
* 이름이 비슷한 여러 파일을 한 번에 선택하기 위해 사용하는 특수 문자입니다.
* `*` (별표): 0개 이상의 모든 문자를 의미합니다. (가장 많이 사용)
* `?` (물음표): 정확히 1개의 문자를 의미합니다.
```bash
# .txt로 끝나는 모든 파일 선택
ls *.txt

# log_2024_08_25.txt, log_2024_08_26.txt 등을 모두 선택
ls log_*

# fileA.txt, fileB.txt, fileC.txt는 선택되지만, file10.txt는 선택되지 않음
ls file?.txt
```

### 파일시스템 개념: inode와 링크
> 파일의 ‘이름’과 ‘실체(데이터)’는 분리되어 관리됩니다. 실체에 대한 메타데이터가 inode입니다.

**inode란?**
* 파일의 소유자, 권한, 타임스탬프, 데이터 블록 위치 등을 저장하는 메타데이터 번호.
* 같은 내용을 다른 이름으로 가리키는 하드링크를 만들면 inode를 공유합니다.

**하드링크 vs 심볼릭링크**
```bash
# 하드링크: 같은 inode를 가리킴 (같은 파일)
ln report.txt report_hard.txt

# 심볼릭링크: 경로를 가리키는 별칭 (inode 다름)
ln -s report.txt report_symlink.txt

# inode 확인
ls -li report*
```
* 하드링크는 같은 파일시스템 내에서만 가능, 디렉토리에는 제한적. 심볼릭링크는 경로만 가리켜 제약이 적음.

### 마운트/언마운트 기초
* 리눅스는 드라이브 문자가 아니라, 디렉토리 트리에 파일시스템을 ‘마운트’하여 붙입니다.
```bash
# 파일시스템 목록
lsblk -f

# 임시 마운트 (예: /dev/sdb1 → /mnt/usb)
sudo mkdir -p /mnt/usb
sudo mount /dev/sdb1 /mnt/usb

# 언마운트
sudo umount /mnt/usb
```
**부팅 시 자동 마운트: /etc/fstab**
```bash
# 장치의 UUID 확인
blkid

# fstab 예시 (root 권한으로 편집)
UUID=xxxx-xxxx /mnt/usb  vfat  defaults,noauto  0  0
```
