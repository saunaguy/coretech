# 2-3-7: 커널 로그/모듈 (`dmesg`, `lsmod`, `modprobe`)

리눅스 커널은 운영체제의 핵심으로, 하드웨어를 제어하고 시스템의 모든 자원을 관리합니다. 커널과 직접적으로 상호작용하는 방법을 아는 것은 시스템의 문제를 진단하고 해결하는 데 필수적입니다.

## 1. `dmesg`: 커널의 메시지 버퍼 보기

- **기능**: `dmesg` (display message or driver message) 명령어는 커널 링 버퍼(kernel ring buffer)에 저장된 메시지를 출력합니다. 이 버퍼에는 시스템 부팅 과정에서 출력되는 모든 메시지, 하드웨어 인식 및 드라이버 로딩 상태, 하드웨어 오류 등 커널 레벨의 중요한 정보가 기록됩니다.

- **주요 사용 사례**:
    - **부팅 문제 진단**: 부팅이 실패하거나 특정 장치가 동작하지 않을 때 `dmesg` 로그를 확인하여 원인을 찾을 수 있습니다.
    - **하드웨어 인식 확인**: 새로운 USB 장치나 디스크를 연결했을 때, 커널이 해당 장치를 제대로 인식했는지 확인합니다.
    - **오류 메시지 확인**: 디스크 I/O 오류, 네트워크 인터페이스 문제 등 하드웨어 관련 오류 메시지를 볼 수 있습니다.

### `dmesg` 사용법

- **전체 메시지 보기**:
  ```bash
  dmesg
  ```
  (출력 내용이 길기 때문에 보통 `less`와 함께 사용합니다: `dmesg | less`)

- **로그 수준(level)으로 필터링**:
  ```bash
  # 에러(err) 또는 경고(warn) 수준의 로그만 보기
  dmesg --level=err,warn
  ```

- **실시간으로 로그 확인**:
  ```bash
  dmesg --follow
  ```
  (새로운 커널 이벤트가 발생할 때마다 로그가 출력됩니다. `journalctl -kf`와 유사합니다.)

- **특정 문자열 검색**:
  ```bash
  # USB 관련 메시지 검색
  dmesg | grep -i usb

  # 디스크(sda) 관련 메시지 검색
  dmesg | grep sda
  ```

## 2. 커널 모듈 관리

리눅스 커널은 **모듈(Module)** 방식을 사용하여 필요할 때만 특정 기능을 동적으로 추가하거나 제거할 수 있습니다. 예를 들어, 특정 파일 시스템 지원, 암호화 알고리즘, 하드웨어 드라이버 등이 모듈 형태로 존재합니다. 이를 통해 커널의 크기를 작게 유지하고 유연성을 높일 수 있습니다.

### `lsmod`: 로드된 모듈 목록 보기

- **기능**: `lsmod` (list modules) 명령어는 현재 커널에 로드되어 있는 모듈의 목록을 보여줍니다.

- **출력 형식**:
  ```bash
  $ lsmod
  Module                  Size  Used by
  vboxguest             368640  6
  vboxsf                 49152  1
  # ... (기타 모듈)
  ```
  - `Module`: 모듈의 이름
  - `Size`: 모듈이 차지하는 메모리 크기 (바이트 단위)
  - `Used by`: 이 모듈을 사용하고 있는 다른 모듈의 수와 이름. 이 값이 0이 아니면 해당 모듈은 다른 모듈에 의해 사용되고 있으므로 안전하게 제거할 수 없습니다.

### `modprobe`: 모듈 로드 및 제거

- **기능**: `modprobe` (module probe)는 커널 모듈을 로드하거나 제거하는 지능적인 명령어입니다. `insmod`(삽입)나 `rmmod`(제거)와 같은 저수준 명령어와 달리, 모듈 간의 의존성을 자동으로 처리해주는 장점이 있습니다.

- **모듈 로드**:
  ```bash
  # 'e1000' 네트워크 드라이버 모듈을 로드
  sudo modprobe e1000
  ```
  만약 `e1000` 모듈이 다른 모듈을 필요로 한다면, `modprobe`는 해당 모듈을 먼저 로드합니다.

- **모듈 제거**:
  ```bash
  # 'e1000' 모듈을 제거
  sudo modprobe -r e1000
  ```
  (`-r` 또는 `--remove` 옵션을 사용합니다.)

- **모듈 정보 확인**:
  `modinfo` 명령어는 특정 모듈의 상세 정보를 보여줍니다.
  ```bash
  $ modinfo vboxguest
  filename:       /lib/modules/5.14.0-427.16.1.el9_4.x86_64/kernel/drivers/virt/vboxguest/vboxguest.ko.xz
  version:        6.1.50
  license:        GPL
  description:    Oracle VM VirtualBox Guest Additions for Linux
  # ... (기타 정보)
  ```

### 모듈 영구 로드

`modprobe`로 로드한 모듈은 재부팅하면 사라집니다. 시스템이 부팅될 때마다 특정 모듈을 자동으로 로드하려면 `/etc/modules-load.d/` 디렉터리 아래에 `.conf` 파일을 만들어 모듈 이름을 추가하면 됩니다.

- 예시: `/etc/modules-load.d/my-modules.conf`
  ```
  # 이 파일에 원하는 모듈 이름을 한 줄에 하나씩 추가
  e1000
  vboxsf
  ```

이처럼 커널 관련 명령어들은 시스템의 가장 낮은 수준에서 무슨 일이 일어나고 있는지 파악하고, 하드웨어와 직접 관련된 문제를 해결하는 데 매우 중요한 도구입니다.
