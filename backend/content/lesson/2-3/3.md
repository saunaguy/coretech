# 2-3-3: 런레벨과 `systemd` 타겟(Target)의 개념

리눅스 시스템은 여러 가지 운영 모드를 가집니다. 예를 들어, 일반적인 다중 사용자 그래픽 환경이 있는가 하면, 오직 텍스트 터미널만 제공하는 서버 환경, 또는 시스템 복구를 위한 최소한의 환경도 있습니다. 이처럼 시스템의 특정 운영 상태를 **런레벨(Runlevel)** 또는 **타겟(Target)**이라고 부릅니다.

## 1. 과거의 방식: `SysVinit`의 런레벨

`systemd`가 표준이 되기 전, `SysVinit` 시스템에서는 숫자로 된 런레벨을 사용했습니다. 이 개념은 여전히 비유적으로 사용되므로 알아두면 좋습니다.

- **런레벨 0**: 시스템 종료 (Halt)
- **런레벨 1**: 단일 사용자 모드 (Single-user mode). 시스템 복구 및 유지보수 작업에 사용됩니다.
- **런레벨 3**: 다중 사용자, 텍스트 모드. 네트워킹이 활성화된, GUI가 없는 서버의 표준 모드입니다.
- **런레벨 5**: 다중 사용자, 그래픽 모드. 일반적인 데스크톱 환경의 표준 모드입니다.
- **런레벨 6**: 시스템 재부팅 (Reboot)

과거에는 `init 3`와 같이 `init` 명령어로 런레벨을 변경했습니다.

## 2. 현대의 방식: `systemd`의 타겟(Target)

`systemd`는 런레벨의 개념을 **타겟(Target)**으로 대체하여 사용합니다. 타겟은 단순히 여러 서비스와 다른 유닛들을 그룹으로 묶어놓은 것입니다. 예를 들어, `graphical.target`은 GUI 환경에 필요한 모든 서비스들의 묶음입니다.

- **장점**:
    - **명시적**: `런레벨 5`보다 `graphical.target`이라는 이름이 훨씬 더 의미를 이해하기 쉽습니다.
    - **유연성**: 타겟은 다른 타겟을 포함(의존)하는 방식으로 유연하게 조합될 수 있습니다. 예를 들어, `graphical.target`은 `multi-user.target`의 모든 기능을 포함하면서 GUI 관련 서비스를 추가로 실행합니다.

### 런레벨과 타겟의 관계

`systemd`는 하위 호환성을 위해 기존 런레벨과 타겟을 다음과 같이 매핑해두었습니다.

| SysVinit 런레벨 | `systemd` 타겟 | 설명 |
| :---: | :--- | :--- |
| 0 | `poweroff.target` | 시스템 종료 |
| 1 | `rescue.target` | 구조 모드 (단일 사용자 모드와 유사) |
| 2, 3, 4 | `multi-user.target` | 다중 사용자, 텍스트 모드, 네트워킹 |
| 5 | `graphical.target` | 다중 사용자, 그래픽 모드, 네트워킹 |
| 6 | `reboot.target` | 시스템 재부팅 |

## 3. `systemctl`을 이용한 타겟 관리

`systemctl` 명령어를 통해 시스템의 기본 부팅 타겟을 확인하고, 현재 운영 모드를 변경할 수 있습니다.

- **`systemctl get-default`**: 부팅 시 기본적으로 진입할 타겟을 확인합니다.
    ```bash
    # 서버 환경의 경우
    $ systemctl get-default
    multi-user.target

    # 데스크톱 환경의 경우
    $ systemctl get-default
    graphical.target
    ```

- **`systemctl set-default <타겟명>`**: 기본 부팅 타겟을 변경합니다.
    ```bash
    # GUI 데스크톱을 텍스트 모드로 부팅되도록 변경
    $ sudo systemctl set-default multi-user.target

    # 텍스트 모드 서버를 GUI 모드로 부팅되도록 변경 (GUI 패키지가 설치된 경우)
    $ sudo systemctl set-default graphical.target
    ```

- **`systemctl isolate <타겟명>`**: **재부팅 없이**, 현재 세션의 운영 모드를 다른 타겟으로 즉시 변경합니다. 과거의 `init` 명령어와 동일한 역할을 합니다.
    ```bash
    # 현재 GUI 환경에서 텍스트 모드로 전환
    $ sudo systemctl isolate multi-user.target

    # 시스템 복구를 위해 구조 모드로 진입
    $ sudo systemctl isolate rescue.target
    ```

- **`systemctl list-units --type=target`**: 현재 시스템에 로드된 모든 타겟 유닛의 목록을 보여줍니다.

## 4. 요약

- **타겟**은 `systemd` 환경에서 특정 시스템 운영 상태를 정의하는 서비스들의 묶음입니다.
- 타겟은 숫자 런레벨보다 더 명시적이고 유연한 관리 방식을 제공합니다.
- `systemctl`을 사용하여 기본 부팅 타겟을 설정(`set-default`)하거나, 현재 운영 모드를 즉시 변경(`isolate`)할 수 있습니다.
