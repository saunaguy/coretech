# 2-3-1: 프로세스 관리 (`ps`, `top`, `htop`, `kill`)

시스템 관리의 핵심은 현재 시스템에서 어떤 프로그램들이 실행되고 있는지(프로세스)를 파악하고, 필요에 따라 이들을 제어하는 것입니다. 이번 장에서는 시스템의 현재 상태를 확인하고, 응답 없는 프로세스를 종료하는 등의 관리 작업을 배웁니다.

## 1. `ps`: 프로세스의 현재 상태 스냅샷

- **기능**: `ps` (Process Status) 명령어는 현재 실행 중인 프로세스들의 **특정 순간 상태**를 사진처럼 찍어서 보여줍니다.
- **옵션 스타일**: `ps`는 역사적인 이유로 옵션을 붙이는 방식이 크게 두 가지로 나뉩니다. 둘 다 매우 널리 쓰이므로 모두 알아두는 것이 좋습니다.
    - **System V 방식**: `-ef` 처럼 하이픈(`-`)을 붙입니다.
    - **BSD 방식**: `aux` 처럼 하이픈을 붙이지 않습니다.

- **주요 사용법**:
    - `ps -ef`: 시스템의 **모든(e)** 프로세스를 **풀 포맷(f)**으로 보여줍니다. `UID`(사용자), `PID`(프로세스 ID), `PPID`(부모 프로세스 ID) 등을 확인할 수 있습니다.
    - `ps aux`: **모든(a)** 사용자의 프로세스, 터미널에 연결되지 않은 프로세스까지 **(x)** **사용자 친화적인 포맷(u)**으로 보여줍니다. `%CPU`, `%MEM` 등 자원 사용량을 직관적으로 볼 수 있습니다.

- **`grep` 과의 조합 (매우 중요)**: `ps`는 단독으로 쓰이기보다는, `grep`과 파이프로 연결하여 원하는 프로세스를 찾아내는 용도로 훨씬 많이 사용됩니다.
    ```bash
    # 현재 실행 중인 프로세스 중 'httpd' 라는 이름이 포함된 것을 검색
    $ ps -ef | grep "httpd"
    root      1234     1  0 14:00 ?        00:00:01 /usr/sbin/httpd -DFOREGROUND
    apache    1236  1234  0 14:00 ?        00:00:00 /usr/sbin/httpd -DFOREGROUND
    ```

## 2. `top`: 실시간 프로세스 모니터링

- **기능**: `ps`가 스냅샷이라면, `top`은 **실시간 동영상**입니다. 시스템의 프로세스 상태와 자원 사용량을 주기적으로(기본 3초) 갱신하여 동적으로 보여주는 대화형 프로그램입니다.
- **실행**: 터미널에 `top`을 입력합니다.
- **화면 구성**:
    - **상단 요약 영역**: 시스템의 전반적인 상태(가동 시간, 로드 에버리지, CPU/메모리 사용량 등)를 보여줍니다.
    - **하단 프로세스 목록**: 현재 실행 중인 프로세스 목록을 보여주며, 기본적으로 CPU 사용량이 높은 순서로 정렬됩니다.
- **주요 조작 키** (top 실행 중에 입력):
    - `P` (대문자): CPU 사용량 순으로 정렬합니다.
    - `M` (대문자): 메모리 사용량 순으로 정렬합니다.
    - `k`: 특정 프로세스를 종료(kill)시킵니다. PID를 입력하라는 프롬프트가 나타납니다.
    - `q`: `top`을 종료합니다.

## 3. `htop`: 더 향상된 `top`

- **기능**: `top`을 더 시각적이고 사용하기 편리하게 만든 향상된 버전입니다.
- **설치 (Red Hat 계열)**: 기본 설치되어 있지 않으므로, `dnf`로 설치해야 합니다.
    ```bash
    $ sudo dnf install htop
    ```
- **`top` 대비 장점**:
    - 텍스트가 컬러로 표시되어 가독성이 좋습니다.
    - 마우스 클릭 및 키보드 화살표로 프로세스 선택 및 스크롤이 가능합니다.
    - 프로세스를 종료하거나 우선순위를 변경하는 작업이 더 쉽습니다. (예: `F9` 키로 kill 메뉴 호출)

> **결론**: 서버에 직접 설치할 수 있는 환경이라면, `top`보다 `htop`을 사용하는 것이 훨씬 편리합니다.

## 4. `kill`: 프로세스에 신호 보내기

- **기능**: 특정 PID를 가진 프로세스에게 **신호(Signal)**를 보내 제어합니다. 가장 흔한 용도는 프로세스를 종료시키는 것입니다.
- **문법**: `kill [옵션] <PID>`

### 주요 신호(Signal)
- **`15` (SIGTERM)**: **기본값**. 프로세스에게 "이제 작업을 정리하고 정상적으로 종료해달라"고 **요청**하는 신호입니다. 가장 먼저 시도해야 할 안전하고 예의 바른 종료 방식입니다.
    ```bash
    # PID가 1234인 프로세스를 정상 종료
    $ kill 1234
    ```
- **`9` (SIGKILL)**: 프로세스의 의사와 상관없이, 커널이 해당 프로세스를 **강제로 즉시 종료**시키는 신호입니다. "망치"와 같아서, 프로세스가 파일을 저장하거나 하던 작업을 마무리할 기회를 주지 않습니다. SIGTERM으로 종료되지 않는 "좀비" 프로세스를 잡을 때 사용하는 최후의 수단입니다.
    ```bash
    # PID가 1234인 프로세스를 강제 종료
    $ kill -9 1234
    # 또는
    $ kill -SIGKILL 1234
    ```
- **`1` (SIGHUP)**: 프로세스를 재시작하지 않고, **설정 파일만 다시 읽어들이게** 할 때 주로 사용되는 신호입니다.

### `pkill` 과 `killall`
PID를 일일이 찾아서 `kill` 하는 것이 번거로울 때, 프로세스의 **이름**을 기반으로 신호를 보낼 수 있습니다.

- **`pkill <프로세스명>`**: 특정 이름을 포함하는 모든 프로세스를 종료합니다.
    ```bash
    # 이름에 'httpd'가 포함된 모든 프로세스를 정상 종료
    $ sudo pkill httpd
    ```
- **`killall <정확한 프로세스명>`**: 정확히 일치하는 이름의 모든 프로세스를 종료합니다.
    ```bash
    # 이름이 정확히 'firefox'인 모든 프로세스를 강제 종료
    $ killall -9 firefox
    ```
