# 4-2-3: DHCP 기본(DORA), 예약/옵션, PXE

네트워크에 연결되는 모든 장치는 IP 주소, 서브넷 마스크, 기본 게이트웨이, DNS 서버 주소와 같은 네트워크 설정을 가져야 통신이 가능합니다. 수십, 수백 대의 컴퓨터에 이 설정을 일일이 수동으로 입력하는 것은 매우 비효율적입니다. **DHCP(Dynamic Host Configuration Protocol)**는 이러한 네트워크 설정 과정을 자동화해주는 핵심 프로토콜입니다.

## 1. DHCP 동작 과정: DORA

DHCP는 클라이언트(PC, 노트북 등)가 네트워크 설정을 요청하고, DHCP 서버가 이를 응답하는 4단계의 과정을 거칩니다. 앞 글자를 따서 **DORA**라고 부릅니다.

1.  **Discover (발견)**: 네트워크에 새로 연결된 클라이언트는 자신의 MAC 주소만 알뿐, IP 주소를 모릅니다. 그래서 네트워크의 모든 장치에게 "혹시 여기 DHCP 서버 있나요?"라고 **브로드캐스트(Broadcast)** 메시지를 보냅니다. (Source IP: `0.0.0.0`, Destination IP: `255.255.255.255`)

2.  **Offer (제안)**: DHCP 서버는 Discover 메시지를 받고, 해당 클라이언트에게 할당해 줄 IP 주소, 서브넷 마스크, 게이트웨이, DNS 서버 정보 등을 담아 "이 IP 주소를 사용하는 건 어때?"라고 제안 메시지를 보냅니다. 이 메시지 역시 브로드캐스트로 전달될 수 있습니다. (네트워크에 여러 DHCP 서버가 있을 수 있으므로, 클라이언트는 여러 제안을 받을 수 있습니다.)

3.  **Request (요청)**: 클라이언트는 여러 제안 중 하나(보통 가장 먼저 도착한 제안)를 선택하고, "나 이 서버가 제안한 IP 주소를 사용하겠습니다!"라고 다시 한번 브로드캐스트 메시지를 보냅니다. 이 메시지에는 자신이 선택한 DHCP 서버의 정보가 포함되어 있어, 다른 DHCP 서버들은 자신의 제안이 거절되었음을 알게 됩니다.

4.  **Acknowledge (확인)**: 클라이언트로부터 요청을 받은 DHCP 서버는, 해당 IP 주소와 설정 정보가 이제 공식적으로 할당되었음을 확인하는 최종 확인(ACK) 메시지를 보냅니다. 이 메시지를 받은 클라이언트는 비로소 네트워크 설정을 완료하고 통신을 시작할 수 있습니다. DHCP 서버는 해당 IP 주소가 특정 시간(**임대 시간, Lease Time**) 동안 이 클라이언트에게 할당되었음을 기록합니다.

## 2. DHCP 주요 기능

### IP 주소 예약 (Reservation)
- **기능**: 특정 MAC 주소를 가진 장치에게는 항상 **동일한 IP 주소**를 할당하도록 DHCP 서버에 미리 설정하는 기능입니다. 프린터, 파일 서버, 웹 서버 등 항상 고정된 IP 주소로 접근해야 하는 네트워크 장치에 유용합니다.
- **설정**: DHCP 서버의 설정 파일에 특정 MAC 주소와 할당할 IP 주소를 1:1로 매핑하여 구성합니다.

### DHCP 옵션 (Options)
- **기능**: DHCP는 IP 주소, 서브넷 마스크, 게이트웨이, DNS 서버 외에도 다양한 추가 정보를 클라이언트에게 전달할 수 있습니다. 이를 **DHCP 옵션**이라고 합니다.
- **주요 옵션**:
    - `Option 3`: Router (기본 게이트웨이 주소)
    - `Option 6`: DNS Servers
    - `Option 42`: NTP Servers (시간 동기화 서버 주소)
    - `Option 66`, `Option 67`: TFTP 서버 주소와 부트 파일 이름 (PXE 부팅에 사용)

## 3. PXE (Preboot eXecution Environment)

- **개념**: PXE(픽시)는 컴퓨터에 운영체제가 설치되어 있지 않거나, 하드 디스크 없이도 네트워크를 통해 부팅 이미지를 받아와 시스템을 시작할 수 있게 해주는 환경입니다. 대규모 서버 클러스터에 자동으로 운영체제를 설치하거나, 디스크 없는(diskless) 시스템을 운영하는 데 사용됩니다.

- **PXE와 DHCP의 연관성**: PXE 부팅 과정에서 DHCP는 매우 중요한 역할을 합니다.
    1.  PXE 부팅이 활성화된 클라이언트는 부팅 시 DHCP Discover 메시지를 보냅니다.
    2.  DHCP 서버는 일반적인 네트워크 설정 정보와 함께, **DHCP 옵션 66번과 67번**을 통해 **TFTP(Trivial File Transfer Protocol) 서버의 IP 주소**와 부팅에 필요한 **부트 로더 파일의 이름**(예: `pxelinux.0`)을 클라이언트에게 알려줍니다.
    3.  클라이언트는 DHCP로부터 받은 TFTP 서버 주소로 접속하여 부트 로더 파일을 다운로드합니다.
    4.  다운로드한 부트 로더가 실행되면, 이 부트 로더는 다시 TFTP 서버로부터 리눅스 커널과 `initramfs` 이미지를 받아와 메모리에 로드하여 부팅을 계속 진행합니다.

DHCP는 단순히 IP 주소를 자동으로 할당하는 것을 넘어, DHCP 옵션과 PXE 부팅 지원을 통해 대규모 네트워크 인프라의 자동화와 중앙 관리를 가능하게 하는 핵심적인 기반 기술입니다.
