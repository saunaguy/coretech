# 1-1-6: 운영체제의 종류와 역할

세상에는 다양한 컴퓨터 시스템이 존재하며, 각각의 목적과 환경에 맞는 여러 종류의 운영체제가 있습니다. 운영체제는 처리 방식, 사용 목적 등에 따라 다양하게 분류할 수 있습니다.

## 1. 처리 방식에 따른 분류

### 📦 일괄 처리 (Batch Processing)
- **개념**: 사용자와의 상호작용 없이, 처리해야 할 작업들을 한 번에 모아서 순차적으로 실행하는 방식입니다.
- **특징**: 시스템의 처리 효율을 높이는 데 중점을 둡니다. 모든 작업이 끝나야 결과를 확인할 수 있습니다.
- **예시**: 급여 계산, 대규모 데이터 분석, 일일 정산 등 주기적이고 반복적인 작업에 사용됩니다.

### 🔄 시분할 시스템 (Time-sharing System)
- **개념**: CPU의 처리 시간을 매우 짧은 단위(Time Slice)로 나누어 여러 작업(프로세스)에 번갈아 할당하는 방식입니다.
- **특징**: 각 사용자는 마치 자신 혼자 컴퓨터를 사용하는 것처럼 느끼게 됩니다. 빠른 응답 시간을 제공하여 대화형(Interactive) 작업에 적합합니다.
- **예시**: 오늘날 우리가 사용하는 대부분의 운영체제(Linux, Windows, macOS)는 시분할 시스템을 기반으로 합니다. 여러 프로그램을 동시에 띄워놓고 사용하는 것이 가능한 이유입니다.

### ⏱️ 실시간 운영체제 (RTOS: Real-Time Operating System)
- **개념**: 정해진 시간(Deadline) 안에 반드시 작업 처리를 완료해야 하는 시스템을 위한 운영체제입니다.
- **특징**: 결과의 정확성뿐만 아니라, **시간적 제약**을 지키는 것이 매우 중요합니다.
- **종류**:
    - **경성 실시간(Hard Real-time)**: 아주 작은 시간 오차도 허용되지 않는 시스템. (예: 미사일 제어, 원자력 발전소 제어, 자동차 에어백 시스템)
    - **연성 실시간(Soft Real-time)**: 시간 제약을 지키지 못하더라도 치명적인 결과를 초래하지는 않는 시스템. (예: 동영상 스트리밍, 온라인 게임)

## 2. 사용 목적 및 규모에 따른 분류

### 🖥️ 데스크톱/개인용 OS (Desktop/Personal OS)
- **목적**: 개인용 컴퓨터(PC) 환경에서 사용자가 편리하게 다양한 응용 프로그램을 사용할 수 있도록 지원합니다.
- **특징**: 사용자 친화적인 그래픽 인터페이스(GUI), 멀티미디어 기능, 다양한 소프트웨어 호환성에 중점을 둡니다.
- **예시**: Microsoft Windows, Apple macOS, Ubuntu/Fedora와 같은 데스크톱 리눅스 배포판.

### 🌐 서버 OS (Server OS)
- **목적**: 네트워크를 통해 다른 컴퓨터(클라이언트)에게 파일, 웹 페이지, 데이터베이스 등의 서비스를 제공하는 컴퓨터를 위한 운영체제입니다.
- **특징**: **안정성, 보안, 고성능**이 매우 중요합니다. 24시간 365일 중단 없이 작동해야 하며, 다수의 동시 접속을 효율적으로 처리할 수 있어야 합니다.
- **예시**: **Linux (CentOS, RHEL, Debian 등)**, Windows Server, UNIX.

> **리눅스의 강점**: 리눅스는 뛰어난 안정성과 성능, 유연성, 그리고 오픈소스라는 장점 덕분에 서버 OS 시장에서 압도적인 점유율을 차지하고 있습니다.

### 📱 모바일 OS (Mobile OS)
- **목적**: 스마트폰, 태블릿과 같은 모바일 기기를 위해 설계된 운영체제입니다.
- **특징**: 터치스크린 인터페이스, 저전력 설계, 무선 통신(Wi-Fi, 5G) 지원, 앱 생태계 등이 핵심 요소입니다.
- **예시**: Google Android, Apple iOS.

### ⚙️ 임베디드 OS (Embedded OS)
- **목적**: 특정 기능을 수행하는 전자 기기나 시스템에 내장(embed)되는 운영체제입니다.
- **특징**: 제한된 하드웨어 자원(CPU, 메모리)에서 작동하도록 고도로 최적화되어 있으며, 높은 안정성을 요구합니다.
- **예시**: 스마트 TV, 공유기, 자동차 인포테인먼트 시스템, 산업용 로봇 등에 사용되는 다양한 버전의 리눅스 또는 RTOS.

이처럼 운영체제는 하나의 개념이 아니라, 다양한 환경과 목적에 맞게 특화된 형태로 발전해왔습니다. 우리가 배우는 리눅스는 특히 서버와 임베디드 시스템에서 강력한 영향력을 발휘하고 있으며, 데스크톱 환경에서도 점차 사용자를 넓혀가고 있습니다.
