# 1-1-5: 운영체제(OS)의 정의와 역할

우리는 컴퓨터를 사용하면서 자연스럽게 운영체제(OS, Operating System)를 접하지만, 그 본질적인 역할이 무엇인지 깊이 생각해보지 않는 경우가 많습니다. 운영체제는 컴퓨터 시스템의 핵심 소프트웨어입니다.

## 1. 🏛️ 운영체제란 무엇인가?

- **핵심 정의**: 컴퓨터 **하드웨어**와 **사용자(또는 응용 프로그램)** 사이에 위치하여, 컴퓨터 자원을 효율적으로 관리하고 사용자에게 편리한 인터페이스를 제공하는 **시스템 소프트웨어**입니다.

- **비유를 통한 이해**:
    - **정부(Government)**: 국가의 자원(토지, 예산, 인력)을 관리하고 국민들이 편리하고 안전하게 생활할 수 있도록 법과 제도를 만드는 것처럼, 운영체제는 컴퓨터의 자원(CPU, 메모리, 디스크)을 관리하고 프로그램들이 원활하게 작동하도록 규칙과 환경을 제공합니다.
    - **오케스트라 지휘자**: 다양한 악기(하드웨어)들이 조화롭게 연주(동작)하여 아름다운 음악(결과)을 만들어내도록 지휘하는 역할을 합니다.

## 2. 🎯 운영체제의 두 가지 핵심 목표

운영체제의 모든 기능은 다음 두 가지 주요 목표를 달성하기 위해 존재합니다.

### 목표 1: 사용자에게 편리한 환경 제공 (추상화)

컴퓨터 하드웨어는 매우 복잡하고 다루기 어렵습니다. 운영체제는 이 복잡성을 숨기고, 마치 간단한 장치처럼 보이게 만드는 **추상화(Abstraction)** 역할을 합니다.

- **복잡성 은폐**: 사용자는 디스크의 어느 섹터에 파일이 저장되는지, CPU가 어떤 명령어를 처리하는지 몰라도 파일을 저장하고 프로그램을 실행할 수 있습니다.
- **사용자 인터페이스 제공**:
    - **CLI (Command Line Interface)**: 텍스트 기반의 명령어로 컴퓨터와 상호작용합니다. (예: 리눅스 셸)
    - **GUI (Graphical User Interface)**: 아이콘, 창, 마우스 등을 이용해 시각적으로 컴퓨터와 상호작용합니다. (예: 윈도우, macOS)
- **일관된 환경**: 프로그램 개발자들은 하드웨어의 종류가 바뀌더라도, 운영체제가 제공하는 일관된 API(시스템 콜)를 통해 프로그램을 작성할 수 있습니다.

### 목표 2: 시스템 자원의 효율적인 관리 (자원 관리자)

컴퓨터의 자원(CPU, 메모리, 스토리지 등)은 한정되어 있습니다. 운영체제는 이 한정된 자원을 여러 프로그램들이 공정하고 효율적으로 나누어 쓸 수 있도록 관리하고 조정하는 **자원 관리자(Resource Manager)** 역할을 합니다.

- **CPU 관리 (프로세스 관리)**
    - 어떤 프로세스에게 CPU를 할당할지, 얼마나 오래 사용하게 할지를 결정합니다. (이를 **스케줄링**이라고 합니다.)
    - 이를 통해 여러 프로그램이 동시에 실행되는 것처럼 보이게 합니다.

- **메모리 관리**
    - 각 프로세스에게 필요한 메모리 공간을 할당하고, 사용이 끝나면 회수합니다.
    - 한 프로세스가 다른 프로세스의 메모리 영역을 침범하지 못하도록 보호하여 시스템의 안정성을 유지합니다.

- **장치 관리 (입출력 관리)**
    - 키보드, 마우스, 프린터, 네트워크 카드 등 다양한 주변 장치를 관리하고, 프로그램이 이 장치들을 사용할 수 있도록 인터페이스(드라이버)를 제공합니다.

- **파일 관리**
    - 스토리지에 파일과 디렉터리를 생성, 삭제, 수정, 검색하는 기능을 제공합니다.
    - 파일의 접근 권한을 관리하여 보안을 유지합니다.

## 3. 🍰 운영체제의 계층적 구조

컴퓨터 시스템은 일반적으로 다음과 같은 계층 구조로 이해할 수 있습니다.

```
+-------------------------+
|         사용자          |
+-------------------------+
|      응용 프로그램      |
| (웹 브라우저, 게임 등)  |
+-------------------------+
|        운영체제         |
| (커널, 시스템 프로그램) |
+-------------------------+
|        하드웨어         |
| (CPU, 메모리, 디스크)   |
+-------------------------+
```

- **하드웨어**: 가장 아래 계층의 물리적인 기계 장치.
- **운영체제**: 하드웨어를 직접 제어하고 관리하는 핵심 소프트웨어.
- **응용 프로그램**: 운영체제가 제공하는 기반 위에서 특정 목적을 위해 실행되는 소프트웨어.
- **사용자**: 응용 프로그램을 통해 컴퓨터와 상호작용하는 주체.

결론적으로, 운영체제는 복잡한 하드웨어를 가리고 편리한 가상 머신(Virtual Machine)을 제공하는 동시에, 한정된 시스템 자원을 효율적으로 관리하는 두뇌와 같은 역할을 수행합니다.
