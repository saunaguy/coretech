# 1-1-1: 하드웨어 기초

컴퓨터 시스템을 이해하기 위한 첫걸음은 하드웨어를 아는 것입니다. 하드웨어는 컴퓨터를 구성하는 물리적인 부품들의 총칭입니다. 리눅스 운영체제는 이러한 하드웨어 자원을 효율적으로 관리하고 제어하는 역할을 합니다.

## 1. 주요 하드웨어 구성 요소

컴퓨터는 다양한 부품들로 이루어져 있지만, 핵심적인 요소는 다음과 같습니다.

### 🧠 중앙 처리 장치 (CPU: Central Processing Unit)

- **역할**: 컴퓨터의 '두뇌'에 해당하며, 모든 계산과 명령어 처리를 담당합니다. 프로그램 코드를 해석하고 실행하는 핵심 장치입니다.
- **주요 성능 지표**:
    - **코어(Core)**: 실제로 연산을 수행하는 핵심 회로. 코어 수가 많을수록 동시에 여러 작업을 처리하는 데 유리합니다(멀티태스킹).
    - **클럭 속도(Clock Speed)**: CPU의 작업 속도를 나타내며, 보통 기가헤르츠(GHz) 단위로 표현됩니다. 클럭 속도가 높을수록 초당 더 많은 명령을 처리할 수 있습니다.
- **리눅스와의 관계**: 리눅스는 CPU의 여러 코어에 작업을 분배(스케줄링)하여 시스템 전체의 성능을 최적화합니다.

### 💾 메모리 (RAM: Random Access Memory)

- **역할**: 현재 실행 중인 프로그램과 데이터를 일시적으로 저장하는 '작업 공간'입니다. CPU가 빠르게 접근하여 데이터를 읽고 쓸 수 있습니다.
- **특징**:
    - **휘발성(Volatile)**: 전원이 꺼지면 저장된 데이터가 모두 사라집니다.
    - **속도**: 하드 디스크(HDD)나 SSD보다 월등히 빠릅니다.
- **리눅스와의 관계**: 리눅스는 메모리를 효율적으로 관리하여 여러 프로세스가 원활하게 동작하도록 돕습니다. 메모리가 부족할 경우, 하드 디스크의 일부를 가상 메모리(Swap)로 사용하기도 합니다.

### 💽 스토리지 (Storage)

- **역할**: 프로그램, 문서, 미디어 파일 등 데이터를 영구적으로 저장하는 '창고'입니다.
- **종류**:
    - **HDD (Hard Disk Drive)**: 자기 디스크를 회전시켜 데이터를 읽고 쓰는 전통적인 방식. 용량 대비 가격이 저렴하지만 속도가 느립니다.
    - **SSD (Solid State Drive)**: 반도체 칩을 이용하여 데이터를 저장. HDD보다 훨씬 빠르고 충격에 강하지만, 가격이 상대적으로 비쌉니다.
- **리눅스와의 관계**: 리눅스는 다양한 파일 시스템(ext4, XFS, Btrfs 등)을 통해 스토리지를 관리하며, 사용자가 파일을 생성, 수정, 삭제할 수 있도록 합니다.

### 🔌 마더보드 (Motherboard)

- **역할**: CPU, RAM, 스토리지 등 컴퓨터의 모든 부품을 연결하는 거대한 회로 기판입니다. 각 부품들이 서로 데이터를 주고받을 수 있는 통로 역할을 합니다.
- **리눅스와의 관계**: 리눅스 커널은 마더보드에 내장된 칩셋과 컨트롤러들을 인식하고, 각 장치가 올바르게 작동하도록 드라이버를 통해 제어합니다.

### 🎮 그래픽 처리 장치 (GPU: Graphics Processing Unit)

- **역할**: 화면에 이미지, 영상, 사용자 인터페이스(UI)를 출력하는 역할을 전문적으로 담당합니다. 특히 3D 그래픽이나 병렬 연산에 특화되어 있습니다.
- **리눅스와의 관계**: 리눅스는 GUI(Graphical User Interface) 환경을 위해 GPU 드라이버를 사용합니다. 최근에는 AI 및 데이터 과학 분야에서 GPU의 병렬 처리 능력을 활용하는 경우가 많습니다.

### ⚡ 전원 공급 장치 (PSU: Power Supply Unit)

- **역할**: 외부 전원(AC)을 컴퓨터 부품들이 사용할 수 있는 안정적인 직류(DC) 전원으로 변환하여 공급합니다.

## 2. 하드웨어의 상호작용

컴퓨터의 동작은 이 부품들의 유기적인 상호작용으로 이루어집니다.

1.  사용자가 프로그램을 실행하면, 해당 프로그램은 **스토리지**에서 **메모리(RAM)**로 로드됩니다.
2.  **CPU**는 메모리에 로드된 프로그램의 명령어를 하나씩 가져와 해석하고 실행합니다.
3.  계산에 필요한 데이터는 메모리에서 가져오고, 처리 결과는 다시 메모리에 저장합니다.
4.  **GPU**는 메모리에 있는 화면 출력 정보를 가져와 모니터에 표시합니다.
5.  이 모든 과정은 **마더보드**라는 통로를 통해 이루어지며, **PSU**가 안정적인 전원을 공급합니다.

리눅스 운영체제는 바로 이 복잡한 하드웨어 상호작용을 추상화하고 관리하여, 사용자와 애플리케이션이 하드웨어의 세부 동작을 몰라도 컴퓨터를 쉽고 효율적으로 사용할 수 있게 해줍니다.
