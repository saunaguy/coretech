# 1-2-6: 기본 CLI (명령줄 인터페이스)

리눅스의 진정한 힘은 그래픽 사용자 인터페이스(GUI)가 아닌, **명령줄 인터페이스(CLI, Command Line Interface)**에서 나옵니다. CLI 환경에 익숙해지는 것은 리눅스를 제대로 활용하기 위한 첫걸음입니다.

## 1. 🖥️ CLI란 무엇인가?

- **정의**: 사용자가 키보드를 통해 텍스트로 된 **명령(Command)**을 입력하여 컴퓨터와 상호작용하는 방식입니다.
- **GUI와의 비교**:
    - **GUI (Graphical User Interface)**: 마우스로 아이콘이나 메뉴를 클릭하여 시각적으로 작업을 수행합니다. 직관적이지만, 반복적인 작업이나 정교한 제어에는 비효율적일 수 있습니다.
    - **CLI (Command Line Interface)**: 정해진 명령어를 통해 정확하고 효율적으로 작업을 수행합니다. 특히 여러 명령을 조합하여 복잡한 작업을 자동화하는 데 매우 강력하며, 서버 환경과 같이 그래픽 환경이 없는 곳에서는 유일한 소통 창구입니다.

## 2. 셸(Shell)과 터미널(Terminal)

CLI 환경을 이야기할 때 항상 함께 나오는 두 가지 용어입니다. 둘은 미묘하게 다릅니다.

- **셸 (Shell)**
    - **역할**: 사용자가 입력한 명령을 해석하여, 운영체제 커널이 이해할 수 있도록 전달하는 **명령어 해석기**입니다.
    - **비유**: 커널이 '정부'라면 셸은 그 정부에 민원을 전달하는 '동사무소 직원'과 같습니다. 사용자의 요구사항(명령어)을 접수하여 커널에 전달하고, 그 처리 결과를 다시 사용자에게 보여줍니다.
    - **종류**: 리눅스에서는 다양한 셸이 있으며, 그중에서도 **`bash` (Bourne Again SHell)**가 대부분의 배포판에서 기본 셸로 사용됩니다.

- **터미널 (Terminal)**
    - **역할**: 셸을 실행하고, 사용자가 명령어를 입력하고 그 결과를 눈으로 볼 수 있도록 해주는 **창 프로그램**입니다.
    - **비유**: 셸이 '방송국'이라면 터미널은 그 방송을 볼 수 있는 'TV'입니다. 터미널이라는 창을 통해 우리는 셸과 대화할 수 있습니다.
    - **예시**: GNOME Terminal, Konsole, xterm 등

> **요약**: 우리는 **터미널**이라는 프로그램을 열어서, 그 안에서 작동하는 **셸**에게 **명령어**를 내리는 것입니다.

## 3. 셸 프롬프트(Prompt) 이해하기

터미널을 실행하면 명령어를 입력하라고 깜빡이는 부분이 나타나는데, 이를 프롬프트라고 합니다. 프롬프트는 현재 시스템에 대한 유용한 정보를 담고 있습니다.

```bash
username@hostname:~/directory$
```

- `username`: 현재 로그인한 **사용자의 이름**입니다.
- `hostname`: 컴퓨터의 **이름(호스트명)**입니다.
- `~/directory`: 현재 작업 중인 **디렉터리(폴더)의 위치**입니다. `~` 표시는 현재 사용자의 홈 디렉터리를 의미하는 특별한 약어입니다.
- `$` 또는 `#`: 현재 사용자의 **권한**을 나타냅니다.
    - `$` : 일반 사용자 권한입니다.
    - `#` : 시스템의 모든 것을 할 수 있는 최고 관리자(**root**) 권한입니다. `#` 프롬프트를 보면 항상 주의해야 합니다.

## 4. 명령어의 기본 구조

리눅스 명령어는 대부분 다음과 같은 구조를 가집니다.

`command [options] [arguments]`

- **Command (명령어)**: 실행하고자 하는 프로그램의 이름입니다. (예: `ls`)
- **Options (옵션)**: 명령어의 기본 동작을 변경하는 추가 설정입니다. 보통 하이픈(`-`)으로 시작하며, 여러 개를 조합할 수 있습니다. (예: `ls -l`, `ls -a`, `ls -la`)
- **Arguments (인자)**: 명령어가 작업을 수행할 **대상**입니다. 보통 파일이나 디렉터리 경로가 됩니다. (예: `ls /home/user`)

## 5. 처음 만나는 필수 명령어 5가지

앞으로 수많은 명령어를 배우겠지만, 우선 CLI 환경과 친해지기 위한 가장 기본적인 5가지 명령어입니다.

1.  **`pwd`** (Print Working Directory)
    - "내가 지금 어디에 있지?"를 알려줍니다. 현재 작업 중인 디렉터리의 전체 경로를 출력합니다.

2.  **`ls`** (List)
    - 현재 디렉터리에 있는 파일과 하위 디렉터리들의 목록을 보여줍니다.

3.  **`cd`** (Change Directory)
    - 다른 디렉터리로 이동(작업 위치를 변경)할 때 사용합니다.
    - `cd /home/user`: 특정 경로로 이동 (절대 경로)
    - `cd documents`: 현재 위치의 하위 디렉터리로 이동 (상대 경로)
    - `cd ..`: 바로 위 상위 디렉터리로 이동
    - `cd ~` 또는 `cd`: 나의 홈 디렉터리로 바로 이동

4.  **`man`** (Manual)
    - **가장 중요한 명령어입니다.** 특정 명령어의 사용법이 궁금할 때 공식 설명서(매뉴얼)를 보여줍니다. (예: `man ls`는 `ls` 명령어의 상세한 설명과 모든 옵션을 보여줍니다.)
    - 설명서 화면에서 나갈 때는 `q` 키를 누릅니다.

5.  **`clear`** (또는 단축키 `Ctrl + L`)
    - 터미널 화면을 깨끗하게 지워줍니다.

이 명령어들을 직접 터미널에 입력해보며 CLI 환경과 첫인사를 나눠보세요. 2장부터는 더 다양하고 강력한 명령어들을 본격적으로 배우게 될 것입니다.
