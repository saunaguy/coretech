# 1-2-3: 가상화(Virtualization) 개념

가상 머신(VM)을 이용한 리눅스 설치 방법을 이해하기 위해서는, 그 기반이 되는 기술인 **가상화(Virtualization)**에 대한 개념을 알아야 합니다. 가상화는 현대 IT 인프라의 핵심 기술 중 하나입니다.

## 1. 💡 가상화란 무엇인가?

- **정의**: 물리적인 컴퓨터 리소스(CPU, 메모리, 스토리지 등)의 실체를 가리고, **논리적인(가상의) 리소스처럼 보이게 만드는 기술**입니다. 이 기술을 통해, 하나의 물리적 컴퓨터(Host) 위에서 여러 개의 독립적인 가상 컴퓨터(Guest)를 동시에 실행할 수 있습니다.

- **핵심 아이디어**: 물리적인 하드웨어 한 대를 여러 대처럼 나누어 쓰는 것입니다. 각 가상 컴퓨터(VM)는 자신이 진짜 하드웨어를 단독으로 사용하고 있다고 착각하며 작동합니다.

## 2. 🧩 가상화의 주요 구성 요소

가상화 환경은 다음과 같은 요소들로 구성됩니다.

- **호스트 (Host)**: 가상 머신이 설치될 기반이 되는 **물리적 컴퓨터** 자체를 의미합니다. 실제 CPU, RAM, 디스크 등의 하드웨어 자원을 제공합니다.
- **호스트 운영체제 (Host OS)**: 호스트 컴퓨터에 설치된 주 운영체제입니다. (예: Windows 11, macOS)
- **게스트 (Guest)**: 호스트 위에 생성된 **가상 컴퓨터(VM)**를 의미합니다.
- **게스트 운영체제 (Guest OS)**: 각각의 가상 머신 내부에 설치되는 운영체제입니다. (예: 우리가 설치할 Ubuntu Linux)
- **하이퍼바이저 (Hypervisor)**: 가상화를 가능하게 하는 **핵심 소프트웨어**입니다. 호스트의 물리적 자원을 가상의 자원으로 변환하여 게스트들에게 나누어주고, 각 게스트들이 서로 독립적으로 작동하도록 제어하고 감독합니다. **가상 머신 모니터(VMM, Virtual Machine Monitor)**라고도 불립니다.

## 3. 하이퍼바이저의 종류

하이퍼바이저는 하드웨어 위에서 실행되는 방식에 따라 크게 두 가지로 나뉩니다.

### 타입 1: 네이티브 (Native) 또는 베어메탈 (Bare-metal) 방식
- **구조**: 하이퍼바이저가 운영체제 없이, **하드웨어 위에 직접 설치되어 실행**되는 방식입니다.
- **특징**: 중간에 거치는 호스트 OS가 없으므로 자원 손실이 거의 없고, **성능과 효율이 매우 높습니다.** 안정성이 뛰어나 기업 환경에서 선호됩니다.
- **비유**: 땅(하드웨어) 위에 바로 기둥(하이퍼바이저)을 세워 건물을 짓는 것과 같습니다.
- **예시**: VMware ESXi, Microsoft Hyper-V, **KVM (리눅스 커널 내장)**, Xen
- **주 사용처**: 아마존 웹 서비스(AWS), 구글 클라우드(GCP)와 같은 클라우드 컴퓨팅, 기업의 데이터 센터.

### 타입 2: 호스티드 (Hosted) 방식
- **구조**: 일반적인 호스트 운영체제(예: 윈도우) 위에 **하나의 응용 프로그램처럼 설치되어 실행**되는 방식입니다.
- **특징**: 기존에 사용하던 PC에 쉽게 설치하고 사용할 수 있어 **편의성이 높습니다.** 하지만 하드웨어 접근 시 호스트 OS를 한 번 더 거쳐야 하므로, 타입 1에 비해 약간의 성능 저하가 발생합니다.
- **비유**: 이미 지어진 건물(호스트 OS)의 한 방에 칸막이(하이퍼바이저)를 치고 사용하는 것과 같습니다.
- **예시**: **Oracle VirtualBox**, VMware Workstation, Parallels Desktop (macOS용)
- **주 사용처**: 개인용 PC에서의 학습, 개발, 테스트 환경 구축. **(우리가 사용할 방식입니다.)**

## 4. 🌟 가상화 기술의 중요성

가상화는 단순히 PC에 다른 OS를 설치하는 것을 넘어, IT 산업 전반에 혁신을 가져왔습니다.

- **서버 통합 및 비용 절감**: 과거에는 서비스마다 물리 서버 한 대가 필요했지만, 이제는 고성능 서버 한 대에 여러 가상 서버를 통합하여 운영할 수 있습니다. 이를 통해 하드웨어 구매 비용, 상면 비용, 전력 비용을 획기적으로 절감할 수 있습니다.
- **높은 격리성과 보안**: 각각의 VM은 서로 완벽하게 격리되어 있습니다. 따라서 하나의 VM에서 바이러스에 감염되거나 시스템 오류가 발생해도, 다른 VM이나 호스트 시스템에는 영향을 주지 않습니다.
- **신속한 배포와 이식성**: 미리 만들어 둔 VM 이미지를 복사하기만 하면 몇 분 안에 새로운 서버를 만들 수 있습니다. 또한, VM은 물리적 서버 간에 쉽게 이동(마이그레이션)할 수 있어 유연성이 높습니다.
- **안전한 테스트 환경**: 새로운 소프트웨어를 설치하거나 위험한 설정을 변경해보고 싶을 때, 스냅샷 기능으로 현재 상태를 저장해두고 마음껏 테스트한 뒤 문제가 생기면 즉시 원래 상태로 복원할 수 있습니다.
