# 1-2-4: 가상화 도구 설치 (VirtualBox)

리눅스를 가상 머신에 설치하기로 결정했다면, 가장 먼저 가상화를 구현해주는 소프트웨어, 즉 하이퍼바이저를 설치해야 합니다. 이 강의에서는 무료이면서 강력한 기능을 제공하는 **Oracle VirtualBox**를 기준으로 설명합니다.

### VirtualBox란?
- **정의**: 개인이 무료로 사용할 수 있는 오픈소스 타입 2 하이퍼바이저입니다.
- **장점**: Windows, macOS, Linux 등 다양한 운영체제를 지원하여 어떤 PC에서도 사용할 수 있으며, 사용법이 비교적 간단하여 초심자가 가상화 기술을 접하기에 매우 좋습니다.

---

## 1. VirtualBox 설치 과정 (Windows 기준)

### 1단계: 하드웨어 가상화 지원 기능 확인

VirtualBox를 사용하려면, CPU에서 가상화 기술(Intel VT-x 또는 AMD-V)을 지원하고, 이 기능이 활성화되어 있어야 합니다. 최신 컴퓨터는 대부분 이 기능을 지원합니다.

1.  **작업 관리자 열기**: 키보드에서 `Ctrl + Shift + Esc` 키를 누릅니다.
2.  **성능 탭으로 이동**: 상단 탭에서 [성능]을 클릭합니다.
3.  **CPU 선택**: 왼쪽 메뉴에서 [CPU]를 선택합니다.
4.  **가상화 상태 확인**: 오른쪽 하단에 "**가상화: 사용**"이라고 표시되어 있는지 확인합니다.

![Task Manager Virtualization](https://i.imgur.com/3bY1gML.png)

>  만약 "가상화: 사용 안 함"으로 표시된다면, 컴퓨터를 재부팅하여 **BIOS/UEFI 설정**에 진입한 뒤, 'Virtualization Technology', 'SVM Mode' 등의 옵션을 찾아 'Enabled'로 변경해야 합니다. (설정 메뉴의 위치는 컴퓨터 제조사마다 다릅니다.)

### 2단계: VirtualBox 다운로드

1.  **공식 사이트 접속**: 웹 브라우저에서 아래 주소로 이동합니다.
    > [https://www.virtualbox.org/wiki/Downloads](https://www.virtualbox.org/wiki/Downloads)
2.  **설치 파일 다운로드**: 페이지에서 "**Windows hosts**" 링크를 클릭하여 설치 파일을 다운로드합니다.

### 3단계: VirtualBox 확장 팩 다운로드

확장 팩(Extension Pack)은 USB 2.0/3.0, 웹캠, 원격 데스크톱(RDP) 등 가상 머신의 추가적인 기능을 활성화해줍니다. 꼭 함께 설치하는 것을 권장합니다.

1.  위와 동일한 다운로드 페이지에서 "**VirtualBox ... Extension Pack**" 링크를 찾습니다.
2.  "**All supported platforms**" 링크를 클릭하여 확장 팩 파일을 다운로드합니다. (`.vbox-extpack` 확장자를 가집니다.)

### 4단계: VirtualBox 설치 실행

1.  다운로드한 VirtualBox 설치 파일(`.exe`)을 실행합니다.
2.  설치 마법사가 시작되면, 대부분의 옵션을 기본값 그대로 두고 [Next]를 클릭하여 진행합니다.
3.  설치 도중 네트워크 연결이 잠시 끊어질 수 있다는 경고창이 나타날 수 있습니다. [Yes]를 눌러 계속 진행합니다.
4.  설치가 완료되면 [Finish]를 클릭합니다.

### 5단계: 확장 팩 설치

1.  VirtualBox 설치가 완료된 후, 다운로드해 둔 확장 팩 파일( `.vbox-extpack`)을 더블 클릭합니다.
2.  VirtualBox가 자동으로 실행되며 확장 팩을 설치할지 묻는 창이 나타납니다. [설치] 버튼을 클릭합니다.
3.  라이선스 동의 창이 나타나면, 스크롤을 끝까지 내린 후 [동의합니다] 버튼을 클릭하여 설치를 완료합니다.

## 2. 첫 가상 머신(VM) 생성 준비

VirtualBox 설치가 완료되었다면, 이제 리눅스를 설치할 가상의 컴퓨터를 생성할 차례입니다. 자세한 리눅스 설치 과정은 다음 장에서 다루고, 여기서는 VM을 만드는 기본적인 흐름만 살펴봅니다.

1.  **VirtualBox 실행**: 설치된 VirtualBox를 실행합니다.
2.  **새로 만들기**: 상단의 [새로 만들기] 버튼을 클릭합니다.
3.  **이름 및 종류 설정**:
    - **이름**: 가상 머신을 식별할 이름을 입력합니다. (예: `Ubuntu Desktop`)
    - **종류**: `Linux`
    - **버전**: `Ubuntu (64-bit)` (설치할 배포판에 맞게 선택)
4.  **메모리 크기 설정**: 가상 머신에 할당할 RAM 크기를 조절합니다. 데스크톱 환경을 사용하려면 최소 4096MB(4GB) 이상을 권장합니다.
5.  **하드 디스크 설정**: "지금 새 가상 하드 디스크 만들기"를 선택하고 [만들기]를 클릭합니다.
    - **파일 종류**: `VDI (VirtualBox 디스크 이미지)` (기본값)
    - **저장 방식**: `동적 할당` (처음엔 작은 크기로 시작해서, 데이터가 늘어남에 따라 파일 크기가 커지는 효율적인 방식)
    - **용량 설정**: 가상 하드 디스크의 최대 크기를 설정합니다. 최소 25GB 이상을 권장합니다.
6.  **생성 완료**: [만들기] 버튼을 누르면 왼쪽 목록에 새로운 가상 머신이 생성됩니다.

이제 리눅스를 설치할 가상의 PC가 준비되었습니다. 다음 단계는 이 가상 PC에 우리가 다운로드한 **Ubuntu ISO 파일을 삽입**하고, 부팅하여 실제 설치를 진행하는 것입니다.
