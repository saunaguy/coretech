# 1-2-5: 가상 머신(VM) 네트워크 모드

가상 머신을 생성하고 나면, 이 가상의 컴퓨터가 외부와 어떻게 통신할지 결정해야 합니다. VirtualBox는 여러 가지 네트워크 모드를 제공하며, 각 모드는 서로 다른 특징과 용도를 가집니다. 가장 많이 사용되는 세 가지 핵심 모드를 이해하는 것이 중요합니다.

## 1. 🌐 NAT (Network Address Translation)

- **개념**: **기본 설정값**이며, 가장 간단한 방식입니다. VirtualBox가 가상 공유기(Router) 역할을 하여, 호스트 PC의 IP 주소를 빌려 외부 인터넷과 통신합니다.

- **동작 방식**:
    1.  VirtualBox는 가상 머신(VM)에게 내부적으로 사용되는 사설 IP 주소(예: `10.0.2.15`)를 할당합니다.
    2.  VM이 인터넷으로 데이터를 보내려고 하면, VirtualBox는 이 요청의 출발지 주소를 호스트 PC의 공인 IP 주소로 "번역(Translation)"하여 내보냅니다.
    3.  외부에서 응답이 오면, VirtualBox는 다시 이 응답을 원래 요청했던 VM에게 전달해줍니다.

- **비유**: 해외여행 시 **로밍 서비스**를 이용하는 것과 같습니다. 내 원래 전화번호(사설 IP)는 해외 통신망에서 직접 사용할 수 없으므로, 통신사가 현지 통신망과 연결(번역)해주는 것과 유사합니다.

- **장점**:
    - 설정이 매우 간편하며, 별다른 구성 없이 VM이 즉시 인터넷을 사용할 수 있습니다.
    - 외부에서 VM으로 직접 접근할 수 없어 **보안에 유리**합니다.

- **단점**:
    - 외부(또는 호스트 PC)에서 VM 내부로 접속(예: SSH 접속, 웹 서버 접속)하는 것이 기본적으로 불가능합니다. (단, '포트 포워딩'이라는 별도 설정을 통해 특정 포트로의 접속은 가능하게 할 수 있습니다.)

- **주 사용처**: VM 안에서 단순히 인터넷을 사용하거나 파일을 다운로드하는 등, 외부로부터의 접속이 필요 없는 일반적인 작업에 적합합니다.

## 2. 🌉 브리지 어댑터 (Bridged Adapter)

- **개념**: VM을 호스트 PC와 동등한, **네트워크상의 독립적인 컴퓨터**로 만드는 방식입니다.

- **동작 방식**: VM은 호스트 PC가 연결된 공유기(물리적 공유기)로부터 직접 IP 주소를 할당받습니다. 예를 들어, 호스트 PC가 `192.168.0.10`을 사용한다면, VM은 `192.168.0.11`과 같이 별개의 IP를 갖게 됩니다.

- **비유**: 집에 새로운 스마트폰(VM)을 들여와 와이파이(공유기)에 연결하는 것과 같습니다. 기존의 PC(호스트)와 동등한 위치에서 네트워크를 사용합니다.

- **장점**:
    - VM이 네트워크상의 완벽한 개체가 되므로, **외부(또는 호스트 PC)에서 VM으로의 접속이 매우 자유롭습니다.**
    - 실제 서버처럼 동작하게 만들 수 있습니다.

- **단점**:
    - VM이 외부에 직접 노출되므로, 방화벽 등 보안 설정에 신경 써야 합니다.
    - 카페 등 공용 네트워크 환경에서는 IP 할당 문제나 보안 문제로 사용이 어려울 수 있습니다.

- **주 사용처**: VM 내부에 **웹 서버, SSH 서버 등을 구축**하여 외부에서 접속해야 할 때 사용합니다.

## 3. 🏠 호스트 전용 어댑터 (Host-only Adapter)

- **개념**: **호스트 PC와 VM들만**이 서로 통신할 수 있는 폐쇄적이고 고립된 내부 네트워크를 생성하는 방식입니다.

- **동작 방식**: VirtualBox는 `VirtualBox Host-Only Ethernet Adapter`라는 가상의 네트워크 카드를 호스트 PC에 생성합니다. VM과 호스트 PC는 이 가상 네트워크 안에서만 서로 통신할 수 있습니다.

- **비유**: 외부와는 연결되지 않은, **집 안에서만 사용하는 인터컴(Intercom)**과 같습니다. 호스트와 VM 간의 사적인 통신 채널입니다.

- **장점**: 외부로부터 완전히 격리되어 있어 **보안성이 매우 높습니다.** 호스트와 VM 간의 파일 공유나 원격 접속 테스트에 유용합니다.

- **단점**: 이 어댑터만으로는 VM이 **인터넷에 접속할 수 없습니다.**

- **주 사용처**: 여러 대의 VM으로 가상의 네트워크 실험 환경을 구축하거나, 인터넷 연결은 필요 없지만 호스트와 VM 간의 통신은 필요할 때 사용합니다. (보통 인터넷 사용을 위해 NAT 어댑터와 함께 2개의 어댑터를 설정하는 경우가 많습니다.)

| 구분 | 인터넷 접속 | 호스트 → VM 접속 | 외부 → VM 접속 | VM → 호스트 접속 |
| :--- | :---: | :---: | :---: | :---: |

| **브리지 어댑터** | **O** | **O** | **O** | **O** |

### 학습자를 위한 추천

- **1단계 (기본)**: 처음에는 가장 간단한 **NAT** 모드를 사용하여 리눅스 설치 및 기본적인 명령어 학습을 진행합니다.
- **2단계 (서버 구축)**: 추후 VM에 웹 서버 등을 설치하고 외부에서 접속해야 할 때, 네트워크 설정을 **브리지 어댑터**로 변경하거나, **호스트 전용 어댑터**를 추가하여 실습을 진행하는 것이 좋습니다.
