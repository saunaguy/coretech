# 2-1-5: 터미널 텍스트 에디터 기초 (`nano`, `vim`)

서버 환경과 같이 GUI가 없는 환경에서는 터미널에서 직접 텍스트 파일을 편집해야 하는 경우가 많습니다. 리눅스에는 다양한 터미널 기반 에디터가 있으며, 그중 가장 대표적인 `nano`와 `vim`의 기초 사용법을 알아봅니다.

## 1. `nano`: 초보자를 위한 쉽고 친절한 에디터

- **철학**: "사용하기 쉬워야 한다." 직관적이며, 화면 하단에 항상 주요 단축키가 표시되어 있어 초보자가 사용하기에 매우 편리합니다.
- **언제 사용할까?**: 간단한 설정 파일을 빠르게 수정하거나, 아직 터미널 에디터가 익숙하지 않은 사용자에게 가장 적합합니다.

- **실행하기**: `nano [편집할 파일명]`
    ```bash
    # mynote.txt 라는 파일을 nano로 엽니다. (파일이 없으면 새로 생성)
    $ nano mynote.txt
    ```

- **기본 인터페이스**: 화면 대부분은 텍스트를 입력하는 공간이며, 아래 두 줄에는 `^` 기호와 함께 단축키가 표시됩니다. `^`는 `Ctrl` 키를 의미합니다. (예: `^X Exit`는 `Ctrl + X` 키를 누르면 종료된다는 뜻입니다.)

- **필수 단축키**:
    - `Ctrl + O` (Write **O**ut): 파일 **저장**. 파일 이름을 확인하고 `Enter`를 누릅니다.
    - `Ctrl + X` (E**x**it): **종료**. 저장하지 않은 변경 사항이 있으면 저장할지 물어봅니다.
    - `Ctrl + W` (**W**here is): 텍스트 **검색**.
    - `Ctrl + K` (**K**ut): 현재 커서가 있는 한 줄 **잘라내기**.
    - `Ctrl + U` (**U**ncut): 잘라낸 내용 **붙여넣기**.

## 2. `vim` (Vi IMproved): 전문가를 위한 강력한 에디터

- **철학**: "최대한 효율적으로." 키보드만으로 모든 작업을 수행할 수 있도록 설계되었습니다. 거의 모든 유닉스 계열 시스템에 기본적으로 설치되어 있어, 한 번 익혀두면 어디서든 유용하게 사용할 수 있습니다.
- **가장 큰 특징: 모드(Mode)**: `vim`에는 여러 가지 작업 모드가 있으며, 현재 모드에 따라 키보드의 역할이 바뀝니다. 이 "모드" 개념이 초보자에게 가장 큰 진입 장벽입니다.

### `vim`의 두 가지 핵심 모드

- **일반 모드 (Normal Mode)**
    - `vim`을 실행하면 가장 먼저 진입하는 기본 모드입니다.
    - 텍스트를 입력하는 모드가 **아니라**, 키보드 하나하나가 명령어(이동, 삭제, 복사 등)로 작동하는 모드입니다.

- **입력 모드 (Insert Mode)**
    - 우리가 흔히 생각하는 텍스트 에디터처럼, 글자를 입력할 수 있는 모드입니다.
    - 이 모드에 진입하면 화면 하단에 `-- INSERT --` 라는 표시가 나타납니다.

### `vim` 필수 사용법

1.  **실행하기**: `vim [편집할 파일명]`
    ```bash
    $ vim mynote.txt
    ```

2.  **모드 전환 (가장 중요!)**
    - 일반 모드에서 `i` 키를 누르면 **입력 모드**로 전환됩니다.
    - 어떤 모드에서든 `Esc` 키를 누르면 **일반 모드**로 돌아옵니다. `vim` 사용 중 "뭔가 이상하다" 싶으면 일단 `Esc`를 누르는 것이 좋습니다.

3.  **저장 및 종료 (일반 모드에서 실행)**
    - `vim`의 명령어는 일반 모드에서 콜론(`:`)을 입력하여 시작합니다.
    - `:w` (**w**rite): 파일 **저장**.
    - `:q` (**q**uit): **종료**.
    - `:wq`: **저장하고 종료**.
    - `:q!`: 변경 사항을 저장하지 않고 **강제 종료**.

4.  **기본 편집 (일반 모드에서 실행)**
    - `dd`: 현재 줄 **삭제** (잘라내기).
    - `yy`: 현재 줄 **복사** (yank).
    - `p`: 삭제하거나 복사한 내용 **붙여넣기** (paste).
    - `/` + `검색어` + `Enter`: 텍스트 **검색**.

### `vim` 처음 사용 시 겪는 문제: "종료를 못 하겠어요!"

대부분의 초보자는 글자를 입력하려고 아무 키나 누르다가 `vim`의 명령어들이 실행되어 당황하고, 저장이나 종료 방법을 몰라 터미널을 강제로 끄는 경우가 많습니다. `vim`을 종료하려면, **반드시 `Esc` 키를 눌러 일반 모드로 돌아온 뒤**, `:q` 또는 `:wq`를 입력해야 합니다.

## 3. `nano` vs. `vim`

| 구분 | `nano` | `vim` |
| :--- | :--- | :--- |
| **학습 난이도** | 매우 쉬움 | 어려움 |
| **편의성** | 직관적, 단축키 항상 표시 | 숙달 시 매우 빠르고 효율적 |
| **기능** | 기본적인 기능에 충실 | 막강한 기능 (매크로, 플러그인 등) |
| **설치 유무** | 기본 설치가 아닐 수 있음 | 거의 모든 시스템에 기본 설치 |

### 👨‍🏫 학습자를 위한 조언

- **우선 `nano`와 친해지세요.** 급하게 파일을 수정해야 할 때 당황하지 않고 작업을 마칠 수 있도록 `nano`의 기본 사용법(열기, 저장, 종료)은 꼭 익혀두는 것이 좋습니다.
- **`vim`은 꾸준히 연습하세요.** 처음에는 불편하고 어렵지만, 손에 익으면 마우스 없이 키보드만으로 모든 작업을 해결하는 `vim`의 효율성에 매료될 것입니다. 서버 관리자나 개발자를 목표로 한다면 `vim`은 선택이 아닌 필수 기술에 가깝습니다.
