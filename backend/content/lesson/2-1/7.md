# 2-1-7: 스트림, 리다이렉션, 파이프

리눅스 철학의 핵심은 "작고 단순한 도구들을 연결하여 복잡한 작업을 수행한다"는 것입니다. 이 철학을 가능하게 하는 것이 바로 표준 스트림, 리다이렉션, 그리고 파이프입니다.

## 1. 표준 스트림 (Standard Streams)

리눅스에서 명령어가 실행될 때, 기본적으로 3개의 통신 채널(스트림)이 열립니다.

- **표준 입력 (stdin, 0)**: 명령어가 데이터를 입력받는 통로입니다. 기본적으로 **키보드**에 연결됩니다.
- **표준 출력 (stdout, 1)**: 명령어가 정상적인 결과물을 출력하는 통로입니다. 기본적으로 **터미널 화면**에 연결됩니다.
- **표준 오류 (stderr, 2)**: 명령어가 에러 메시지를 출력하는 통로입니다. 기본적으로 **터미널 화면**에 연결됩니다.

## 2. 리다이렉션 (Redirection)

- **기능**: 표준 스트림의 기본 방향을 다른 곳(주로 파일)으로 바꾸는 기능입니다.

### 출력(stdout) 리다이렉션

명령어의 결과(표준 출력)를 화면 대신 파일에 저장하고 싶을 때 사용합니다.

- `>` (덮어쓰기): 지정된 파일이 존재하면 내용을 모두 지우고 새로 씁니다. 파일이 없으면 새로 생성합니다.
    ```bash
    # ls -l 명령어의 결과를 file_list.txt 파일에 저장 (덮어쓰기)
    $ ls -l > file_list.txt
    ```
- `>>` (이어붙이기): 지정된 파일이 존재하면 내용의 맨 끝에 이어서 씁니다. 파일이 없으면 새로 생성합니다.
    ```bash
    # application.log 파일에 새로운 로그 메시지를 추가
    $ echo "Server restarted at $(date)" >> application.log
    ```

### 오류(stderr) 리다이렉션

오류 메시지만을 별도의 파일에 저장하고 싶을 때 사용합니다. 스트림 번호 `2`를 사용합니다.

- `2>`: 표준 오류(2번 스트림)를 파일로 리다이렉션합니다.
    ```bash
    # find 명령 실행 시 발생하는 오류 메시지를 errors.txt 파일에 저장
    $ find /root -name "*.conf" 2> errors.txt
    ```

### 모든 출력 리다이렉션

표준 출력과 표준 오류를 하나의 파일에 모두 저장하고 싶을 때 사용합니다.

- `&>` 또는 `> ... 2>&1`: 두 스트림을 모두 리다이렉션합니다. `2>&1`은 "2번 스트림(stderr)을 1번 스트림(stdout)이 가는 곳으로 보내라"는 의미입니다.
    ```bash
    # 스크립트의 모든 출력(정상+오류)을 output.log 파일에 저장
    $ ./my_script.sh &> output.log
    $ ./my_script.sh > output.log 2>&1  # 위와 동일한 기능
    ```

### 입력(stdin) 리다이렉션

키보드 대신 파일의 내용을 명령어의 입력으로 사용하고 싶을 때 사용합니다.

- `<`: 파일의 내용을 표준 입력으로 사용합니다.
    ```bash
    # names.txt 파일의 내용을 sort 명령어의 입력으로 주어 정렬
    $ sort < names.txt
    ```

## 3. 파이프 (Pipe `|`)

- **기능**: **리눅스 CLI의 꽃.** 한 명령어의 표준 출력(stdout)을 다른 명령어의 표준 입력(stdin)으로 직접 연결하는 기능입니다. 여러 명령어를 체인처럼 엮어 복잡한 작업을 간단하게 처리할 수 있습니다.
- **비유**: 공장의 **컨베이어 벨트**와 같습니다. 첫 번째 공정의 결과물이 벨트를 타고 다음 공정의 입력으로 바로 들어갑니다.

- **사용법**: `명령어1 | 명령어2 | 명령어3 ...`

- **사용 예시**:
    ```bash
    # 1. ls -l의 결과가 너무 길 때, less로 넘겨서 페이지 단위로 보기
    $ ls -l /etc | less

    # 2. 현재 실행 중인 프로세스 목록에서 'bash'라는 단어가 포함된 행만 필터링하기
    $ ps -ef | grep "bash"

    # 3. history 명령어의 결과에서 'apt'를 포함하는 행을 찾아, 그중 마지막 5줄만 보기
    $ history | grep "apt" | tail -n 5
    ```

## 4. 명령 치환 (Command Substitution)

- **기능**: 명령어의 실행 결과를 다른 명령어의 **인자(argument)**로 사용하고 싶을 때 사용합니다.
- **사용법**: `$(명령어)` 또는 `` `명령어` `` (백틱)

- **동작 원리**: 셸은 `$(...)` 부분을 먼저 실행하여 그 결과(문자열)를 얻어낸 뒤, 그 문자열을 원래 명령어의 일부인 것처럼 치환하여 최종 명령어를 실행합니다.

- **사용 예시**:
    ```bash
    # 1. "오늘 날짜는 ... 입니다" 라고 출력하기
    $ echo "Today is $(date)"

    # 2. .conf로 끝나는 모든 설정 파일들을 찾아 한 번에 vim으로 열기
    # find 명령어의 결과(파일 경로 목록)가 vim 명령어의 인자로 사용된다.
    $ vim $(find . -name "*.conf")
    ```

이러한 기능들을 조합하면, 단순한 명령어 몇 개만으로도 매우 정교하고 강력한 작업들을 수행할 수 있게 됩니다.
