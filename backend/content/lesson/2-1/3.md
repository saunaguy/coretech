# 2-1-3: 텍스트 파일 내용 확인

리눅스 시스템의 설정 파일, 로그 파일, 소스 코드 등은 대부분 텍스트 파일 형태로 되어 있습니다. 따라서 파일의 내용을 빠르고 효율적으로 확인하는 것은 매우 중요한 기술입니다. 이번 장에서는 편집기를 열지 않고 파일 내용을 확인하는 다양한 명령어들을 배웁니다.

## 1. `cat` (concatenate)

- **기능**: 파일의 내용을 처음부터 끝까지 **한 번에** 화면에 출력합니다. 원래는 여러 파일을 합쳐서 출력하는 기능이지만, 단일 파일을 확인할 때도 많이 사용됩니다.
- **장점**: 파일 전체를 빠르게 훑어볼 수 있습니다.
- **단점**: 파일의 내용이 길 경우, 터미널 화면을 순식간에 뒤덮어 버려 앞부분의 내용을 볼 수 없습니다.
- **주요 옵션**:
    - `-n` (number): 각 행의 앞에 줄 번호를 붙여서 출력합니다.

- **사용 예시**:
    ```bash
    # /etc/passwd 파일의 전체 내용을 출력
    $ cat /etc/passwd

    # 각 행에 줄 번호를 붙여서 출력
    $ cat -n /etc/passwd
    ```

> **결론**: `cat`은 내용이 짧은 파일을 확인할 때 유용합니다.

## 2. `less`

- **기능**: `cat`의 단점을 보완한 명령어로, 파일의 내용을 **페이지 단위로** 나누어 보여줍니다. 위아래 스크롤, 검색 등 다양한 기능이 있어 **가장 많이 사용되고 권장되는** 파일 뷰어입니다.
- **이름의 유래**: 초창기에 있던 `more`라는 명령어보다 더 많은 기능을 제공한다는 의미에서 "less is more"라는 농담과 함께 `less`라는 이름이 붙었습니다.
- **사용법**: `less [파일명]`을 입력하면 `less` 전용 화면으로 전환됩니다.

- **주요 조작 키**:
    - `↑`, `↓`, `j`, `k`: 한 줄씩 위아래로 스크롤
    - `Space` 또는 `f`: 한 페이지 아래로 이동
    - `b`: 한 페이지 위로 이동
    - `/` + `검색어` + `Enter`: 아래 방향으로 텍스트 검색 (n: 다음 찾기, N: 이전 찾기)
    - `g`: 파일의 가장 첫 줄로 이동
    - `G`: 파일의 가장 마지막 줄로 이동
    - `q`: `less` 화면에서 빠져나오기

> **결론**: 내용이 긴 파일을 탐색하며 읽을 때 가장 강력하고 편리한 도구입니다.

## 3. `more`

- **기능**: `less`와 유사하게 페이지 단위로 파일을 보여주는 고전적인 명령어입니다.
- **`less`와의 차이점**: `less`와 달리 **아래로만 스크롤이 가능**하며, 이미 지나간 내용을 다시 보려면 종료 후 재실행해야 합니다. 기능이 매우 제한적입니다.
- **주요 조작 키**:
    - `Space`: 한 페이지 아래로 이동
    - `Enter`: 한 줄 아래로 이동
    - `q`: 종료

> **결론**: 대부분의 시스템에 `less`가 설치되어 있으므로, 특별한 이유가 없다면 `more` 대신 `less`를 사용하는 것이 좋습니다.

## 4. `head`

- **기능**: 파일의 **처음 일부분**만 보여줍니다. 기본값은 10줄입니다.
- **주요 옵션**:
    - `-n <숫자>` 또는 `-<숫자>`: 보고 싶은 줄의 개수를 지정합니다.

- **사용 예시**:
    ```bash
    # /var/log/syslog 파일의 첫 10줄을 확인
    $ head /var/log/syslog

    # /var/log/syslog 파일의 첫 5줄만 확인
    $ head -n 5 /var/log/syslog
    ```

## 5. `tail`

- **기능**: 파일의 **마지막 일부분**만 보여줍니다. 기본값은 10줄입니다. 시간이 지남에 따라 내용이 추가되는 로그 파일을 확인할 때 매우 유용합니다.
- **주요 옵션**:
    - `-n <숫자>`: 보고 싶은 줄의 개수를 지정합니다.
    - `-f` (follow): **`tail`의 핵심 기능입니다.** 파일의 끝부분을 보여준 채로 종료하지 않고, 파일에 새로운 내용이 추가될 때마다 그 내용을 **실시간으로 계속해서 화면에 출력**해줍니다. 중단하려면 `Ctrl + C`를 누릅니다.

- **사용 예시**:
    ```bash
    # /var/log/syslog 파일의 마지막 10줄을 확인
    $ tail /var/log/syslog

    # /var/log/syslog 파일의 마지막 100줄을 확인
    $ tail -n 100 /var/log/syslog

    # syslog 파일에 추가되는 로그를 실시간으로 모니터링
    $ tail -f /var/log/syslog
    ```

### 📝 명령어 요약

| 명령어 | 주요 기능 | 스크롤 | 사용 사례 |
| :--- | :--- | :--- | :--- |
| `cat` | 파일 전체를 한 번에 출력 | 불가능 | 내용이 매우 짧은 파일 확인 |
| `less` | 페이지 단위로 파일 탐색 | **양방향 가능** | **내용이 긴 파일(로그, 소스코드) 확인** |
| `more` | 페이지 단위로 파일 탐색 | 아래로만 가능 | `less`가 없는 아주 오래된 시스템 |
| `head` | 파일의 **첫 부분**만 확인 | 불가능 | 파일의 종류나 제목 등을 빠르게 확인할 때 |
| `tail` | 파일의 **마지막 부분**만 확인 | 불가능 | 최신 로그 확인, `-f` 옵션으로 실시간 로그 감시 |
