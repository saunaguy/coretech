# 2-1-1: 파일 및 디렉터리 관리

CLI 환경에서 가장 기본이 되는 작업은 파일과 디렉터리(폴더)를 생성, 조회, 복사, 이동, 삭제하는 것입니다. 이번 장에서는 이와 관련된 핵심 명령어들을 배웁니다.

## 1. `ls` (List)

- **기능**: 현재 위치의 파일 및 디렉터리 목록을 보여줍니다.
- **주요 옵션**:
    - `-l` (long): 권한, 소유자, 크기, 수정 날짜 등 상세 정보를 긴 형태로 보여줍니다.
    - `-a` (all): `.`으로 시작하는 숨김 파일 및 디렉터리를 포함한 모든 항목을 보여줍니다.
    - `-h` (human-readable): `-l` 옵션과 함께 사용하며, 파일 크기를 사람이 읽기 쉬운 단위(KB, MB, GB)로 보여줍니다.
    - `-F`: 항목의 종류를 표시해줍니다. (디렉터리는 `/`, 실행 파일은 `*`)

- **사용 예시**:
    ```bash
    # 현재 디렉터리의 목록을 상세 정보와 함께 표시
    $ ls -lh
    total 28K
    drwxr-xr-x 2 user user 4.0K Sep 24 10:00 Documents
    -rw-r--r-- 1 user user  22K Sep 23 15:30 report.txt
    ```

## 2. `mkdir` (Make Directory)

- **기능**: 새로운 디렉터리를 생성합니다.
- **주요 옵션**:
    - `-p` (parents): 경로상의 모든 중간 디렉터리들을 함께 생성합니다. 매우 유용한 옵션입니다.

- **사용 예시**:
    ```bash
    # 'backup' 이라는 이름의 디렉터리 생성
    $ mkdir backup

    # 한 번에 여러 단계의 하위 디렉터리 생성
    $ mkdir -p project/src/components
    ```

## 3. `touch`

- **기능**: 비어있는 새 파일을 생성하거나, 이미 파일이 존재할 경우 파일의 최종 수정 시간을 현재 시간으로 업데이트합니다.

- **사용 예시**:
    ```bash
    # 'note.txt' 라는 빈 파일 생성
    $ touch note.txt
    ```

## 4. `cp` (Copy)

- **기능**: 파일이나 디렉터리를 복사합니다.
- **사용법**: `cp [옵션] <원본> <대상>`
- **주요 옵션**:
    - `-r` (recursive): 디렉터리를 복사할 때 반드시 사용해야 하며, 디렉터리 내부의 모든 내용까지 재귀적으로 복사합니다.

- **사용 예시**:
    ```bash
    # note.txt 파일을 note_backup.txt 라는 이름으로 복사
    $ cp note.txt note_backup.txt

    # note.txt 파일을 backup/ 디렉터리 안으로 복사
    $ cp note.txt backup/

    # project/ 디렉터리 전체를 project_backup/ 이라는 이름으로 복사
    $ cp -r project/ project_backup/
    ```

## 5. `mv` (Move)

- **기능**: 파일이나 디렉터리를 다른 위치로 **이동**하거나, **이름을 변경**할 때 사용합니다.
- **사용법**: `mv [옵션] <원본> <대상>`

- **사용 예시**:
    ```bash
    # note.txt 파일의 이름을 report.txt 로 변경
    $ mv note.txt report.txt

    # report.txt 파일을 documents/ 디렉터리로 이동
    $ mv report.txt documents/

    # backup/ 디렉터리의 이름을 old_backup/ 으로 변경
    $ mv backup/ old_backup/
    ```

## 6. `rm` (Remove)

- **기능**: 파일이나 디렉터리를 삭제합니다.
- **⚠️ 경고**: `rm` 명령어는 휴지통 기능이 없습니다. 한 번 삭제하면 복구하기 매우 어렵거나 불가능하므로, 항상 신중하게 사용해야 합니다.
- **주요 옵션**:
    - `-i` (interactive): 삭제하기 전에 정말 삭제할 것인지 사용자에게 한 번 더 물어봅니다.
    - `-r` (recursive): 디렉터리와 그 안의 모든 내용을 재귀적으로 삭제합니다. 디렉터리를 삭제할 때는 반드시 필요합니다.
    - `-f` (force): 삭제 시 발생하는 경고나 질문을 무시하고 강제로 삭제합니다. **`-rf` 옵션은 매우 위험하므로 사용에 각별한 주의가 필요합니다.**

- **사용 예시**:
    ```bash
    # report.txt 파일을 삭제
    $ rm report.txt

    # 삭제 전 확인 메시지를 띄우며 파일 삭제
    $ rm -i report.txt
    rm: remove regular empty file 'report.txt'? y

    # old_backup/ 디렉터리와 그 안의 모든 내용을 삭제
    $ rm -r old_backup/

    # 절대로 따라하지 마세요! (시스템 전체를 삭제하려는 시도)
    # $ rm -rf /
    ```

### `ls`의 다양한 정렬 옵션

`ls -l`에 추가 옵션을 사용하여 원하는 기준으로 파일을 정렬할 수 있습니다.

- **`-t`**: 수정된 시간 순서대로 정렬 (최신 파일이 위로)
- **`-S`**: 파일 크기 순서대로 정렬 (가장 큰 파일이 위로)
- **`-r`**: 정렬 순서를 역순으로 변경 (예: `ls -ltr`은 가장 오래된 파일부터 보여줌)

```bash
# /etc 디렉터리에서 가장 최근에 수정된 파일 5개 보기
$ ls -lt /etc | head -n 5

# 현재 디렉터리에서 가장 용량이 큰 파일 순서로 보기
$ ls -lSh
```

### `cp`와 `mv` 진행 상황 확인

대용량 파일을 복사하거나 이동할 때 `rsync` 명령어를 사용하면 진행 상황을 볼 수 있어 유용합니다.

```bash
# -a: 아카이브 모드 (권한, 소유권 등 보존)
# -h: 사람이 읽기 쉬운 형식
# --progress: 진행 상황 표시
$ rsync -ah --progress large_video.mp4 /mnt/backup/
```

### `rm`을 안전하게: `trash-cli`

`rm`은 파일을 영구적으로 삭제하여 위험합니다. `trash-cli`는 파일을 휴지통으로 보내는 기능을 제공하여 실수를 방지할 수 있습니다.

```bash
# 설치 (Node.js 환경 필요)
$ npm install --global trash-cli

# 파일 및 디렉터리를 휴지통으로 보내기
$ trash put sensitive_file.txt old_directory/

# 휴지통 목록 보기
$ trash list

# 휴지통 비우기
$ trash empty
```

### `ls`를 넘어: `eza` (구 `exa`)

`eza`는 `ls`를 대체하는 현대적인 도구로, 더 나은 색상 구분, Git 연동, 아이콘 표시 등 다양한 편의 기능을 제공합니다.

```bash
# 설치 (Debian/Ubuntu 기준)
$ sudo apt install eza

# 기본 사용법 (ls와 유사)
$ eza -l --icons --git --header
```
- `-l`: 상세 목록
- `--icons`: 파일 종류에 맞는 아이콘 표시
- `--git`: Git 상태 표시
- `--header`: 각 열의 제목 표시

### 링크 파일: 단순 복사가 아닌 '바로가기'

`ln` 명령어를 사용하면 원본 파일을 복사하지 않고, 해당 파일을 가리키는 '링크'를 만들 수 있습니다.

- **심볼릭 링크 (Symbolic Link, `-s`)**: 원본 파일의 경로를 가리키는 '바로가기'와 유사합니다. 원본이 삭제되면 링크는 깨집니다.
    ```bash
    # /var/log/syslog 파일을 홈 디렉터리에 syslog.log라는 이름으로 링크
    $ ln -s /var/log/syslog ~/syslog.log
    ```
- **하드 링크 (Hard Link)**: 원본 파일과 동일한 데이터 블록을 가리키는 또 다른 파일 이름을 만듭니다. 원본이 삭제되어도 다른 링크가 남아있으면 데이터는 유지됩니다. (단, 디렉터리에는 사용 불가)
    ```bash
    $ ln original.txt hardlink.txt
    ```
