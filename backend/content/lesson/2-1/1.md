# 2-1-1: 파일 및 디렉터리 관리

CLI 환경에서 가장 기본이 되는 작업은 파일과 디렉터리(폴더)를 생성, 조회, 복사, 이동, 삭제하는 것입니다. 이번 장에서는 이와 관련된 핵심 명령어들을 배웁니다.

## 1. `ls` (List)

- **기능**: 현재 위치의 파일 및 디렉터리 목록을 보여줍니다.
- **주요 옵션**:
    - `-l` (long): 권한, 소유자, 크기, 수정 날짜 등 상세 정보를 긴 형태로 보여줍니다.
    - `-a` (all): `.`으로 시작하는 숨김 파일 및 디렉터리를 포함한 모든 항목을 보여줍니다.
    - `-h` (human-readable): `-l` 옵션과 함께 사용하며, 파일 크기를 사람이 읽기 쉬운 단위(KB, MB, GB)로 보여줍니다.
    - `-F`: 항목의 종류를 표시해줍니다. (디렉터리는 `/`, 실행 파일은 `*`)

- **사용 예시**:
    ```bash
    # 현재 디렉터리의 목록을 상세 정보와 함께 표시
    $ ls -lh
    total 28K
    drwxr-xr-x 2 user user 4.0K Sep 24 10:00 Documents
    -rw-r--r-- 1 user user  22K Sep 23 15:30 report.txt
    ```

## 2. `mkdir` (Make Directory)

- **기능**: 새로운 디렉터리를 생성합니다.
- **주요 옵션**:
    - `-p` (parents): 경로상의 모든 중간 디렉터리들을 함께 생성합니다. 매우 유용한 옵션입니다.

- **사용 예시**:
    ```bash
    # 'backup' 이라는 이름의 디렉터리 생성
    $ mkdir backup

    # 한 번에 여러 단계의 하위 디렉터리 생성
    $ mkdir -p project/src/components
    ```

## 3. `touch`

- **기능**: 비어있는 새 파일을 생성하거나, 이미 파일이 존재할 경우 파일의 최종 수정 시간을 현재 시간으로 업데이트합니다.

- **사용 예시**:
    ```bash
    # 'note.txt' 라는 빈 파일 생성
    $ touch note.txt
    ```

## 4. `cp` (Copy)

- **기능**: 파일이나 디렉터리를 복사합니다.
- **사용법**: `cp [옵션] <원본> <대상>`
- **주요 옵션**:
    - `-r` (recursive): 디렉터리를 복사할 때 반드시 사용해야 하며, 디렉터리 내부의 모든 내용까지 재귀적으로 복사합니다.

- **사용 예시**:
    ```bash
    # note.txt 파일을 note_backup.txt 라는 이름으로 복사
    $ cp note.txt note_backup.txt

    # note.txt 파일을 backup/ 디렉터리 안으로 복사
    $ cp note.txt backup/

    # project/ 디렉터리 전체를 project_backup/ 이라는 이름으로 복사
    $ cp -r project/ project_backup/
    ```

## 5. `mv` (Move)

- **기능**: 파일이나 디렉터리를 다른 위치로 **이동**하거나, **이름을 변경**할 때 사용합니다.
- **사용법**: `mv [옵션] <원본> <대상>`

- **사용 예시**:
    ```bash
    # note.txt 파일의 이름을 report.txt 로 변경
    $ mv note.txt report.txt

    # report.txt 파일을 documents/ 디렉터리로 이동
    $ mv report.txt documents/

    # backup/ 디렉터리의 이름을 old_backup/ 으로 변경
    $ mv backup/ old_backup/
    ```

## 6. `rm` (Remove)

- **기능**: 파일이나 디렉터리를 삭제합니다.
- **⚠️ 경고**: `rm` 명령어는 휴지통 기능이 없습니다. 한 번 삭제하면 복구하기 매우 어렵거나 불가능하므로, 항상 신중하게 사용해야 합니다.
- **주요 옵션**:
    - `-i` (interactive): 삭제하기 전에 정말 삭제할 것인지 사용자에게 한 번 더 물어봅니다.
    - `-r` (recursive): 디렉터리와 그 안의 모든 내용을 재귀적으로 삭제합니다. 디렉터리를 삭제할 때는 반드시 필요합니다.
    - `-f` (force): 삭제 시 발생하는 경고나 질문을 무시하고 강제로 삭제합니다. **`-rf` 옵션은 매우 위험하므로 사용에 각별한 주의가 필요합니다.**

- **사용 예시**:
    ```bash
    # report.txt 파일을 삭제
    $ rm report.txt

    # 삭제 전 확인 메시지를 띄우며 파일 삭제
    $ rm -i report.txt
    rm: remove regular empty file 'report.txt'? y

    # old_backup/ 디렉터리와 그 안의 모든 내용을 삭제
    $ rm -r old_backup/

    # 절대로 따라하지 마세요! (시스템 전체를 삭제하려는 시도)
    # $ rm -rf /
    ```

### ✏️ 연습 문제

터미널에서 직접 다음 시나리오를 따라 해보세요.

1.  `my_project` 라는 디렉터리를 만드세요.
2.  `cd` 명령어로 `my_project` 디렉터리 안으로 이동하세요.
3.  `src` 와 `docs` 라는 두 개의 하위 디렉터리를 만드세요.
4.  `touch` 명령어로 `docs` 디렉터리 안에 `readme.md` 파일을 만드세요. (`touch docs/readme.md`)
5.  `ls -lR` 명령어로 현재 디렉터리 구조 전체를 확인해보세요. (`-R`은 하위 디렉터리까지 모두 보여주는 옵션입니다.)
6.  `docs/readme.md` 파일을 `src/` 디렉터리로 복사하세요.
7.  `src/readme.md` 파일의 이름을 `app.js`로 변경하세요.
8.  `docs/readme.md` 파일을 삭제하세요.
9.  `cd ..` 명령어로 상위 디렉터리로 나온 뒤, `rm -r my_project/` 명령어로 프로젝트 디렉터리 전체를 삭제하세요.
