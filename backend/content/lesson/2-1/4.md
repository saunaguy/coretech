# 2-1-4: 도움말 명령어 (`man`, `help`)

수백 개가 넘는 리눅스 명령어를 모두 외우는 것은 불가능하며, 그럴 필요도 없습니다. 중요한 것은 필요할 때 원하는 정보를 스스로 찾아내는 능력입니다. 리눅스는 강력한 내장 도움말 시스템을 갖추고 있습니다.

## 1. `man` (Manual)

- **기능**: 리눅스 명령어, 설정 파일, 시스템 콜 등에 대한 **공식 설명서(Manual)**를 보여주는, **가장 중요하고 포괄적인 도움말 명령어**입니다.
- **사용법**: `man [찾고 싶은 대상]`

- **`man ls` 실행해보기**: `ls` 명령어의 설명서를 확인해봅시다.
    ```bash
    $ man ls
    ```
    `less`와 동일한 인터페이스가 나타나며, 키보드로 스크롤하고 `q` 키로 종료할 수 있습니다.

### 맨 페이지(Man Page)의 구조

맨 페이지는 표준화된 구조를 가지고 있어 원하는 정보를 쉽게 찾을 수 있습니다.

- `NAME`: 명령어의 이름과 한 줄 요약 설명.
- `SYNOPSIS`: 명령어의 문법 구조. `[ ]`는 생략 가능한 항목을 의미합니다.
- `DESCRIPTION`: 명령어가 무엇을 하는지에 대한 상세한 설명.
- `OPTIONS`: **가장 자주 보게 될 부분**으로, 사용 가능한 모든 옵션에 대한 설명이 나열되어 있습니다.
- `EXAMPLES`: 실제 사용 예시.
- `SEE ALSO`: 함께 보면 좋은 관련 명령어들이나 주제.

### 맨 페이지의 섹션

맨 페이지는 내용에 따라 여러 섹션으로 나뉘어 있습니다. 가끔 이름이 같은 다른 주제가 있을 수 있어 섹션 번호로 구분하기도 합니다.

- `1`: 일반 사용자 명령어
- `5`: 설정 파일의 형식
- `8`: 시스템 관리자용 명령어

예를 들어, `passwd`라는 이름은 사용자 암호를 바꾸는 '명령어'이기도 하고, 사용자 정보가 담긴 '/etc/passwd'라는 '설정 파일'이기도 합니다. 이 둘을 구분해서 보려면 다음과 같이 섹션 번호를 명시할 수 있습니다.

```bash
# 1번 섹션의 passwd 명령어 설명서를 확인
$ man 1 passwd

# 5번 섹션의 /etc/passwd 파일 형식 설명서를 확인
$ man 5 passwd
```

## 2. `--help` 옵션

- **기능**: 대부분의 명령어는 `--help` 옵션을 지원합니다. `man` 페이지처럼 상세하지는 않지만, 해당 명령어의 **사용법과 주요 옵션들을 간략하게 요약**해서 터미널에 바로 보여줍니다.
- **사용법**: `[명령어] --help`

- **`man` 과 `--help` 의 차이**
    - **`--help`**: "이 명령어 옵션이 뭐였더라?" 처럼, 이미 아는 명령어의 옵션을 잠시 확인하고 싶을 때 **빠르게** 사용합니다.
    - **`man`**: 해당 명령어를 처음 보거나, 그 기능 전체를 **깊이 있게** 이해하고 싶을 때 사용합니다.

- **사용 예시**:
    ```bash
    $ ls --help
    $ mkdir --help
    $ cp --help
    ```

## 3. `help` (셸 내장 명령어용)

- **기능**: `cd`, `if`, `for` 와 같이, 셸 자체에 포함된 **셸 내장(built-in) 명령어**에 대한 도움말을 보여줍니다.
- **`man` 과의 차이**: `ls`나 `cp` 같은 일반 명령어는 `/bin/ls`, `/bin/cp` 처럼 별도의 파일로 존재하지만, 셸 내장 명령어는 셸 프로그램의 일부입니다. 따라서 `man`으로는 찾을 수 없거나, 정보가 부족할 수 있습니다. 이럴 때 `help`를 사용합니다.

- **내장 명령어 확인법**: `type` 명령어를 사용하면 해당 명령어가 내장 명령어인지, 외부 파일인지 확인할 수 있습니다.
    ```bash
    $ type ls
    ls is aliased to 'ls --color=auto'
    $ type /bin/ls
    /bin/ls is /bin/ls

    $ type cd
    cd is a shell builtin
    ```

- **사용 예시**:
    ```bash
    # cd 명령어에 대한 도움말 확인
    $ help cd
    ```

## 4. `apropos` (or `man -k`)

- **기능**: "파일을 복사하고 싶은데, 명령어가 뭐였지?" 처럼, **정확한 명령어 이름이 기억나지 않을 때** 키워드를 통해 관련 명령어를 검색해줍니다.
- **동작 원리**: 모든 맨 페이지의 `NAME` 섹션(한 줄 요약 설명)에서 키워드를 검색하여 일치하는 목록을 보여줍니다.

- **사용 예시**:
    ```bash
    # "copy files" 라는 키워드로 관련 명령어를 검색
    $ apropos "copy files"
    cp (1)               - copy files and directories

    # "rename" 이라는 키워드로 관련 명령어를 검색
    $ apropos "rename"
    mv (1)               - move (rename) files
    rename (1)           - rename files
    ```

### 💡 도움말 활용 전략

1.  **명령어 이름은 아는데, 옵션이 가물가물하다** → `[명령어] --help`
2.  **명령어를 처음 보거나, 자세히 알고 싶다** → `man [명령어]`
3.  **`cd`나 `for`문 같은 셸 기능이 궁금하다** → `help [셸 내장 명령어]`
4.  **내가 하려는 작업은 있는데, 명령어 이름이 생각나지 않는다** → `apropos [키워드]`
