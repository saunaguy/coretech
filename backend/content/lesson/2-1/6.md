# 2-1-6: 셸(Shell) 편의 기능: 자동 완성, 와일드카드, 히스토리, 별칭

리눅스 셸은 단순히 명령어를 실행하는 것을 넘어, 사용자의 편의를 위한 강력하고 다양한 기능들을 내장하고 있습니다. 이 기능들을 잘 활용하면 CLI 작업의 속도와 효율을 극적으로 높일 수 있습니다.

## 1. 탭 자동 완성 (Tab Completion)

**CLI 생산성의 핵심**이라고 할 수 있는 가장 중요하고 기본적인 기능입니다.

- **기능**: 명령어, 파일, 디렉터리 이름의 일부만 입력하고 `Tab` 키를 누르면, 셸이 나머지 부분을 자동으로 완성해줍니다.
- **장점**: 긴 파일 이름을 일일이 입력할 필요가 없어 오타를 줄여주고, 타이핑 속도를 비약적으로 향상시킵니다.
- **사용법**:
    - `docu` 입력 후 `Tab` → `documents/` 로 자동 완성
    - 만약 `docu`로 시작하는 항목이 여러 개 있다면, 아무 일도 일어나지 않습니다. 이때 `Tab` 키를 한 번 더 누르면, 가능한 모든 목록을 보여줍니다.

> 💡 **습관**: 항상 `Tab` 키를 사용하는 습관을 들이는 것이 좋습니다. 파일이나 디렉터리 경로를 끝까지 직접 입력하는 것은 비효율적입니다.

## 2. 글로빙과 와일드카드 (Globbing & Wildcards)

- **기능**: 와일드카드(Wildcard)라는 특수 문자를 사용하여, 여러 개의 파일을 한 번에 지정하는 패턴을 만드는 기능입니다. 셸은 명령어가 실행되기 *전에* 이 패턴을 보고, 일치하는 모든 파일 이름의 목록으로 바꿔치기(확장)합니다. 이 과정을 **글로빙(Globbing)**이라고 합니다.

- **주요 와일드카드**:
    - `*` (별표, Asterisk): **0개 이상의 모든 문자**와 일치합니다. 가장 널리 사용됩니다.
        - `ls *.log`: `.log`로 끝나는 모든 파일 목록을 보여줍니다.
        - `rm report_*`: `report_`로 시작하는 모든 파일을 삭제합니다.

    - `?` (물음표, Question Mark): **정확히 1개의 아무 문자**와 일치합니다.
        - `ls report_?.txt`: `report_1.txt`, `report_A.txt`와는 일치하지만, `report_10.txt`와는 일치하지 않습니다.

    - `[ ]` (대괄호, Brackets): 괄호 안에 포함된 **문자 중 하나**와 일치합니다. 범위를 지정할 수도 있습니다.
        - `ls [abc].txt`: `a.txt`, `b.txt`, `c.txt` 파일과 일치합니다.
        - `ls item_[0-9].log`: `item_0.log`부터 `item_9.log`까지의 파일과 일치합니다.

## 3. 명령어 히스토리 (Command History)

- **기능**: 셸은 사용자가 입력했던 명령어들을 기억하고 있으며, 이를 쉽게 다시 불러와 사용할 수 있도록 도와줍니다.

- **주요 활용법**:
    - `↑` / `↓` (위/아래 화살표 키): 이전에 입력했던 명령어를 시간 순서대로 탐색합니다.
    - `history`: 지금까지 입력한 명령어 전체 목록을 번호와 함께 출력합니다.
    - `!n`: `history` 목록의 `n`번째 명령어를 실행합니다. (예: `!123`)
    - `!!`: 바로 직전에 실행했던 명령어를 재실행합니다.
    - `Ctrl + R`: **(강력 추천)** **역방향 검색(reverse-i-search)** 기능입니다. 이 키를 누르고 기억나는 명령어의 일부(예: `cp`)를 입력하면, 해당 단어가 포함된 가장 최근의 명령어를 찾아줍니다. `Ctrl + R`을 반복해서 누르면 더 이전의 기록을 계속 탐색할 수 있습니다.

## 4. 별칭 (Alias)

- **기능**: 길고 복잡한 명령어를 더 짧고 간단한 나만의 명령어로 만들어 사용하는 기능입니다.

- **사용법**: `alias [별칭이름]='[실행할 명령어]'`

- **임시 별칭 만들기**:
    ```bash
    # ls -lhF 명령어를 ll 이라는 이름으로 사용하고 싶을 때
    $ alias ll='ls -lhF'

    # 이제 ll만 입력해도 ls -lhF가 실행된다.
    $ ll
    ```

- **별칭 영구적으로 만들기**:
    - 터미널에서 만든 별칭은 해당 세션이 종료되면 사라집니다. 별칭을 계속 사용하려면, 셸이 시작될 때마다 읽어들이는 설정 파일에 등록해야 합니다.
    - `bash` 셸의 경우, 이 파일은 보통 홈 디렉터리의 `~/.bashrc` 입니다.
    1.  `nano ~/.bashrc` 명령어로 파일을 엽니다.
    2.  파일의 맨 아래에 `alias ll='ls -lhF'` 와 같은 줄을 추가합니다.
    3.  `Ctrl+O`로 저장하고 `Ctrl+X`로 종료합니다.
    4.  `source ~/.bashrc` 명령어를 실행하거나, 새 터미널을 열면 별칭이 적용됩니다.

- **별칭 해제**: `unalias [별칭이름]`
    ```bash
    $ unalias ll
    ```
