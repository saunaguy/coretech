# 4-5-1: 고가용성/고급 토폴로지: VLAN/Trunk, Bonding/Teaming

단순한 네트워크 구성을 넘어, 대규모 환경에서는 네트워크를 논리적으로 분리하고, 여러 개의 물리적 연결을 묶어 성능과 안정성을 높이는 고급 기술들이 사용됩니다. VLAN과 Bonding은 이러한 고급 네트워크 토폴로지의 가장 기본이 되는 기술입니다.

## 1. VLAN (Virtual LAN)

- **개념**: VLAN은 물리적인 스위치 하나를, 마치 여러 개의 독립된 스위치인 것처럼 **논리적으로 분할**하는 기술입니다. 각 VLAN은 고유한 ID(VLAN ID)를 가지며, 같은 VLAN에 속한 장치들끼리만 통신할 수 있습니다. 서로 다른 VLAN 간의 통신은 반드시 라우터(L3 장비)를 거쳐야 합니다.

- **동작 원리**: 이더넷 프레임에 **VLAN 태그(Tag)**라는 추가 정보를 붙여, 이 프레임이 어떤 VLAN에 속하는지를 구분합니다. (IEEE 802.1Q 표준)

- **장점**:
    - **브로드캐스트 도메인 분리**: VLAN을 나누면, 한 VLAN 내에서 발생한 브로드캐스트 트래픽이 다른 VLAN으로 전파되지 않습니다. 이는 불필요한 트래픽을 줄여 네트워크 전체의 성능을 향상시킵니다.
    - **보안 강화**: 부서별(인사, 개발, 재무) 또는 서버 역할별(웹, WAS, DB)로 VLAN을 분리하여, 허가되지 않은 장치 간의 접근을 원천적으로 차단할 수 있습니다. 예를 들어, 웹 서버는 DB 서버와 통신이 필요하지만, 일반 사용자 PC는 DB 서버에 직접 접근할 필요가 없습니다.
    - **유연한 네트워크 구성**: 물리적인 위치와 상관없이, 스위치 설정 변경만으로 장치를 원하는 논리적 네트워크에 쉽게 포함시키거나 제외할 수 있습니다.

### Trunk Port 와 Access Port

- **Access Port**: **하나의 VLAN**에만 속하는 포트입니다. 주로 PC나 서버와 같은 최종 장치(End-device)를 연결하는 데 사용됩니다. 이 포트를 통과하는 프레임에는 VLAN 태그가 붙지 않습니다.
- **Trunk Port**: **여러 개의 VLAN** 트래픽을 동시에 전송할 수 있는 포트입니다. 주로 스위치와 스위치, 또는 스위치와 라우터를 연결하는 데 사용됩니다. Trunk 포트를 통과하는 프레임에는 어떤 VLAN에 속하는지를 나타내는 VLAN 태그가 반드시 포함되어야 합니다.

## 2. Bonding / Teaming (Link Aggregation)

- **개념**: 여러 개의 물리적 네트워크 인터페이스(NIC)를 하나의 논리적인 인터페이스로 묶어, **대역폭을 늘리거나(Performance)**, 하나의 인터페이스에 장애가 발생해도 다른 인터페이스를 통해 통신을 유지하는 **고가용성(High Availability)**을 제공하는 기술입니다. 링크 통합(Link Aggregation)이라고도 불립니다.

- **리눅스에서의 구현**: 전통적으로 **Bonding** 드라이버가 사용되었으며, 최신 시스템에서는 더 유연하고 확장성 있는 **Teaming** 드라이버가 사용됩니다.

### Bonding/Teaming의 주요 모드

- **`mode=0` (Round-robin)**: 묶인 인터페이스들로 패킷을 순서대로 돌아가며 전송합니다. 부하 분산과 장애 극복을 모두 제공하지만, 패킷 순서가 바뀔 수 있어 TCP 통신에는 적합하지 않을 수 있습니다.

- **`mode=1` (Active-backup)**: 가장 널리 사용되는 고가용성 모드입니다. 오직 하나의 인터페이스(Active)만 활성화되어 통신하며, 이 인터페이스에 장애가 발생하면 즉시 다른 대기 중인 인터페이스(Backup)가 통신을 이어받습니다(Failover). 대역폭은 늘어나지 않지만, 네트워크 연결의 안정성을 크게 높여줍니다.

- **`mode=4` (802.3ad, LACP)**: LACP(Link Aggregation Control Protocol)라는 표준 프로토콜을 사용하여 스위치와 동적으로 링크 통합을 협상합니다. 부하 분산과 장애 극복을 모두 제공하며, 연결된 스위치에서도 해당 포트들을 LACP로 설정해야 합니다. 가장 이상적인 방식이지만, 스위치의 지원이 필요합니다.

- **`mode=6` (Adaptive Load Balancing)**: 스위치의 특별한 설정 없이도, 나가는 트래픽은 분산하고 들어오는 트래픽은 하나의 인터페이스로 받는 등 커널 레벨에서 지능적으로 부하를 분산합니다.

### 설계 시 고려사항

- **VLAN과 Bonding 연계**: 서버에 여러 개의 네트워크 연결이 필요할 때(예: 서비스망, 관리망, 스토리지망), 물리적 NIC를 여러 개 장착하는 대신, Bonding으로 묶인 고대역폭/고가용성 링크 위에 여러 개의 VLAN 인터페이스를 생성하여 논리적으로 망을 분리하는 것이 현대적인 데이터 센터의 일반적인 구성 방식입니다.
  `물리적 NIC 2개 → Bonding (bond0) → VLAN 인터페이스 3개 (bond0.10, bond0.20, bond0.30)`

- **스위치 이중화**: 진정한 고가용성을 위해서는 서버의 NIC뿐만 아니라, 각 NIC가 연결되는 물리적인 스위치 자체도 이중화(두 대 이상)하여, 하나의 스위치가 고장 나더라도 전체 네트워크가 중단되지 않도록 구성해야 합니다. (이를 MC-LAG, vPC 등 벤더별 기술로 구현합니다.)

VLAN과 Bonding은 물리적인 제약을 넘어, 논리적으로 네트워크를 유연하게 구성하고 안정성과 성능을 극대화하는 데이터 센터 네트워킹의 핵심 기술입니다.
