# 4-1-2: 인터페이스 관리: `ip`/`nmcli`, 주소/링크/라우트

서버의 네트워크를 설정하고 관리하는 것은 IP 주소를 할당하고, 인터페이스를 활성화하며, 외부와 통신하기 위한 경로(route)를 지정하는 작업을 포함합니다. 리눅스에서는 이러한 작업을 위한 여러 도구를 제공하며, 최신 시스템에서는 `ip`와 `nmcli`가 주로 사용됩니다.

## 1. `ip` (iproute2): 강력한 저수준 도구

`ip` 명령어는 `ifconfig`, `route` 등 전통적인 네트워크 도구들을 대체하는 `iproute2` 패키지의 핵심 도구입니다. 커널의 네트워크 스택과 직접 상호작용하며, 네트워크의 거의 모든 측면을 제어할 수 있습니다.

### `ip link`: 네트워크 인터페이스(L2) 관리
- **기능**: 네트워크 인터페이스의 물리적 계층(L2) 속성을 확인하고 변경합니다. (MAC 주소, MTU, 상태 등)

  ```bash
  # 모든 인터페이스의 정보 보기
  ip link show

  # 특정 인터페이스(eth0)의 상태를 UP/DOWN으로 변경
  sudo ip link set eth0 up
  sudo ip link set eth0 down

  # MTU 크기 변경
  sudo ip link set eth0 mtu 1400
  ```

### `ip addr`: IP 주소(L3) 관리
- **기능**: 네트워크 인터페이스에 IP 주소(L3)를 할당, 삭제, 확인합니다.

  ```bash
  # 모든 인터페이스의 IP 주소 정보 보기
  ip addr show
  # 또는 ip a

  # eth0 인터페이스에 IP 주소 추가
  sudo ip addr add 192.168.1.100/24 dev eth0

  # eth0 인터페이스에서 IP 주소 삭제
  sudo ip addr del 192.168.1.100/24 dev eth0
  ```

### `ip route`: 라우팅 테이블(L3) 관리
- **기능**: IP 패킷이 목적지까지 찾아가기 위한 경로 정보, 즉 라우팅 테이블을 확인하고 관리합니다.

  ```bash
  # 현재 라우팅 테이블 보기
  ip route show
  # 또는 ip r

  # 기본 게이트웨이(default gateway) 추가
  # 모든 트래픽은 기본적으로 192.168.1.1 라우터를 통해 나감
  sudo ip route add default via 192.168.1.1

  # 특정 네트워크(10.0.0.0/8)로 가는 정적 경로 추가
  sudo ip route add 10.0.0.0/8 via 192.168.1.254
  ```

**주의**: `ip` 명령어로 변경한 설정은 **일시적**이며, 시스템을 재부팅하면 사라집니다. 영구적인 설정은 각 배포판의 네트워크 설정 파일이나 `NetworkManager`를 통해 이루어져야 합니다.

## 2. `nmcli`: NetworkManager의 커맨드라인 인터페이스

`NetworkManager`는 데스크톱과 서버 환경 모두에서 네트워크 설정을 동적이고 지속적으로 관리해주는 표준 서비스입니다. `nmcli`는 이 `NetworkManager`를 제어하는 커맨드라인 도구로, `ip` 명령어보다 더 사용자 친화적이며 영구적인 설정을 쉽게 할 수 있습니다.

### `nmcli`의 객체 모델
`nmcli`는 `connection`과 `device`라는 두 가지 주요 객체를 관리합니다.
- **`device`**: 실제 물리적/논리적 네트워크 인터페이스 (예: `eth0`).
- **`connection`**: IP 주소, 게이트웨이, DNS 서버 등 인터페이스에 적용될 설정들의 묶음 (프로필). 하나의 `device`는 여러 `connection` 프로필을 가질 수 있으며, 한 번에 하나만 활성화됩니다.

### 주요 `nmcli` 명령어

- **상태 확인**:
  ```bash
  # 전체 네트워크 상태 보기
  nmcli general status

  # device 목록과 상태 보기
  nmcli device status

  # connection 프로필 목록 보기
  nmcli connection show
  ```

- **Connection 프로필 수정 (영구 설정)**:
  `nmcli connection modify [프로필이름] [설정] [값]`

  ```bash
  # "System eth0" 프로필의 IP 주소를 수동으로 설정
  sudo nmcli connection modify "System eth0" ipv4.method manual
  sudo nmcli connection modify "System eth0" ipv4.addresses 192.168.1.100/24
  sudo nmcli connection modify "System eth0" ipv4.gateway 192.168.1.1
  sudo nmcli connection modify "System eth0" ipv4.dns "8.8.8.8 8.8.4.4"

  # 변경 사항을 적용하기 위해 connection을 다시 활성화
  sudo nmcli connection up "System eth0"
  ```

- **새로운 Connection 프로필 생성**:
  ```bash
  # eth1 장치를 위한 새로운 프로필 "my-office" 생성 (DHCP 자동 할당)
  sudo nmcli connection add type ethernet con-name my-office ifname eth1
  ```

### `ip` vs `nmcli`

| 구분 | `ip` (iproute2) | `nmcli` (NetworkManager) |
| --- | --- | --- |
| **역할** | 저수준 커널 네트워크 스택 제어 | 고수준 네트워크 설정 관리 서비스 |
| **지속성** | 일시적 (재부팅 시 초기화) | 영구적 (설정이 파일로 저장됨) |
| **사용 편의성** | 다소 복잡하고 문법이 어려움 | 더 직관적이고 사용자 친화적 |
| **주요 용도** | 스크립트, 임시 테스트, 네트워크 상태의 상세 분석 | 서버 및 데스크톱의 영구적인 네트워크 설정 관리 |

**결론**: 서버의 IP 주소나 게이트웨이를 영구적으로 변경해야 할 때는 `nmcli` (또는 RHEL 계열의 `nmtui`, 설정 파일 직접 편집)를 사용하는 것이 올바른 방법입니다. `ip` 명령어는 현재 시스템의 네트워크 상태를 확인하거나, 재부팅 없이 임시로 설정을 변경하여 테스트하는 용도로 매우 유용합니다.
