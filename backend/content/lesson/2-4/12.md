# 2-4-12: 디스크 용량 분석 (`df`, `du`, `ncdu`)

서버의 디스크 공간이 가득 차면 서비스가 중단되거나 데이터가 유실될 수 있으므로, 주기적으로 디스크 사용량을 확인하고 관리하는 것은 매우 중요합니다. 리눅스는 디스크 용량을 전체적으로, 그리고 디렉터리별로 분석하는 효율적인 도구들을 제공합니다.

## 1. `df`: 전체 디스크(파일 시스템) 사용량 확인

- **기능**: `df` (disk free)는 시스템에 마운트된 전체 파일 시스템 각각의 총 용량, 사용 중인 용량, 사용 가능한 용량, 사용률 등을 보여줍니다.

- **주요 옵션**:
    - `-h` (human-readable): 용량을 사람이 읽기 쉬운 단위(K, M, G)로 보여줍니다. 거의 항상 사용됩니다.
    - `-T` (print-type): 파일 시스템의 타입(xfs, ext4 등)을 함께 보여줍니다.
    - `-i`: 용량 대신 아이노드(inode)의 사용량을 보여줍니다. (파일 수가 매우 많은 경우 용량은 남아도 아이노드가 부족해 파일을 더 생성하지 못할 수 있습니다.)

- **사용법**:
  ```bash
  $ df -hT
  Filesystem     Type      Size  Used Avail Use% Mounted on
  /dev/sda1      xfs        50G  10G   40G  20% /
  /dev/sdb1      ext4      100G  80G   20G  80% /data
  tmpfs          tmpfs     1.9G    0  1.9G   0% /dev/shm
  ```
  - `Use%`: 사용률. 이 값이 90%를 넘어가면 주의 깊게 살펴봐야 합니다.
  - `Mounted on`: 마운트된 위치.

## 2. `du`: 특정 디렉터리/파일의 용량 확인

- **기능**: `du` (disk usage)는 특정 파일이나 디렉터리가 차지하고 있는 디스크 용량을 계산하여 보여줍니다. 어떤 디렉터리가 용량을 많이 차지하는지 추적해 나갈 때 사용됩니다.

- **주요 옵션**:
    - `-h` (human-readable): 용량을 사람이 읽기 쉬운 단위로 보여줍니다.
    - `-s` (summarize): 지정된 각 인자에 대한 총계만 보여줍니다. (하위 디렉터리 각각을 보여주지 않음)
    - `-d [N]` 또는 `--max-depth=[N]`: 지정된 깊이(N)의 하위 디렉터리까지만 용량을 보여줍니다.

- **사용법**:
  ```bash
  # 현재 디렉터리의 각 하위 디렉터리별 용량과 총 용량 보기
  du -h

  # /var/log 디렉터리의 전체 용량만 확인
  du -sh /var/log

  # 현재 디렉터리에서 한 단계 하위 디렉터리까지만의 용량 확인
  du -h --max-depth=1
  ```

- **`du`와 `sort`를 이용한 용량 분석**:
  `du`와 `sort`를 조합하면 특정 디렉터리에서 용량을 가장 많이 차지하는 하위 디렉터리들을 쉽게 찾을 수 있습니다.
  ```bash
  # /var 디렉터리에서 용량을 많이 차지하는 순서대로 정렬 (상위 10개)
  du -h --max-depth=1 /var | sort -hr | head -n 10
  ```
  (`sort -hr`: `-h`는 사람이 읽기 쉬운 숫자(10G, 2M)를 인식하여 정렬, `-r`은 역순(내림차순) 정렬)

## 3. `ncdu`: 인터랙티브한 디스크 용량 분석기

- **기능**: `ncdu` (NCurses Disk Usage)는 `du`와 유사하지만, 결과를 텍스트 기반의 인터랙티브한 인터페이스로 보여주어 사용자가 직접 디렉터리를 오가며 용량 분석을 훨씬 쉽게 할 수 있도록 도와주는 매우 유용한 도구입니다. (기본 설치되어 있지 않을 수 있으므로 `sudo dnf install ncdu` 또는 `sudo apt install ncdu`로 설치 필요)

- **사용법**:
  ```bash
  # 현재 디렉터리를 기준으로 분석 시작
  ncdu

  # 특정 디렉터리(예: /)를 기준으로 분석 시작
  ncdu /
  ```

- **인터랙티브 인터페이스**:
    - 화살표 키(↑, ↓)로 이동, Enter 키로 디렉터리 진입.
    - `d`: 선택한 파일 또는 디렉터리 삭제.
    - `n`: 이름 순으로 정렬.
    - `s`: 크기 순으로 정렬.
    - `q`: 종료.

`ncdu`는 어떤 파일과 디렉터리가 디스크 공간을 차지하고 있는지 직관적으로 파악할 수 있게 해주어, 디스크 용량 문제 해결에 가장 먼저 추천되는 도구 중 하나입니다.

### 디스크 용량 문제 해결 워크플로우

1.  **`df -h`**: 어떤 파일 시스템(파티션)의 용량이 거의 다 찼는지 확인한다. (예: `/` 또는 `/var`)
2.  **`ncdu /path/to/full/filesystem`**: 용량이 가득 찬 파일 시스템의 루트에서 `ncdu`를 실행하여 어떤 디렉터리가 비정상적으로 큰지 분석한다. (예: `ncdu /var`)
3.  **원인 파악 및 조치**: `ncdu`를 통해 원인이 되는 디렉터리(주로 로그 파일, 캐시, 오래된 백업 등)를 찾았다면, 해당 파일을 삭제, 압축, 또는 다른 디스크로 이동하여 공간을 확보한다.
