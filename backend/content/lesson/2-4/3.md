# 2-4-3: 스트림 편집 (`tee`, `xargs`, `tr`)

파이프라인(`|`)은 리눅스 명령어들을 강력하게 만드는 핵심 요소입니다. 한 명령어의 출력을 다른 명령어의 입력으로 연결하는 파이프라인 사이에서 데이터 스트림을 유용하게 조작하는 세 가지 중요한 명령어가 있습니다: `tee`, `xargs`, `tr`.

## 1. `tee`: 출력을 파일과 화면으로 동시에

- **기능**: `tee` 명령어는 수도관의 T자형 파이프처럼, 표준 입력으로 들어온 데이터를 **표준 출력(화면)과 파일** 두 군데로 동시에 보내주는 역할을 합니다. 파이프라인 중간에서 흐르는 데이터를 파일로 저장하여 중간 결과를 확인하거나 로그를 남기고 싶을 때 매우 유용합니다.

- **주요 옵션**:
    - `-a` (append): 파일에 내용을 덮어쓰지 않고, 맨 뒤에 추가합니다.

- **예시**:
  ```bash
  # ls -l의 결과를 화면에도 보여주고, file_list.txt 파일에도 저장
  ls -l | tee file_list.txt

  # 어떤 작업의 결과를 로그 파일에 기록하면서 동시에 화면으로 진행 상황을 볼 때
  some_command | tee process.log

  # 루트 권한으로 파일을 써야 할 때 sudo와 함께 사용
  # echo "new config" > /etc/config.conf  (Permission denied 발생 가능)
  echo "new config" | sudo tee /etc/config.conf
  ```
  (리다이렉션(`>`)은 셸이 실행하므로 `sudo`의 권한이 적용되지 않지만, `tee`는 `sudo`로 실행된 프로세스이므로 루트 권한으로 파일에 쓸 수 있습니다.)

## 2. `xargs`: 입력을 인자로 변환

- **기능**: `xargs` (eXtended ARGumentS)는 표준 입력으로 들어온 데이터(주로 파일 목록)를 읽어, 뒤따르는 특정 명령어의 **인자(argument)**로 넘겨 실행해주는 역할을 합니다. 파이프라인으로 연결되지 않는 명령어(예: `cp`, `rm`, `echo` 등)에 여러 개의 입력을 전달해야 할 때 필수적입니다.

- **동작 원리**:
  `find . -name "*.log"` → `xargs` → `rm log1.log log2.log ...`

- **주요 옵션**:
    - `-0` (null): 입력 값들이 `NULL` 문자로 구분된다고 가정합니다. 파일 이름에 공백이나 특수문자가 포함되어 있을 때 안전하게 처리하기 위해 `find`의 `-print0` 옵션과 함께 사용됩니다.
    - `-I {}`: 입력값을 한 번에 하나씩 읽어, 뒤따르는 명령어의 `{}` 부분에 치환하여 실행합니다. (placeholder 기능)

- **예시**:
  ```bash
  # 현재 디렉터리 아래의 모든 .log 파일을 찾아 삭제
  find . -name "*.log" | xargs rm

  # 파일 이름에 공백이 포함될 경우를 대비한 안전한 방법
  find . -name "*.log" -print0 | xargs -0 rm

  # 찾은 모든 .txt 파일에 대해, 각 파일을 .bak 확장자로 복사
  # find의 결과가 one.txt, two.txt 라면 -> cp one.txt one.txt.bak, cp two.txt two.txt.bak 실행
  find . -name "*.txt" | xargs -I {} cp {} {}.bak
  ```

## 3. `tr`: 문자 단위 치환/삭제

- **기능**: `tr` (translate) 명령어는 표준 입력으로 들어온 텍스트 스트림에서 **문자 단위**로 치환(translate), 압축(squeeze), 삭제(delete)하는 간단하지만 빠른 도구입니다.

- **주요 사용법**:
    - **치환**: `tr 'SET1' 'SET2'`
      SET1의 첫 번째 문자를 SET2의 첫 번째 문자로, 두 번째 문자를 두 번째 문자로... 1:1 매핑하여 바꿉니다.
    - **삭제**: `tr -d 'SET'`
      SET에 포함된 모든 문자를 삭제합니다.
    - **압축**: `tr -s 'SET'`
      SET에 포함된 문자가 연속으로 반복될 경우, 한 개의 문자로 압축합니다.

- **예시**:
  ```bash
  # 모든 소문자를 대문자로 변경
  echo "hello world" | tr 'a-z' 'A-Z'
  # 결과: HELLO WORLD

  # Windows 형식의 개행 문자(^M, \r)를 Unix 형식으로 변환
  tr -d '\r' < windows_file.txt > unix_file.txt

  # 공백이 여러 개 연속된 경우, 하나의 공백으로 압축
  echo "hello     world" | tr -s ' '
  # 결과: hello world

  # PATH 환경 변수의 ":"를 줄바꿈으로 변경하여 각 경로를 한 줄씩 보기
  echo $PATH | tr ':' '\n'
  ```

이 세 명령어는 다른 명령어들과 결합될 때 그 진가를 발휘합니다. `tee`는 파이프라인의 투명성을, `xargs`는 인자 전달의 유연성을, `tr`은 문자 단위의 빠른 변환을 제공하여 셸 스크립트와 커맨드라인 작업을 한층 더 강력하게 만들어 줍니다.
