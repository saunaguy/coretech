# 2-4-2: 아카이빙/압축 (`tar`, `gzip`, `bzip2`, `xz`)

리눅스에서는 여러 파일이나 디렉터리를 하나의 파일로 묶는 **아카이빙(Archiving)**과 파일의 크기를 줄이는 **압축(Compression)**을 위해 다양한 도구를 사용합니다. 이 두 개념은 종종 함께 사용됩니다.

## 1. `tar`: 아카이브의 표준

- **기능**: `tar` (Tape Archive)는 여러 개의 파일과 디렉터리를 그 구조와 권한 등의 속성을 그대로 유지하면서 하나의 `.tar` 파일로 묶거나 풀어주는 명령어입니다. `tar` 자체는 압축 기능이 없으며, 오직 묶는 역할만 합니다.

- **주요 옵션**:
    - **`c` (create)**: 새로운 `.tar` 아카이브 파일을 생성합니다.
    - **`x` (extract)**: `.tar` 아카이브 파일의 내용을 풉니다.
    - **`t` (list)**: `.tar` 아카이브 파일에 어떤 파일들이 들어있는지 목록을 보여줍니다. (풀지 않고 내용만 확인)
    - **`f` (file)**: 아카이브 파일의 이름을 지정합니다. 거의 항상 사용되는 필수 옵션입니다.
    - **`v` (verbose)**: 처리되는 파일들의 목록을 자세하게 보여줍니다.

- **기본 사용법**:
  ```bash
  # my_project 디렉터리를 project.tar 파일로 묶기
  tar -cvf project.tar my_project/

  # project.tar 파일의 내용 확인하기
  tar -tvf project.tar

  # project.tar 파일 풀기 (현재 디렉터리에 풀림)
  tar -xvf project.tar
  ```

## 2. 압축 도구: `gzip`, `bzip2`, `xz`

`tar`로 묶인 파일은 압축되지 않아 크기가 큽니다. 이 `.tar` 파일을 압축 도구를 이용해 크기를 줄일 수 있습니다. 각 도구는 압축률과 속도 면에서 장단점을 가집니다.

| 도구 | 확장자 | 압축 속도 | 압축률 | 비고 |
| --- | --- | --- | --- | --- |
| `gzip` | `.gz` | 빠름 | 보통 | 가장 널리, 보편적으로 사용됨 |
| `bzip2` | `.bz2` | 느림 | 높음 | `gzip`보다 높은 압축률이 필요할 때 사용 |
| `xz` | `.xz` | 매우 느림 | 매우 높음 | 최고의 압축률이 필요할 때 사용 (최신 배포판에서 많이 보임) |

- **사용법**:
  ```bash
  # file.txt를 압축 (file.txt.gz 생성, 원본 삭제)
  gzip file.txt

  # file.txt.gz 압축 풀기 (file.txt 생성, 원본 삭제)
  gunzip file.txt.gz

  # bzip2, xz도 유사하게 사용
  bzip2 file.txt  # file.txt.bz2 생성
  bunzip2 file.txt.bz2

  xz file.txt     # file.txt.xz 생성
  unxz file.txt.xz
  ```

## 3. `tar`와 압축을 한번에

`tar` 명령어는 압축 도구와 연동하는 옵션을 제공하여 아카이빙과 압축을 한 번에 처리할 수 있습니다. 이것이 가장 일반적인 사용 방식입니다.

- **주요 압축 연동 옵션**:
    - **`z` (gzip)**: `gzip`을 사용하여 압축하거나 해제합니다. (`.tar.gz` 또는 `.tgz`)
    - **`j` (bzip2)**: `bzip2`를 사용하여 압축하거나 해제합니다. (`.tar.bz2`)
    - **`J` (xz)**: `xz`를 사용하여 압축하거나 해제합니다. (`.tar.xz`)

### 통합 사용 예시

- **`gzip`으로 묶고 압축하기 (`.tar.gz`)**:
  ```bash
  # my_project/ 디렉터리를 project.tar.gz로 압축
  tar -zcvf project.tar.gz my_project/

  # project.tar.gz 압축 풀기
  tar -zxvf project.tar.gz
  ```

- **`bzip2`로 묶고 압축하기 (`.tar.bz2`)**:
  ```bash
  # my_project/ 디렉터리를 project.tar.bz2로 압축
  tar -jcvf project.tar.bz2 my_project/

  # project.tar.bz2 압축 풀기
  tar -jxvf project.tar.bz2
  ```

- **`xz`로 묶고 압축하기 (`.tar.xz`)**:
  ```bash
  # my_project/ 디렉터리를 project.tar.xz로 압축
  tar -Jcvf project.tar.xz my_project/

  # project.tar.xz 압축 풀기
  tar -Jxvf project.tar.xz
  ```

- **특정 디렉터리에 압축 풀기 (`-C` 옵션)**:
  ```bash
  # /opt/backup 디렉터리에 압축 풀기
  tar -zxvf project.tar.gz -C /opt/backup
  ```

- **팁**: 옵션의 순서는 중요하지 않지만, `-f`는 항상 파일명 바로 앞에 오는 것이 관례입니다. (`-zcvf` 대신 `-cvzf`로 써도 동일하게 동작합니다.)

파일 백업, 소프트웨어 소스 코드 배포 등 리눅스 환경에서 파일을 주고받을 때 `.tar.gz` 형태가 가장 널리 사용되므로 사용법을 잘 익혀두는 것이 매우 중요합니다.
