# 2-4-8: 보안/네트워크 심화 (`iptables`, `firewalld`, `tcpdump`, `ssh`, `scp`, `rsync`)

네트워크 기초 도구를 넘어, 시스템을 보호하고 원격으로 관리하며, 데이터를 심도 있게 분석하는 고급 도구들을 알아봅니다.

## 1. 방화벽: `iptables`와 `firewalld`

방화벽은 미리 정의된 규칙에 따라 서버로 들어오고 나가는 네트워크 트래픽을 허용하거나 차단하는 보안 시스템입니다. 리눅스 커널에는 **Netfilter**라는 패킷 필터링 프레임워크가 내장되어 있으며, `iptables`와 `firewalld`는 이 Netfilter를 제어하는 사용자 공간 도구입니다.

### `iptables`
- **기능**: 전통적인 리눅스 방화벽 도구로, 매우 유연하고 강력한 규칙 설정이 가능합니다. 패킷이 거쳐가는 경로에 따라 여러 **테이블(Table)**과 **체인(Chain)**으로 구성되며, 각 체인에 규칙을 추가하여 패킷을 제어합니다.
- **주요 체인**:
    - `INPUT`: 서버로 들어오는 패킷에 대한 규칙.
    - `OUTPUT`: 서버에서 나가는 패킷에 대한 규칙.
    - `FORWARD`: 서버를 거쳐 다른 곳으로 전달되는 패킷에 대한 규칙.
- **단점**: 사용법이 복잡하고, 규칙을 변경하면 즉시 적용되므로 서비스 재시작 없이 동적으로 규칙을 관리하기가 다소 까다롭습니다.

### `firewalld`
- **기능**: `iptables`의 복잡성을 개선한 최신 방화벽 관리 도구입니다. **Zone(영역)**이라는 개념을 도입하여 네트워크 인터페이스를 특정 Zone에 할당하고, 각 Zone별로 미리 정의된 보안 레벨에 따라 규칙을 적용합니다. (예: `public` Zone, `internal` Zone, `dmz` Zone 등)
- **장점**: 규칙을 동적으로 추가/삭제할 수 있으며, 서비스 이름을 기반으로 규칙(예: `http`, `ssh`)을 쉽게 관리할 수 있습니다.
- **주요 명령어 (`firewall-cmd`)**:
  ```bash
  # 현재 활성화된 Zone과 인터페이스 확인
  sudo firewall-cmd --get-active-zones

  # public Zone에 http 서비스를 영구적으로 허용
  sudo firewall-cmd --zone=public --add-service=http --permanent

  # public Zone에 8080/tcp 포트를 영구적으로 허용
  sudo firewall-cmd --zone=public --add-port=8080/tcp --permanent

  # 변경된 규칙 적용
  sudo firewall-cmd --reload
  ```

## 2. 패킷 분석: `tcpdump`

- **기능**: `tcpdump`는 네트워크 인터페이스를 오가는 모든 패킷을 실시간으로 캡처하여 그 내용을 보여주는 강력한 커맨드라인 패킷 분석 도구입니다. 네트워크 문제의 근본 원인을 분석하거나, 특정 애플리케이션이 어떤 통신을 하는지 확인할 때 사용됩니다.
- **주요 옵션**:
    - `-i`: 캡처할 네트워크 인터페이스 지정 (예: `eth0`). `any`로 지정하면 모든 인터페이스를 대상으로 합니다.
    - `-n`: 호스트 이름이나 포트 이름을 숫자로 표시합니다.
    - `-w`: 캡처한 패킷을 파일(`.pcap`)로 저장합니다. (나중에 Wireshark 등에서 분석)
    - **필터 표현식**: `host`, `port`, `src`, `dst`, `tcp`, `udp` 등 다양한 표현식을 조합하여 원하는 패킷만 캡처할 수 있습니다.

- **예시**:
  ```bash
  # eth0 인터페이스의 모든 패킷 캡처
  sudo tcpdump -i eth0

  # 1.2.3.4 호스트와 통신하는 패킷만 캡처
  sudo tcpdump -i eth0 host 1.2.3.4

  # 80번 포트(http)를 사용하는 패킷만 캡처하여 파일로 저장
  sudo tcpdump -i eth0 -w http_traffic.pcap port 80
  ```

## 3. 원격 접속 및 파일 전송

### `ssh` (Secure Shell)
- **기능**: 원격에 있는 다른 리눅스 서버에 암호화된 채널을 통해 안전하게 접속하여 명령을 내릴 수 있는 필수적인 원격 관리 도구입니다. 기본적으로 22번 포트를 사용합니다.
- **사용법**:
  ```bash
  # user라는 사용자로 remote.server.com에 접속
  ssh user@remote.server.com

  # 특정 포트(예: 2222)로 접속
  ssh -p 2222 user@remote.server.com
  ```

### `scp` (Secure Copy)
- **기능**: `ssh`를 기반으로 동작하여 두 호스트 간에 파일을 안전하게 복사하는 명령어입니다.
- **사용법**:
  ```bash
  # 로컬의 local_file.txt를 원격 서버의 /remote/dir/에 복사
  scp local_file.txt user@remote.server.com:/remote/dir/

  # 원격 서버의 /remote/dir/remote_file.txt를 로컬의 현재 디렉터리로 복사
  scp user@remote.server.com:/remote/dir/remote_file.txt .

  # 디렉터리 전체를 복사 (-r 옵션)
  scp -r local_dir/ user@remote.server.com:/remote/dir/
  ```

### `rsync` (Remote Sync)
- **기능**: `scp`와 유사하게 파일을 복사하지만, 훨씬 더 지능적이고 효율적인 동기화 기능을 제공합니다. 파일의 변경된 부분만 찾아내어 전송하므로 반복적인 백업이나 대용량 파일 동기화에 매우 효과적입니다.
- **주요 옵션**:
    - `-a` (archive): `-rlptgoD` 옵션을 모두 포함한 것과 같으며, 권한, 소유자, 타임스탬프 등 파일의 모든 속성을 그대로 유지하며 재귀적으로 복사합니다. 거의 항상 사용됩니다.
    - `-v` (verbose): 진행 상황을 자세히 보여줍니다.
    - `-z` (compress): 전송 중 데이터를 압축하여 속도를 높입니다.
    - `--delete`: 원본에 없는 파일은 대상에서 삭제하여 두 디렉터리를 완전히 동일하게 만듭니다.

- **사용법**:
  ```bash
  # 로컬의 local_dir/을 원격 서버의 /remote/dir/에 효율적으로 동기화
  rsync -avz local_dir/ user@remote.server.com:/remote/dir/

  # 원격 서버의 내용을 로컬로 동기화 (백업)
  rsync -avz user@remote.server.com:/var/www/html/ ~/backup/
  ```
