# 2-4-5: 패키지 관리 (`yum`/`dnf`, `apt`, `rpm`/`dpkg`)

리눅스에서 소프트웨어를 설치, 업데이트, 삭제하는 작업을 **패키지 관리**라고 합니다. 소스 코드를 직접 컴파일하여 설치하는 전통적인 방식과 달리, 패키지 관리 시스템은 미리 컴파일된 바이너리와 관련 설정 파일들을 `패키지`라는 단위로 묶어 손쉽게 관리할 수 있도록 해줍니다.

리눅스 배포판은 크게 두 가지 계열의 패키지 관리 시스템으로 나뉩니다: **RPM 기반**과 **Debian 기반**.

## 1. RPM 기반 (Red Hat 계열: RHEL, CentOS, Fedora)

### 고수준 패키지 관리자: `dnf` (과거 `yum`)

- **기능**: `dnf` (Dandified YUM)는 인터넷 상의 **리포지토리(Repository)**라는 패키지 저장소에서 필요한 패키지를 자동으로 찾아 다운로드하고, **의존성(Dependency)** 문제를 해결하며 설치해주는 지능적인 도구입니다. (예: `A`라는 프로그램을 설치하려면 `B`라는 라이브러리가 먼저 필요한 경우, `B`를 알아서 함께 설치해 줌)
- `yum` (Yellowdog Updater, Modified)은 오랫동안 사용되어 온 도구이며, `dnf`는 `yum`의 차세대 버전입니다. 명령어 사용법은 거의 동일합니다.

- **주요 명령어**:
  ```bash
  # 패키지 설치
  sudo dnf install httpd

  # 패키지 업데이트
  sudo dnf update httpd

  # 시스템의 모든 패키지 업데이트
  sudo dnf upgrade

  # 패키지 삭제
  sudo dnf remove httpd

  # 설치된 패키지 목록 보기
  dnf list installed

  # 특정 패키지 검색 (이름이나 설명에서)
  dnf search "web server"

  # 특정 파일이 어떤 패키지에 포함되어 있는지 확인
  dnf provides /etc/httpd/conf/httpd.conf
  ```

### 저수준 패키지 관리자: `rpm`

- **기능**: `rpm` (Red Hat Package Manager)은 `.rpm` 패키지 파일을 직접 다루는 저수준 도구입니다. 리포지토리나 의존성 해결 기능이 없으므로, 주로 이미 다운로드된 `.rpm` 파일을 설치하거나 시스템에 설치된 패키지를 검증하는 등의 용도로 사용됩니다.

- **주요 명령어**:
  ```bash
  # .rpm 파일 설치 (-i: install, -v: verbose, -h: hash)
  sudo rpm -ivh package.rpm

  # 패키지 삭제 (-e: erase)
  sudo rpm -e httpd

  # 특정 패키지가 설치되어 있는지 확인 (-q: query)
  rpm -q httpd

  # 특정 파일이 어떤 패키지에 속하는지 확인
  rpm -qf /etc/httpd/conf/httpd.conf
  ```

## 2. Debian 기반 (Debian, Ubuntu, Mint)

### 고수준 패키지 관리자: `apt`

- **기능**: `apt` (Advanced Package Tool)는 `dnf`/`yum`과 동일한 역할을 하는 Debian 계열의 고수준 패키지 관리자입니다. (`apt-get`, `apt-cache` 등의 명령어를 통합하여 더 사용자 친화적으로 만든 최신 도구입니다.)

- **주요 명령어**:
  ```bash
  # 패키지 목록 업데이트 (설치 전 항상 실행 권장)
  sudo apt update

  # 패키지 설치
  sudo apt install apache2

  # 패키지 업데이트
  sudo apt upgrade apache2

  # 시스템의 모든 패키지 업데이트
  sudo apt upgrade

  # 패키지 삭제
  sudo apt remove apache2

  # 설치된 패키지 목록 보기
  apt list --installed

  # 특정 패키지 검색
  apt search "web server"
  ```

### 저수준 패키지 관리자: `dpkg`

- **기능**: `dpkg` (Debian Package)는 `.deb` 패키지 파일을 직접 다루는 저수준 도구로, `rpm`과 유사한 역할을 합니다.

- **주요 명령어**:
  ```bash
  # .deb 파일 설치 (-i: install)
  sudo dpkg -i package.deb

  # 패키지 삭제 (-r: remove)
  sudo dpkg -r apache2

  # 특정 패키지가 설치되어 있는지 확인 (-s: status)
  dpkg -s apache2

  # 특정 파일이 어떤 패키지에 속하는지 확인 (-S: search)
  dpkg -S /etc/apache2/apache2.conf
  ```

## 정리

| 구분 | Red Hat 계열 (CentOS, Fedora) | Debian 계열 (Ubuntu) |
| --- | --- | --- |
| **고수준 관리자** | `dnf` (or `yum`) | `apt` |
| **저수준 관리자** | `rpm` | `dpkg` |
| **패키지 확장자** | `.rpm` | `.deb` |
| **역할** | - **고수준**: 인터넷 저장소(리포지토리)에서 의존성을 해결하며 자동 설치/업데이트<br>- **저수준**: 로컬의 패키지 파일을 직접 설치/삭제/조회 | - **고수준**: 인터넷 저장소(리포지토리)에서 의존성을 해결하며 자동 설치/업데이트<br>- **저수준**: 로컬의 패키지 파일을 직접 설치/삭제/조회 |

일반적인 소프트웨어 설치 및 관리에는 `dnf`나 `apt`와 같은 고수준 관리자를 사용하는 것이 훨씬 편리하고 안전합니다. `rpm`이나 `dpkg`는 특정 버전의 패키지를 수동으로 설치해야 하거나, 시스템 복구 등의 특수한 상황에서 사용됩니다.
