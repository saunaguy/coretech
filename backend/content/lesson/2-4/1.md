# 2-4-1: 텍스트 처리 (`grep`, `awk`, `sed`, `cut`, `sort`)

리눅스/유닉스 철학의 핵심 중 하나는 "모든 것은 파일(텍스트 스트림)이다"입니다. 이 철학 덕분에, 간단한 텍스트 처리 도구들을 파이프(`|`)로 연결하여 매우 복잡하고 강력한 작업을 수행할 수 있습니다. `grep`, `awk`, `sed`는 텍스트 처리의 삼대장으로 불립니다.

## 1. `grep`: 패턴 검색의 제왕

- **기능**: `grep` (Global Regular Expression Print)은 파일이나 표준 입력으로부터 특정 문자열 패턴(정규 표현식 포함)을 포함하는 라인을 찾아 출력하는 명령어입니다.

- **주요 옵션**:
    - `-i` (ignore-case): 대소문자를 무시하고 검색합니다.
    - `-v` (invert-match): 패턴과 일치하지 **않는** 라인을 출력합니다.
    - `-n` (line-number): 결과 출력 시 라인 번호를 함께 보여줍니다.
    - `-r` 또는 `-R` (recursive): 지정된 디렉터리 하위의 모든 파일을 대상으로 재귀적으로 검색합니다.
    - `-E` (extended-regexp): 확장 정규 표현식(Egrep)을 사용합니다. (`egrep` 명령어와 동일)
    - `-c` (count): 일치하는 라인의 수를 출력합니다.

- **예시**:
  ```bash
  # /etc/passwd 파일에서 "bash" 문자열이 포함된 라인 찾기
  grep "bash" /etc/passwd

  # 현재 디렉터리 아래의 모든 .conf 파일에서 "Error" 문자열을 대소문자 구분 없이 검색
  grep -ir "Error" .

  # access.log 파일에서 404 에러가 아닌 모든 로그 보기
  grep -v " 404 " access.log
  ```

## 2. `sed`: 스트림 편집의 마법사

- **기능**: `sed` (Stream Editor)는 텍스트 스트림(파일 또는 파이프 입력)을 한 줄씩 읽어 특정 패턴을 찾아 편집(치환, 삭제, 추가, 삽입 등)한 후 출력하는 강력한 도구입니다. 원본 파일은 기본적으로 수정하지 않습니다.

- **핵심 사용법: 치환(substitute)**
  `sed 's/찾을패턴/바꿀내용/플래그'`

- **주요 플래그**:
    - `g` (global): 라인 전체에서 일치하는 모든 패턴을 바꿉니다. (없으면 첫 번째 일치 항목만 바뀜)
    - `i`: 대소문자를 무시합니다.

- **예시**:
  ```bash
  # "apple"을 "orange"로 치환 (각 라인에서 첫 번째만)
  sed 's/apple/orange/' file.txt

  # "apple"을 "orange"로 모두 치환
  sed 's/apple/orange/g' file.txt

  # 5번째 라인 삭제
  sed '5d' file.txt

  # "error"가 포함된 라인 삭제
  sed '/error/d' file.txt

  # 원본 파일을 직접 수정 (-i 옵션, 주의해서 사용)
  sed -i 's/old/new/g' config.conf
  ```

## 3. `awk`: 텍스트 필드 처리의 달인

- **기능**: `awk`는 텍스트를 한 줄씩 읽어, 각 라인을 특정 구분자(기본값: 공백)로 나눈 **필드(field)** 단위로 처리하고 조작하는 데 특화된 프로그래밍 언어입니다. 복잡한 조건과 동작을 조합하여 리포트를 생성하거나 데이터를 가공하는 데 매우 강력합니다.

- **기본 구조**: `awk '패턴 { 동작 }'`

- **내장 변수**:
    - `$0`: 전체 라인
    - `$1`, `$2`, ...: 첫 번째 필드, 두 번째 필드, ...
    - `NF` (Number of Fields): 현재 라인의 총 필드 수
    - `NR` (Number of Records): 현재까지 처리한 총 라인 수

- **예시**:
  ```bash
  # /etc/passwd 파일에서 사용자 이름(첫 번째 필드)만 출력
  # -F":" : 구분자를 ":"로 지정
  awk -F":" '{ print $1 }' /etc/passwd

  # ls -l 결과에서 파일 이름(9번째 필드)만 출력
  ls -l | awk '{ print $9 }'

  # 파일 크기(5번째 필드)가 1024바이트보다 큰 파일만 출력
  ls -l | awk '$5 > 1024 { print $9 }'

  # 각 라인의 맨 앞에 라인 번호 추가하기
  awk '{ print NR, $0 }' file.txt
  ```

## 4. `cut` & `sort`: 잘라내고 정렬하기

- **`cut`**: `awk`보다 단순하게 텍스트를 열(column) 단위로 잘라내는 데 사용됩니다.
  - `-d` (delimiter): 구분자를 지정합니다.
  - `-f` (fields): 가져올 필드 번호를 지정합니다.

  ```bash
  # /etc/passwd에서 사용자 이름(첫 번째 필드)과 셸(7번째 필드)을 ":" 구분자로 잘라내기
  cut -d":" -f1,7 /etc/passwd
  ```

- **`sort`**: 텍스트 라인을 정렬합니다.
  - `-n` (numeric-sort): 숫자 순서로 정렬합니다.
  - `-r` (reverse): 역순으로 정렬합니다.
  - `-k` (key): 정렬 기준으로 삼을 필드를 지정합니다.
  - `-u` (unique): 중복된 라인을 제거하고 하나만 남깁니다. (`uniq` 명령어와 유사)

  ```bash
  # 파일 내용을 알파벳순으로 정렬
  sort file.txt

  # ls -l 결과를 파일 크기(5번째 필드) 기준으로 내림차순 정렬
  ls -l | sort -nr -k5
  ```

이 도구들은 단독으로도 유용하지만, 파이프(`|`)를 통해 서로의 출력을 입력으로 연결할 때 진정한 힘을 발휘합니다. 예를 들어, 로그 파일에서 특정 에러 메시지를 찾아(`grep`), 그중 필요한 정보만 잘라내고(`awk` 또는 `cut`), 결과를 정렬하여(`sort`) 리포트를 만드는 식의 연계가 가능합니다.
