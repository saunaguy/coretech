# 2-2-1: 사용자 및 그룹 관리 (Red Hat 계열)

리눅스는 태생부터 여러 사용자가 동시에 접속하여 사용하는 **다중 사용자(Multi-user)** 시스템입니다. 따라서 각 사용자를 식별하고, 파일이나 시스템 자원에 대한 접근을 제어하는 사용자/그룹 관리는 시스템 보안의 가장 기본적이고 중요한 부분입니다.

이 장의 모든 명령어는 시스템 설정을 변경하므로, 대부분 최고 관리자(`root`) 권한이 필요합니다. 명령어 앞에 `sudo`를 붙여 실행하세요.

### 관련 주요 설정 파일
- `/etc/passwd`: 사용자 계정 정보 저장 (사용자 이름, UID, GID, 홈 디렉터리, 셸 정보 등)
- `/etc/shadow`: 사용자 암호 정보를 암호화하여 저장
- `/etc/group`: 그룹 정보 저장

---

## 1. 사용자 계정 관리

### `useradd`: 새로운 사용자 생성
- **기능**: 새로운 사용자 계정을 생성합니다.
- **주요 옵션**:
    - `-c "코멘트"`: 사용자에 대한 설명(Comment)을 추가합니다. 보통 전체 이름을 넣습니다.
    - `-d <홈 디렉터리>`: 홈 디렉터리 경로를 직접 지정합니다. (기본값: `/home/<사용자명>`)
    - `-m`: 홈 디렉터리를 생성합니다. (Red Hat 계열에서는 기본적으로 생성되지만, 명시적으로 사용하는 것이 좋습니다.)
    - `-g <그룹명>`: 사용자가 속할 **주 그룹(primary group)**을 지정합니다.
    - `-G <그룹명1,그룹명2>`: 사용자가 추가로 속할 **보조 그룹(supplementary groups)**을 지정합니다.
    - `-s <셸 경로>`: 사용자의 기본 로그인 셸을 지정합니다. (기본값: `/bin/bash`)

- **사용 예시**:
    ```bash
    # 'testuser' 라는 이름의 사용자를 생성 (홈 디렉터리 자동 생성)
    $ sudo useradd testuser

    # 주석, 홈 디렉터리, 셸을 지정하여 'dev1' 사용자 생성
    $ sudo useradd -m -c "Developer One" -d /data/dev1 -s /bin/bash dev1
    ```

### `passwd`: 사용자 암호 설정 및 변경
- **기능**: `useradd`로 계정을 만든 직후에는 암호가 설정되어 있지 않아 로그인이 불가능합니다. `passwd` 명령어로 암호를 설정해야 합니다.

- **사용 예시**:
    ```bash
    # 'testuser' 사용자의 암호를 설정 (관리자가 설정)
    $ sudo passwd testuser
    Changing password for user testuser.
    New password: <암호 입력>
    Retype new password: <암호 다시 입력>

    # 현재 로그인한 자신의 암호를 변경
    $ passwd
    ```

### `usermod`: 사용자 정보 수정
- **기능**: 이미 생성된 사용자의 속성을 변경합니다.
- **주요 옵션**:
    - `-aG <그룹명>`: 사용자를 특정 보조 그룹에 **추가**합니다. `-a`(append) 옵션이 없으면 기존 그룹을 덮어쓰므로 **매우 중요**합니다.
    - `-l <새로운 사용자명>`: 사용자의 로그인 이름을 변경합니다.
    - `-L`: 사용자의 계정을 잠가 로그인을 막습니다 (Lock).
    - `-U`: 잠긴 계정을 해제합니다 (Unlock).

- **사용 예시**:
    ```bash
    # 'testuser'를 'wheel' 그룹에 추가하여 sudo 권한 부여 (Red Hat 방식)
    $ sudo usermod -aG wheel testuser

    # 'testuser'의 이름을 'localuser'로 변경
    $ sudo usermod -l localuser testuser

    # 'localuser' 계정 잠그기
    $ sudo usermod -L localuser
    ```

### `userdel`: 사용자 삭제
- **기능**: 사용자 계정을 삭제합니다.
- **주요 옵션**:
    - `-r`: 사용자의 홈 디렉터리와 메일 스풀을 함께 삭제합니다. 이 옵션 없이 삭제하면 홈 디렉터리는 그대로 남게 됩니다.

- **사용 예시**:
    ```bash
    # 'testuser' 계정만 삭제
    $ sudo userdel testuser

    # 'localuser' 계정과 홈 디렉터리까지 모두 삭제
    $ sudo userdel -r localuser
    ```

## 2. 그룹 관리

여러 사용자에게 동일한 권한을 부여해야 할 때, 각 사용자에게 일일이 권한을 주는 대신 그룹에 권한을 부여하고 사용자들을 그 그룹에 포함시키는 것이 효율적입니다.

- **`groupadd <그룹명>`**: 새로운 그룹을 생성합니다.
    ```bash
    $ sudo groupadd developers
    ```
- **`groupmod -n <새 그룹명> <기존 그룹명>`**: 그룹의 이름을 변경합니다.
    ```bash
    $ sudo groupmod -n webdev developers
    ```
- **`groupdel <그룹명>`**: 그룹을 삭제합니다.
    ```bash
    $ sudo groupdel webdev
    ```

## 3. 정보 확인 명령어

- **`id [사용자명]`**: 특정 사용자의 UID(사용자 ID), GID(주 그룹 ID), 그리고 속한 그룹들의 정보를 보여줍니다.
    ```bash
    $ id testuser
    uid=1001(testuser) gid=1001(testuser) groups=1001(testuser),10(wheel)
    ```
- **`groups [사용자명]`**: 특정 사용자가 속한 그룹 목록만 간단히 보여줍니다.
- **`getent passwd`**: `/etc/passwd` 파일의 내용을 형식에 맞춰 보여줍니다.
- **`getent group`**: `/etc/group` 파일의 내용을 형식에 맞춰 보여줍니다.
