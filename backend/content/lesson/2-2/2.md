# 2-2-2: 파일 권한의 이해 (`chmod`, `chown`, `umask`)

리눅스는 다중 사용자 시스템이므로, "이 파일은 누가 읽고, 쓰고, 실행할 수 있는가?"를 정의하는 파일 권한(Permission) 시스템은 보안의 가장 핵심적인 요소입니다.

## 1. `ls -l` 로 권한 확인하기

`ls -l` 명령어를 실행하면 파일의 상세 정보가 나오며, 가장 첫 번째 필드가 바로 권한을 나타냅니다.

```
-rwxr-xr-- 1 testuser developers 4096 Sep 24 11:00 script.sh
drwx------ 2 testuser testuser   4096 Sep 24 10:50 private_dir
```

` -rwxr-xr-- ` 부분을 4부분으로 나누어 해석할 수 있습니다.

| 1 | 2 | 3 | 4 |
| :---: | :---: | :---: | :---: |
| `-` | `rwx` | `r-x` | `r--` |
| 파일 종류 | 소유자 권한 | 그룹 권한 | 그 외 사용자 권한 |

- **1. 파일 종류**: `-`(파일), `d`(디렉터리), `l`(심볼릭 링크) 등을 나타냅니다.
- **2. 소유자(User) 권한**: 파일을 소유한 사용자의 권한입니다.
- **3. 그룹(Group) 권한**: 파일이 속한 그룹의 사용자들에게 부여되는 권한입니다.
- **4. 그 외 사용자(Other) 권한**: 소유자도 아니고 그룹에도 속하지 않은 나머지 모든 사용자의 권한입니다.

### 권한의 의미
- `r` (Read): 읽기 권한. 파일의 내용을 보거나, 디렉터리의 목록을 볼 수 있습니다.
- `w` (Write): 쓰기 권한. 파일의 내용을 수정하거나, 디렉터리 내에서 파일을 생성/삭제/이름변경 할 수 있습니다.
- `x` (eXecute): 실행 권한. 파일을 프로그램처럼 실행하거나, 디렉터리에 `cd` 명령으로 진입할 수 있습니다.

## 2. `chmod`: 권한 변경하기

`chmod` (change mode) 명령어는 파일이나 디렉터리의 권한을 변경합니다. 변경 방식은 크게 두 가지가 있습니다.

### 기호(Symbolic) 방식: 직관적인 방법
- **문법**: `chmod [대상][연산자][권한] 파일명`
    - **대상(who)**: `u`(user), `g`(group), `o`(other), `a`(all)
    - **연산자(operator)**: `+`(권한 추가), `-`(권한 제거), `=`(권한 설정)
    - **권한(permission)**: `r`, `w`, `x`

- **예시**:
    ```bash
    # script.sh 파일에 소유자의 실행(x) 권한을 추가한다.
    $ chmod u+x script.sh

    # data.txt 파일에서 그룹의 쓰기(w) 권한을 제거한다.
    $ chmod g-w data.txt

    # 모든 사용자에게 report.txt 파일의 읽기(r) 권한을 부여한다.
    $ chmod a+r report.txt
    ```

### 숫자(Octal) 방식: 빠르고 효율적인 방법
- **개념**: r, w, x 권한을 숫자로 변환하여 조합합니다. **`r=4`, `w=2`, `x=1`**
    - `rwx` = 4 + 2 + 1 = `7`
    - `rw-` = 4 + 2 + 0 = `6`
    - `r-x` = 4 + 0 + 1 = `5`
    - `r--` = 4 + 0 + 0 = `4`
- **문법**: `chmod [소유자숫자][그룹숫자][기타숫자] 파일명`

- **예시**:
    ```bash
    # script.sh 파일의 권한을 755 (rwxr-xr-x) 로 변경 (스크립트 파일의 표준 권한)
    $ chmod 755 script.sh

    # data.txt 파일의 권한을 644 (rw-r--r--) 로 변경 (일반 텍스트 파일의 표준 권한)
    $ chmod 644 data.txt

    # private_dir 디렉터리의 권한을 700 (rwx------) 로 변경 (소유자만 접근 가능)
    $ chmod 700 private_dir/
    ```

## 3. `chown`: 소유권 변경하기

`chown` (change owner) 명령어는 파일이나 디렉터리의 소유자 및 소유 그룹을 변경합니다.

- **문법**: `chown [소유자]:[그룹] 파일명` (소유자나 그룹 중 하나만 변경 가능)
- **주요 옵션**:
    - `-R` (Recursive): 디렉터리와 그 안의 모든 파일/하위 디렉터리의 소유권을 한 번에 변경합니다.

- **예시**:
    ```bash
    # data.txt 파일의 소유자를 'dev1' 사용자로 변경
    $ sudo chown dev1 data.txt

    # data.txt 파일의 소유 그룹을 'developers' 그룹으로 변경
    $ sudo chown :developers data.txt

    # data.txt 파일의 소유자와 그룹을 한 번에 변경
    $ sudo chown dev1:developers data.txt

    # /data/project 디렉터리 및 모든 하위 파일/디렉터리의 소유권을 변경
    $ sudo chown -R dev1:developers /data/project
    ```

## 4. `umask`: 기본 권한 설정하기

- **기능**: 파일이나 디렉터리를 **새로 생성할 때** 어떤 기본 권한을 부여할지 결정하는 값입니다. `umask`는 "빼낼" 권한을 지정하는 마스크(mask) 값입니다.
- **기본 최대 권한**:
    - 디렉터리: `777` (`rwxrwxrwx`)
    - 파 일: `666` (`rw-rw-rw-`) (파일은 기본적으로 실행 권한을 갖지 않습니다.)
- **계산법**: `최종 권한 = 최대 권한 - umask 값`

- **일반적인 umask 값 `0022` (또는 `022`)**
    - 새로 만드는 디렉터리: `777 - 022 = 755` (`rwxr-xr-x`)
    - 새로 만드는 파일: `666 - 022 = 644` (`rw-r--r--`)

- **명령어**:
    ```bash
    # 현재 umask 값 확인
    $ umask
    0022

    # 현재 세션의 umask 값을 0027로 변경 (그룹 쓰기, 기타 모든 권한 차단)
    $ umask 0027
    ```
