# 2-2-5: 파일 속성/불변 플래그 (`chattr`, `lsattr`)

일반적인 `rwx` 권한 설정만으로는 시스템의 중요 파일을 완벽하게 보호하기 어려운 경우가 있습니다. 예를 들어, `root` 사용자는 모든 파일에 대한 권한을 무시하고 파일을 수정하거나 삭제할 수 있습니다. 하지만 파일의 **속성(Attribute)**을 변경하면, `root` 사용자조차도 파일을 함부로 변경하거나 삭제할 수 없게 만드는 강력한 보호 장치를 설정할 수 있습니다.

이 기능은 ext2, ext3, ext4, XFS 등 대부분의 리눅스 파일 시스템에서 지원됩니다.

## 1. `chattr` 와 `lsattr`

- **`lsattr` (List Attributes)**: 파일이나 디렉터리에 설정된 특정 속성을 확인하는 명령어입니다.
- **`chattr` (Change Attributes)**: 파일이나 디렉터리의 속성을 변경(설정 또는 해제)하는 명령어입니다. `root` 권한이 필요합니다.

## 2. 핵심 속성(플래그) 알아보기

다양한 속성이 있지만, 시스템 보안과 운영에 있어 가장 중요하고 자주 사용되는 두 가지 속성은 `i`와 `a`입니다.

### `i` 속성: 완전한 보호 (Immutable)

- **기능**: "Immutable"의 약자로, 이 속성이 설정된 파일은 **그 누구도(심지어 root도) 내용을 수정, 삭제, 이름 변경, 링크 생성을 할 수 없습니다.** 파일을 완전히 "얼려서" 어떠한 변경도 불가능하게 만듭니다.

- **주요 사용 사례**: 해킹이나 관리자의 실수로부터 시스템의 매우 중요한 설정 파일을 보호할 때 사용합니다. (예: `/etc/resolv.conf`, `/etc/hosts` 등)

- **사용 예시**:
    ```bash
    # 1. 테스트용 중요 파일 생성
    $ sudo touch /etc/important.conf

    # 2. 'i' 속성 부여
    $ sudo chattr +i /etc/important.conf

    # 3. 속성 확인 (i 플래그가 설정된 것을 볼 수 있음)
    $ lsattr /etc/important.conf
    ----i---------e---- /etc/important.conf

    # 4. 일반 사용자가 삭제 시도 -> 당연히 실패
    $ rm /etc/important.conf
    rm: cannot remove '/etc/important.conf': Operation not permitted

    # 5. root가 삭제 시도 -> 역시 실패!
    $ sudo rm /etc/important.conf
    rm: cannot remove '/etc/important.conf': Operation not permitted

    # 6. 파일을 수정하려면, 반드시 'i' 속성을 먼저 제거해야 한다.
    $ sudo chattr -i /etc/important.conf
    $ sudo rm /etc/important.conf # 이제 삭제 성공
    ```

### `a` 속성: 추가만 가능 (Append-only)

- **기능**: "Append-only"의 약자로, 이 속성이 설정된 파일은 **내용을 덧붙이는 것(append)만 가능**합니다. 기존 내용을 수정하거나 삭제하는 것은 불가능합니다.

- **주요 사용 사례**: 중요한 로그 파일에 사용됩니다. 누군가 악의적으로 기존의 접속 기록이나 시스템 로그를 지우거나 변조하는 것을 막고, 새로운 로그는 계속 쌓이도록 할 수 있습니다.

- **사용 예시**:
    ```bash
    # 1. 테스트용 로그 파일 생성
    $ sudo touch /var/log/secure.log

    # 2. 'a' 속성 부여
    $ sudo chattr +a /var/log/secure.log

    # 3. 속성 확인
    $ lsattr /var/log/secure.log
    -----a--------e---- /var/log/secure.log

    # 4. 파일 끝에 새로운 내용 추가 -> 성공
    $ echo "New log entry" | sudo tee -a /var/log/secure.log
    New log entry

    # 5. 파일을 덮어쓰려고 시도 -> 실패!
    $ echo "Overwrite attempt" | sudo tee /var/log/secure.log
    tee: /var/log/secure.log: Operation not permitted

    # 6. 속성 제거
    $ sudo chattr -a /var/log/secure.log
    ```

## 3. 요약

`chattr`는 일반적인 `rwx` 권한 체계를 넘어서는, 파일 시스템 레벨의 강력한 보호 기능을 제공합니다. 특히 `i` 속성과 `a` 속성은 시스템의 무결성을 유지하고 중요한 파일을 보호하는 데 매우 효과적인 도구이므로, 시스템 관리자라면 반드시 알아두어야 할 기능입니다.
